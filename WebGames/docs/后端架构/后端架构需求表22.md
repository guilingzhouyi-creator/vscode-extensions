# 后端架构需求表22（第二十二卷：精英变异怪物通用衍生与狂暴状态机底座）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**普通怪物变异衍生、词缀矩阵动态插拔 (Pluggable Affix Matrix)、参数化狂暴状态机 (Configurable Berserk FSM) 与战利品衍生通用底座**。
>
> **【严正声明 · 绝对通用底座准则】**：
> 1. **纯粹的装饰器/增强器架构 (Decorator Pattern)**：任何基础怪物实体（基于第七卷与第八卷）均可通过装配 `EliteMutationProfile` 动态升维为精英/地牢首领，无任何代码级侵入；
> 2. **数据驱动词缀注册中心 (Data-Driven Affix Registry)**：所有词缀属性倍率、光环作用域、受击反应函数均由配置文件或注册表注入，支持无缝拓展新词缀；
> 3. **通用狂暴状态机 (Generic Berserk FSM)**：支持自定义狂暴触发条件（按剩余血量百分比、战斗持续时间阈值、累积承受伤害阈值等），狂暴增益曲线参数化可调；
> 4. **战利品动态强化管线 (Dynamic Loot Scale Pipeline)**：根据怪物变异词缀数量与阶位乘子，自发放大对应品类的掉落概率与高阶强化材料产出。

## 二、 通用词缀计算与力学动态注入求解器 (`GenericAffixSolver`)

```gdscript
# 脚本路径: res://core/domain/monster/generic_affix_solver.gd
class_name GenericAffixSolver
extends RefCounted

# 通用词缀注入算法
static func compile_elite_modifiers(
    base_stats: Dictionary,
    affix_ids: Array[String],
    registry: Dictionary
) -> Dictionary:
    var compiled = base_stats.duplicate(true)

    for affix_id in affix_ids:
        var affix_def = registry.get(affix_id, {})
        if affix_def.is_empty(): continue

        # 1. 属性乘法修正
        for key in affix_def.get("stat_multipliers", {}).keys():
            if compiled.has(key):
                compiled[key] *= affix_def["stat_multipliers"][key]

        # 2. 属性加法修正
        for key in affix_def.get("stat_additions", {}).keys():
            if compiled.has(key):
                compiled[key] += affix_def["stat_additions"][key]

    return compiled
```

## 三、 通用狂暴状态机 (`GenericBerserkFSM`)

```gdscript
# 脚本路径: res://core/domain/monster/generic_berserk_fsm.gd
class_name GenericBerserkFSM
extends RefCounted

static func update_berserk_status(
    monster: EliteMonsterAggregate,
    current_hp: float,
    max_hp: float,
    delta_seconds: float
) -> Dictionary:
    var cfg = monster.berserk_config
    var hp_ratio = current_hp / max(1.0, max_hp)

    # 1. 检定血量狂暴
    var hp_thresh = cfg.get("hp_threshold_ratio", 0.0)
    if hp_thresh > 0.0 and hp_ratio <= hp_thresh and not monster.is_berserk_active:
        monster.is_berserk_active = true
        monster.current_damage_multiplier *= 1.5
        return { "triggered": true, "cause": "HP_THRESHOLD", "multiplier": monster.current_damage_multiplier }

    # 2. 检定超时狂暴
    var time_limit = cfg.get("time_limit_seconds", 0.0)
    if time_limit > 0.0:
        monster.elapsed_combat_seconds += delta_seconds
        if monster.elapsed_combat_seconds > time_limit:
            var excess_steps = int((monster.elapsed_combat_seconds - time_limit) / 10.0)
            monster.current_damage_multiplier = 1.0 + float(excess_steps) * cfg.get("overtime_damage_step", 0.20)
            return { "triggered": true, "cause": "OVERTIME_ENRAGE", "multiplier": monster.current_damage_multiplier }

    return { "triggered": false }
```
