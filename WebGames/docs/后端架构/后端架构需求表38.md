# 后端架构需求表38（第三十八卷：全域多语言国际化、词条动态插值与兜底回退引擎）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**多语言本地化 (I18N & L10N)、动态参数插值格式化 (Parametric Text Interpolation)、未翻译安全兜底与热切换中枢**。系统必须满足：
> 1. **全域零硬编码文案准则 (Zero Hardcoded Text)**：
>    - 核心引擎与领域模型中严禁出现任何展示性硬编码自然语言，所有物品名、技能描述、任务对话、剧情文本、错误码提示一律使用 `loc_key`（如 `combat.crit_strike.log`）；
> 2. **参数化占位符动态插值引擎 (Dynamic Token Interpolation Engine)**：
>    - 支持 `{player_name}`、`{damage}`、`{item_name}` 等变量动态替换，支持复数形式与带格式富文本修饰；
> 3. **多层级语言包加载与安全回退 (Multi-tier Fallback Hierarchy)**：
>    - 默认语言链：目标语言（如 `ja_JP`）$\rightarrow$ 首选后备语言（`en_US`）$\rightarrow$ 最终原初语言（`zh_CN`）$\rightarrow$ 原始 `loc_key`；杜绝界面因缺词条发生 Fatal 崩溃；
> 4. **毫秒级语言即时热重载 (Hot Reloading)**：
>    - 联动《第二十六卷》全局设置中心，玩家切换语言时无需重启游戏，所有 UI 文本与通知通过事件总线自发刷新。

## 二、 文本插值与本地化解析求解器 (`LocalizationSolver`)

```gdscript
# 脚本路径: res://core/domain/i18n/localization_solver.gd
class_name LocalizationSolver
extends RefCounted

# 解析并格式化本地化文本
static func translate(
    catalog: LocalizationRegistryCatalog,
    loc_key: String,
    params: Dictionary = {},
    locale_override: String = ""
) -> String:
    var target_loc = locale_override if locale_override != "" else catalog.current_locale
    var dict = catalog._locale_dictionaries.get(target_loc, {})

    var raw_template = ""
    if dict.has(loc_key):
        raw_template = dict[loc_key]
    else:
        # 回退至备用语言
        var fb_dict = catalog._locale_dictionaries.get(catalog.fallback_locale, {})
        if fb_dict.has(loc_key):
            raw_template = fb_dict[loc_key]
        else:
            # 最终兜底返回原始 key
            return "[%s]" % loc_key

    # 动态参数插值
    var formatted_text = raw_template
    for k in params.keys():
        var token = "{" + str(k) + "}"
        formatted_text = formatted_text.replace(token, str(params[k]))

    return formatted_text
```

## 三、 多语言解析与热重载管线 (`LocalizationSolver`)

1. **动态参数插值**：`translate` 将 `{attacker}` 等命名占位符按上下文参数精准插值格式化；
2. **多层级兜底回退**：当前语言缺词条 → `fallback_locale` 回退 → 双缺时返回 `[原始 key]` 安全兜底，界面永不空白；
3. **即时热重载**：`I18nHotReloadPipeline.switch_language` 切换语言环境零重启生效，`register_translation` / `load_locale_dict` 支撑语言包装载。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM38-003`（见归档库档案卷）。
