# 后端架构需求表32（第三十二卷：多硬件输入感知、键鼠手柄热插拔与自适应控制器调度系统）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
>
> 本卷定义卡拉尔高魔世界引擎的**多外设硬件输入流监听 (Multi-Hardware Input Stream)、设备自适应热切换 (Adaptive Controller Hot-Swap)、摇杆死区校准与动作映射中枢**。系统必须满足：
> 1. **全外设统一事件总线 (Unified Hardware Input Event Bus)**：
>    - 全面兼容并监控 **键盘 (Keyboard)、鼠标 (Mouse)、标准游戏手柄 (Xbox / DualShock / Switch Pro / Steam Deck)** 与触摸/虚拟轴；
> 2. **自适应输入设备热识别与 UI 提示热切换 (Seamless Device Hot-Switching)**：
>    - 引擎毫秒级监听活跃输入源：
>      - 玩家移动手柄摇杆或按键 ➔ 瞬间无缝切换为【手柄模式】，UI 动作图标即时变换为 `(A) / (X) / (RT)`；
>      - 玩家滑动鼠标或敲击键盘 ➔ 瞬间切换为【键鼠模式】，UI 提示自发展示 `[E] / [Space] / [Click]`；
> 3. **摇杆非线性死区与灵敏度滤波求解器 (Stick Deadzone & Sensitivity Filter)**：
>    - 过滤摇杆硬件物理漂移，支持轴向死区 (Axial Deadzone) 与径向圆形死区 (Radial Deadzone)；
> 4. **动作重映射与全局设置持久化联动 (Action Rebinding & Persistence)**：
>    - 支持玩家自定义动作按键绑定，自动联动《第二十六卷》写入 `settings.kalar_cfg`。

## 一、 输入设备状态领域实体 (`InputDeviceStateAggregate`)

# 脚本路径: res://core/domain/input/input_device_state_aggregate.gd
class_name InputDeviceStateAggregate
extends RefCounted

enum ActiveInputDevice {
    KEYBOARD_AND_MOUSE, # 键盘与鼠标
    GAMEPAD_CONTROLLER, # 游戏手柄 (XInput / DualShock / DirectInput)

var current_device: ActiveInputDevice = ActiveInputDevice.KEYBOARD_AND_MOUSE
var last_input_timestamp_ms: int = 0
var gamepad_device_id: int = 0

# 摇杆滤波配置
var stick_deadzone_inner: float = 0.15       # 内部死区 (防漂移)

var mouse_sensitivity_scalar: float = 1.0

# 动作按键映射字典 (action_name -> Array[InputEventDTO])

    "move_north": ["Key_W", "Joypad_Up"],
    "move_south": ["Key_S", "Joypad_Down"],
    "move_east": ["Key_D", "Joypad_Right"],
    "move_west": ["Key_A", "Joypad_Left"],
    "interact": ["Key_E", "Joypad_ButtonA"],
    "open_inventory": ["Key_I", "Joypad_ButtonY"]
}

## 二、 摇杆死区滤波与设备自适应调度求解器 (`AdaptiveInputFilterSolver`)

```gdscript
# 脚本路径: res://core/domain/input/adaptive_input_filter_solver.gd
class_name AdaptiveInputFilterSolver
extends RefCounted

# 径向圆形死区非线性重映射
static func apply_radial_deadzone(
    raw_stick_vector: Vector2,
    inner_deadzone: float,
    outer_deadzone: float
) -> Vector2:
    var magnitude = raw_stick_vector.length()
    if magnitude < inner_deadzone:
        return Vector2.ZERO
    if magnitude > outer_deadzone:
        return raw_stick_vector.normalized()

    # 非线性平滑归一化映射
    var scaled_mag = (magnitude - inner_deadzone) / (outer_deadzone - inner_deadzone)
    return raw_stick_vector.normalized() * scaled_mag

# 自动设备切换识别
static func evaluate_active_device_switch(
    aggregate: InputDeviceStateAggregate,
    is_gamepad_event: bool,
    current_time_ms: int
) -> Dictionary:
    var previous = aggregate.current_device
    var new_device = ActiveInputDevice.GAMEPAD_CONTROLLER if is_gamepad_event else ActiveInputDevice.KEYBOARD_AND_MOUSE

    if new_device != previous:
        aggregate.current_device = new_device
        aggregate.last_input_timestamp_ms = current_time_ms
        return {
            "device_switched": true,
            "old_device": previous,
            "new_device": new_device,
            "ui_prompt_mode": "GAMEPAD" if is_gamepad_event else "KEYBOARD_MOUSE"
        }

    return { "device_switched": false }
```

## 三、 自适应输入滤波与键位重映射服务 (`AdaptiveInputFilterSolver`)

1. **设备毫秒级热切换**：`handle_device_input_event` 按最近输入源判定键鼠/手柄模式，`get_ui_button_prompt` 即时热更新按键提示图标；
2. **径向死区滤波**：`filter_radial_deadzone` 内死区归零防物理漂移、外死区饱和归一化、中间线性重映射，全程径向圆形判定；
3. **动作键位重映射**：`ActionRebindingService.rebind_action` 玩家自定义映射即时热应用；
4. **Tab 双击组合检测**：`TabDoubleTapDetector` 按配置窗口期（`domains.hardware_input` → `tab_double_tap/window_ms`，默认 300ms）区分单击/双击，非 Tab 键自动重置连按节奏，供《第二十一卷》聊天命令智能补全联动。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM32-003`（见归档库档案卷）。
