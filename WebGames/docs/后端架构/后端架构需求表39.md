# 后端架构需求表39（第三十九卷：全域事件驱动音频调度、空间混音与动态音轨编排系统）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**全域事件驱动音频调度 (Event-Driven Audio Dispatcher)、2D 空间声学距离衰减混音、多音轨淡入淡出 (Cross-fade) 与音频总线中枢**。系统必须满足：
> 1. **深度联动全域事件流与状态机 (Coupled with Event Stream)**：
>    - 绝非写死音频触发，全面监听《第二卷》战斗命中、《第三卷》进入城镇、《第八卷》怪物狂暴、《第三十五卷》世界大事件推流；
> 2. **四轨独立音频总线拓扑 (Four-Track Audio Bus Architecture)**：
>    - `BGM` (背景音乐): 支持双音轨平滑交叉淡入淡出 (Cross-fade)；
>    - `BGS` (环境音效): 城镇喧嚣、雨夜风暴、熔岩呼啸持续流；
>    - `SE` (即时动作音效): 刀剑挥砍、魔法吟唱爆裂、金币叮当；
>    - `ME` (剧情音乐段): 战胜号角、神降降临、任务交付专属短奏；
> 3. **空间几何声学距离衰减方程 (Spatial Acoustic Attenuation)**：
>    - 针对地面音源 $\mathbf{P}_{\text{audio}}$ 与玩家监听位置 $\mathbf{P}_{\text{listener}}$：
>      $$\text{Vol}_{\text{eff}} = \text{Vol}_{\text{base}} \times \max\left(0.0, 1.0 - \frac{\|\mathbf{P}_{\text{listener}} - \mathbf{P}_{\text{audio}}\|}{R_{\text{max}}}\right)$$
> 4. **并发声效防爆音截断池 (Voice Concurrency & Polyphony Limiter)**：
>    - 同一音频事件（如箭雨打击）同时触发时，限制最大并发播放路数（如最多 4 路），超时自发抑制，杜绝爆音与声卡卡死。

```gdscript
enum AudioBusTrack { BGM, BGS, SE, ME }

var max_audible_distance: float = 20.0      # 最大可听半径 (米)
var fade_duration_seconds: float = 0.0      # 交叉淡入淡出时长
```

## 二、 空间声学与混音衰减求解器 (`SpatialAudioSolver`)

```gdscript
# 脚本路径: res://core/domain/audio/spatial_audio_solver.gd
class_name SpatialAudioSolver
extends RefCounted

# 计算最终生效音量与声道平衡
static func evaluate_spatial_audio(
    cmd: AudioDispatchCommandDTO,
    listener_pos: Vector2,
    master_volume: float
) -> Dictionary:
    if not cmd.is_spatial:
        return { "play": true, "effective_volume": cmd.volume_scale * master_volume, "pan": 0.0 }

    var dist = listener_pos.distance_to(cmd.source_pos)
    if dist >= cmd.max_audible_distance:
        return { "play": false, "effective_volume": 0.0, "pan": 0.0 }

    # 线性距离衰减
    var dist_factor = clamp(1.0 - (dist / cmd.max_audible_distance), 0.0, 1.0)
    var eff_vol = cmd.volume_scale * dist_factor * master_volume

    # 左右声道立体声水平声相 (Pan: -1.0 左, +1.0 右)
    var delta_x = cmd.source_pos.x - listener_pos.x
    var pan = clamp(delta_x / cmd.max_audible_distance, -1.0, 1.0)

    return {
        "play": eff_vol > 0.001,
        "effective_volume": eff_vol,
        "pan": pan,
        "pitch": cmd.pitch_scale
    }
```

## 三、 空间声学求解与四轨总线管线 (`AudioBusPipeline`)

1. **空间衰减与声相**：`evaluate_spatial_audio` 按听者距离线性衰减有效音量 (1 − d/max) 并几何求解立体声水平 pan；
2. **并发限流防爆音**：`dispatch_sound_event` 对同音效维护活跃计数，超过并发上限返回 CONCURRENCY_LIMIT_REACHED 截断，保护声卡；
3. **四轨独立总线**：BGM/BGS/SE/ME 各轨按 `bus_vols` 独立加权路由，互不串扰。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM39-003`（见归档库档案卷）。
