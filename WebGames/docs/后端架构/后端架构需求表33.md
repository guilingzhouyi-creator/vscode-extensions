# 后端架构需求表33（第三十三卷：地面实体掉落物、空间拾取保护与生态衰变半衰期系统）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**物理地面掉落实体 (Ground Dropped Item Entity)、空间拾取判定、所有权保护倒计时与生态自然衰变半衰期中枢**。系统必须满足：
> 1. **全域物品落地物理实体化 (Physicalization of Dropped Items)**：
>    - 无论是击败魔兽、破坏矿脉、盗贼失手还是玩家主动丢弃，物品均必须真实实例化为地面实体，挂载于《第三十一卷》微观实数欧氏坐标 $\mathbf{P} = (x, y)$；
> 2. **空间距离与负重拾取检定 (Proximity & Inventory Capacity Check)**：
>    - 玩家必须肉身接近掉落物有效拾取半径（如 $R \le 2.0\text{m}$），且随身背包体积与负重有余量，方可拾取入包；
> 3. **击杀归属与拾取保护倒计时状态机 (Ownership Protection Window)**：
>    - BOSS/精英怪掉落物享有专属保护期（如 60 秒内仅首刀贡献者或所在小队成员可见/可拾取）；保护期结束后转为全服自由拾取公共状态；
> 4. **材质生态衰变与自然分解半衰期 (Ecological Decay Half-Life)**：
>    - 掉落物绝非无限期永久堆积（严防内存泄漏与场景垃圾泛滥）：
>      - 有机生鲜（魔兽生肉/新鲜草药）：24 小时自然腐败分解为有机腐殖质；
>      - 普通装备与矿石：72 小时慢速风化销蚀；
>      - 传奇遗物与魔单晶：永不自然销蚀，直至被拾取或地脉吞噬。

## 一、 地面掉落物实体聚合根 (`GroundDroppedItemAggregate`)

```gdscript
# 脚本路径: res://core/domain/loot/ground_dropped_item_aggregate.gd
class_name GroundDroppedItemAggregate
extends RefCounted

enum LootDecayCategory {
    ORGANIC_PERISHABLE,   # 有机易腐品 (生肉/鲜花/生鲜药材) -> 半衰期短
    STANDARD_MINERAL_EQUIP,# 标准装备与矿石 -> 中等半衰期
    ETERNAL_LEGENDARY     # 传奇神器与魔单晶 -> 永不自然腐朽
}

var drop_id: String                         # 掉落实体唯一 ID (UUID)
var item_entity: RefCounted                 # 引用的真实万物物品实体 ItemEntity (第一卷)

# 空间位置 (第三十一卷)
var location_town_id: String
var local_coordinates: Vector2 = Vector2.ZERO
var pickup_radius_meters: float = 2.0

# 归属与保护权
var killer_account_id: String = ""          # 击杀者/掉落归属人
var killer_team_id: String = ""             # 归属小队 ID
var protection_remain_seconds: float = 60.0 # 专属保护倒计时 (秒)

# 生态衰变生命周期
var decay_category: LootDecayCategory = LootDecayCategory.STANDARD_MINERAL_EQUIP
var total_lifespan_seconds: float = 7200.0  # 地面存活总时限 (秒)
var elapsed_alive_seconds: float = 0.0
var is_decayed: bool = false
```

## 二、 空间拾取与归属保护求解器 (`GroundLootPickupSolver`)

```gdscript
# 脚本路径: res://core/domain/loot/ground_loot_pickup_solver.gd
class_name GroundLootPickupSolver
extends RefCounted

# 检定是否允许拾取
static func can_player_pickup(
    player_account_id: String,
    player_team_id: String,
    player_pos: Vector2,
    loot: GroundDroppedItemAggregate
) -> Dictionary:
    if loot.is_decayed:
        return { "allow": false, "code": "ERR_ALREADY_DECAYED", "msg": "物品已自然风化销蚀" }

    var dist = player_pos.distance_to(loot.local_coordinates)
    if dist > loot.pickup_radius_meters:
        return { "allow": false, "code": "ERR_TOO_FAR", "msg": "距离掉落物过远，无法拾取" }

    # 归属保护期检定
    if loot.protection_remain_seconds > 0.0:
        var is_owner = (player_account_id == loot.killer_account_id) or (loot.killer_team_id != "" and player_team_id == loot.killer_team_id)
        if not is_owner:
            return {
                "allow": false,
                "code": "ERR_PROTECTION_LOCKED",
                "msg": "该战利品处于击杀者专属保护期内，剩余 %.1f 秒" % loot.protection_remain_seconds
            }

    return { "allow": true }
```

## 三、 生态衰变状态机与拾取求解器 (`GroundLootDecayFSM`)

1. **拾取半径检定**：`attempt_pickup` 以欧氏距离强制空间邻近，超出返回 OUT_OF_PICKUP_RANGE；
2. **击杀者专属保护窗**：`protection_remain_seconds` 保护期内非击杀者拾取拦截 PROTECTED_BY_KILLER，窗口过后转全服公共；
3. **生态衰变生命周期**：`tick_ground_loot` 按 `LootDecayCategory` 材质寿命（生鲜/矿石/神器）衰减，到期 `is_decayed` 置位并拒绝拾取（ITEM_DECAYED），自动完成垃圾回收。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM33-003`（见归档库档案卷）。
