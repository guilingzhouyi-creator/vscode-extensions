# 后端架构需求表41（第四十一卷：登录页全服动态告示板、维护倒计时与 GM 远程推流系统）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**启动与登录全服告示板 (Title Announcement & Bulletin Board)、停机维护倒计时闸门、动态富文本公告与 GM 远程热推中枢**。系统必须满足：
> 1. **冷启动告示板原子缓存 (Cold Start Cache & Protocol)**：
>    - 客户端启动阶段在进入主场景前，优先向后端/本地缓存发起 `BulletinBoardSyncRequest`，获取最新维护状态与版本公告；
> 2. **服务器维护倒计时与强制阻断闸门 (Maintenance Gatekeeper)**：
>    - 公告包含 `is_under_maintenance: bool` 与 `maintenance_end_utc: int`；
>    - 维护期间非白名单（非 GM）账户尝试点击“进入游戏”时，状态机强行拦截并弹出精准维护倒计时提示；
> 3. **动态富文本与活动公告卡片集 (Announcement Cards)**：
>    - 支持多张公告轮播卡片（如“新版本更新日志”、“全服开服庆典”、“修复热补丁说明”），支持优先级权重排序；
> 4. **联动第二十卷 GM 系统与指令热推 (GM Live Management)**：
>    - 管理员可通过 GM 命令或控制台动态修改、发布、下架公告，全服客户端毫秒级热更同步。

## 二、 告示板同步与登录准入求解器 (`BulletinBoardSolver`)

```gdscript
# 脚本路径: res://core/domain/bulletin/bulletin_board_solver.gd
class_name BulletinBoardSolver
extends RefCounted

# 校验当前客户端是否允许登录
static func check_login_permission(
    board: BulletinBoardAggregate,
    is_gm_account: bool,
    current_utc: int
) -> Dictionary:
    if board.server_maintenance_mode:
        if not is_gm_account:
            var remain_secs = max(0, board.maintenance_end_timestamp_utc - current_utc)
            return {
                "allow_login": false,
                "code": "ERR_SERVER_MAINTENANCE",
                "remain_seconds": remain_secs,
                "msg": "%s 预计剩余维护时间: %d 分钟" % [board.maintenance_notice_msg, int(remain_secs / 60.0)]
            }

    return { "allow_login": true, "msg": "允许进入世界" }
```

## 三、 告示板同步与登录准入求解器 (`BulletinBoardSolver`)

1. **维护闸门**：`set_maintenance` 开启维护后 `check_login_permission` 对普通账户强阻断（ERR_SERVER_MAINTENANCE）并下发剩余倒计时；
2. **GM 白名单放行**：管理员账户在维护期 `allow_login` 直通，保障远程运维与热修；
3. **公告优先级排序**：`add_card` 按权重动态插入，卡片集合恒保持降序，热补丁公告恒先于常规活动展示。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM41-003`（见归档库档案卷）。
