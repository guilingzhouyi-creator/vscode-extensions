# 后端架构需求表31（第三十一卷：双轨空间坐标系、文字拓扑向 2D 连续位移平滑演化引擎）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**宏观图论拓扑网络 (Topological Discrete Graph) 与微观连续欧氏空间坐标 (Continuous Euclidean Space) 双轨并存机制**。系统必须满足：
> 1. **双轨架构设计 (Dual-Layer Spatial Architecture)**：
>    - **宏观层（大地图与城镇路由）**：以大陆节点、定居点 ID、建筑子图 ID 为离散拓扑图论索引（满足文字跑团、战略宏观调度与快速路由）；
>    - **微观层（局部场景与交互物理）**：在每个定居点或野外网格内，严格维护实数浮点坐标 $\mathbf{P} = (x, y) \in \mathbb{R}^2$（米制绝对坐标）；
> 2. **文字向 2D/3D 平滑演化零成本桥接 (Seamless 2D Transformation Bridge)**：
>    - 文字模式下的指令（如“向北移动 10 米”、“走入铁匠铺”）在底层直接转换为连续向量位移 $\Delta \mathbf{P} = \mathbf{v} \times \Delta t$；
>    - 后续前端接入 2D 瓦片地图 (TileMap) 或虚拟摇杆时，**底层坐标模型 100% 完全复用，无需重写任何空间判定逻辑**；
> 3. **空间距离与多形状触发器检定 (Spatial Trigger Evaluator)**：
>    - 支持圆形半径触发器 ($D \le R$)、矩形包围盒 (AABB) 与多边形房间边界检定；
> 4. **速度、地形阻抗与负重对位移的衰减 (Velocity & Terrain Impedance)**：
>    - 移动速度严格受到《第七卷》敏捷 AGI、《第十八卷》装备总负重与《第三卷》地质阻抗矩阵的综合阻尼约束。

# 1. 宏观离散图论定位
var continent_id: String = "CONTINENT_CENTRAL"   # 大陆 ID

func get_global_spatial_fingerprint() -> String:
    return "%s:%s:%s:(%.2f,%.2f)" % [continent_id, region_node_id, interior_subgraph_id, local_coordinates.x, local_coordinates.y]

## 二、 空间移动与 2D 演化桥接求解器 (`MovementVectorBridgeSolver`)

```gdscript
# 脚本路径: res://core/domain/spatial/movement_vector_bridge_solver.gd
class_name MovementVectorBridgeSolver
extends RefCounted

# 1. 文字动词移动指令转连续向量
# verb_direction: "NORTH", "SOUTH", "EAST", "WEST", "NORTHEAST", etc.
static func translate_text_step_to_vector(verb_direction: String, distance_meters: float) -> Vector2:
    var dir = Vector2.ZERO
    match verb_direction.to_upper():
        "NORTH", "N": dir = Vector2(0, -1)
        "SOUTH", "S": dir = Vector2(0, 1)
        "EAST", "E": dir = Vector2(1, 0)
        "WEST", "W": dir = Vector2(-1, 0)
        "NORTHEAST", "NE": dir = Vector2(1, -1).normalized()
        "NORTHWEST", "NW": dir = Vector2(-1, -1).normalized()
        "SOUTHEAST", "SE": dir = Vector2(1, 1).normalized()
        "SOUTHWEST", "SW": dir = Vector2(-1, 1).normalized()
    return dir * distance_meters

# 2. 连续时间步位移步进 (支持摇杆输入与物理模拟)
static func step_movement(
    location: SpatialLocationEntity,
    input_direction: Vector2,
    terrain_friction: float,
    weight_penalty_ratio: float,
    delta_seconds: float
) -> Vector2:
    var effective_speed = location.base_move_speed_mps * (1.0 - weight_penalty_ratio) * (1.0 / max(0.1, terrain_friction))
    var movement_delta = input_direction.normalized() * effective_speed * delta_seconds

    location.local_coordinates += movement_delta
    if input_direction.length_squared() > 0.001:
        location.orientation_facing = input_direction.normalized()

    return location.local_coordinates
```

## 三、 文字位移桥接与空间触发状态机 (`MovementVectorBridgeSolver`)

1. **文字动词 → 连续向量**：`translate_text_step_to_vector` 将 NORTH/EAST 等方位动词精确映射为欧氏向量，`apply_displacement` 累加进局部实数坐标；
2. **综合速度衰减**：`calculate_effective_speed` = 基础速度 × AGI 修正 × 负重惩罚 ÷ 地形阻抗（例：4.5 × 1.0 × 0.5 ÷ 2.0 == 1.125 m/s）；
3. **空间触发状态机**：`SpatialTriggerFSM.evaluate_trigger_state` 输出 OUTSIDE → ENTERED → INSIDE → EXITED 完整边界生命周期，支撑圆形与多边形区域。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM31-003`（见归档库档案卷）。
