# 后端架构需求表35（第三十五卷：全域因果剧情流、动态事件编排调度与世界大事件编年史引擎）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎**统领全域因果律、时空状态机组合、宏观世界演进与动态叙事流转的最高核心中枢 (Grand Narrative Causality Orchestrator)**。系统必须满足：
> 1. **全域事件因果有向无环图 (Narrative Event Causality DAG)**：
>    - 游戏中的一切剧情并非线性的死脚本，而是基于世界状态快照的自发涌现与因果链推进；
>    - 每个剧情节点由**【前置条件求值器 (Precondition Evaluator)】**、**【触发动作集 (Action Pipeline)】**与**【因果突变影响 (Causality Mutators)】**构成；
> 2. **多元条件复合组合判定 (Multi-Condition Composite Solver)**：
>    - 支持空间坐标、地缘所属、昼夜时间、天气魔素浓度、阵营声望、经历阶位、背包特定物品、以及历史已死 NPC 墓碑记录的多维复合布尔逻辑运算（`AND` / `OR` / `NOT`）；
> 3. **三层事件拓扑分级 (Three-Tier Event Hierarchy)**：
>    - **世界史诗天灾事件 (World Calamity & Historical Eras)**：帝国政变、神降天灾、大洲魔素海啸；全大陆广播并改变全局环境阻抗；
>    - **地缘城镇生态事件 (Regional Town Incidents)**：兽潮围城、黑市暴动、行会罢工、瘟疫蔓延；影响局部物价与治安；
>    - **个人因果奇遇事件 (Personal Encounters & Quests)**：酒馆密谋、遗迹残卷破译、暗杀伏击；
> 4. **不可逆因果历史编年史流水 (Irreversible World Chronicle Log)**：
>    - 发生的每个重大事件均生成确定性事件哈希并写入《第六卷》存档编年史，单机与联机回放 100% 确定可查。

## 二、 全域因果事件流编排调度引擎 (`NarrativeCausalityOrchestrator`)

```gdscript
# 脚本路径: res://core/domain/narrative/narrative_causality_orchestrator.gd
class_name NarrativeCausalityOrchestrator
extends RefCounted

# 求值世界状态是否满足事件触发条件
static func evaluate_conditions(ast: Dictionary, world_context: Dictionary) -> bool:
    var op = ast.get("type", "AND")
    var conds = ast.get("conditions", [])

    if conds.is_empty():
        return true

    for c in conds:
        var passed = false
        var kind = c.get("kind", "")
        match kind:
            "TOWN_EQUALS":
                passed = (world_context.get("current_town_id") == c.get("val"))
            "HOUR_BETWEEN":
                var h = world_context.get("current_hour", 12)
                passed = (h >= c.get("min") and h <= c.get("max"))
            "REPUTATION_GREATER":
                var rep = world_context.get("reputations", {}).get(c.get("faction"), 0)
                passed = (rep >= c.get("val"))
            "VARIABLE_FLAG":
                passed = (world_context.get("global_flags", {}).get(c.get("key")) == c.get("val"))

        if op == "AND" and not passed:
            return false
        elif op == "OR" and passed:
            return true

    return (op == "AND")

# 推进事件管线
static func try_dispatch_event(
    event: NarrativeEventAggregate,
    world_context: Dictionary,
    event_bus: RefCounted
) -> Dictionary:
    if event.has_triggered and not event.is_repeatable:
        return { "dispatched": false, "reason": "ALREADY_COMPLETED" }

    if not evaluate_conditions(event.trigger_conditions_ast, world_context):
        return { "dispatched": false, "reason": "CONDITIONS_NOT_MET" }

    event.has_triggered = true
    event.triggered_timestamp_utc = world_context.get("utc_now", 0)

    return {
        "dispatched": true,
        "event_id": event.event_id,
        "scope": event.event_scope,
        "payload": event.payload_actions
    }
```

## 三、 因果剧情编排器与编年史管线 (`NarrativeCausalityOrchestrator`)

1. **AST 复合条件求值**：`evaluate_ast_condition` 递归求值 AND/OR 嵌套树，谓词覆盖城镇等同、等级门槛、阵营声望阈值等多维世界上下文；
2. **优先级权重仲裁**：`arbitrate_and_trigger` 对并发事件按权重降序仲裁触发，世界史诗级（500）恒先于个人奇遇级（50）；
3. **编年史确定性落盘**：`ChronicleLoggerPipeline.log_chronicle_event` 为每条大事件生成 16 位哈希指纹，构成不可逆因果编年史流水，供单机/联机回放审计。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM35-003`（见归档库档案卷）。
