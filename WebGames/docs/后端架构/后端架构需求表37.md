# 后端架构需求表37（第三十七卷：工程调试热更、特性开关与金丝雀灰度推送分流系统）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**动态特性开关配置 (Feature Flag & Toggles)、金丝雀灰度推送分流算法 (Canary Rollout Bucketing)、工程调试控制台与崩溃自愈熔断中枢**。系统必须满足：
> 1. **动态特性开关矩阵 (Feature Flag Matrix)**：
>    - 全域所有新增系统（如第三十卷空间商铺、第三十一卷2D位移、第二十七卷玩家公会）均可受特性开关动态控制启用/禁用/隐藏；
>    - 可以在不重新打包发布的情况下，动态开启或关闭特定玩法实验；
> 2. **确定性哈希百分比分流求解器 (Deterministic Hash Bucketing Solver)**：
>    - 采用一致性哈希方程：$$\text{Bucket} = \text{CRC32}(\text{account\_id} + \text{feature\_key}) \pmod{100}$$
>    - 精准支撑 $0\% \rightarrow 10\% \rightarrow 50\% \rightarrow 100\%$ 阶梯式金丝雀灰度推送；
>    - 白名单账户（开发者、核心测试员）100% 强制命中灰度实验；
> 3. **工程调试控制台指令注入 (Debug Telemetry & Command Injection)**：
>    - 开发者/测试员可输入灰度控制指令（如 `/canary enable_feature 2D_MOVEMENT`）；
>    - 动态上报灰度节点性能耗时与帧率遥测指标；
> 4. **异常崩溃自动回滚与熔断保护 (Circuit Breaker & Rollback Guard)**：
>    - 灰度模块一旦在客户端触发未捕获 Fatal 崩溃，熔断计数器累加；达到阈值（如连续 3 次）自发对该客户端回滚禁用该特性并上报故障快照。

## 一、 灰度分流与特性开关实体 (`FeatureToggleAggregate`)

```gdscript
# 脚本路径: res://core/domain/canary/feature_toggle_aggregate.gd
class_name FeatureToggleAggregate
extends RefCounted

enum RolloutStrategy {
    GLOBAL_DISABLED,    # 全局关闭 (0%)
    WHITELIST_ONLY,     # 仅白名单测试员可见
    PERCENTAGE_CANARY,  # 百分比灰度分流 (1%~99%)
    GLOBAL_ENABLED      # 全量开放 (100%)
}

class FeatureFlagEntry extends RefCounted:
    var feature_key: String                 # 如 "FEATURE_2D_CONTINUOUS_MOVEMENT"
    var strategy: RolloutStrategy = RolloutStrategy.GLOBAL_DISABLED
    var rollout_percentage: int = 0         # 0~100
    var whitelist_account_ids: Array[String] = []
    var is_circuit_broken: bool = false     # 是否已被熔断器强制关闭
    var failure_count: int = 0              # 崩溃计数

# feature_key -> FeatureFlagEntry
var flags_registry: Dictionary = {}
```

## 二、 灰度分流与熔断求解器 (`CanaryRolloutSolver`)

```gdscript
# 脚本路径: res://core/domain/canary/canary_rollout_solver.gd
class_name CanaryRolloutSolver
extends RefCounted

# 计算账户是否命中某特性的灰度分流
static func is_feature_enabled_for_account(
    flag: FeatureToggleAggregate.FeatureFlagEntry,
    account_id: String
) -> bool:
    if flag.is_circuit_broken:
        return false

    match flag.strategy:
        FeatureToggleAggregate.RolloutStrategy.GLOBAL_DISABLED:
            return false
        FeatureToggleAggregate.RolloutStrategy.GLOBAL_ENABLED:
            return true
        FeatureToggleAggregate.RolloutStrategy.WHITELIST_ONLY:
            return flag.whitelist_account_ids.has(account_id)
        FeatureToggleAggregate.RolloutStrategy.PERCENTAGE_CANARY:
            if flag.whitelist_account_ids.has(account_id):
                return true
            # 确定性哈希散列
            var seed_str = account_id + ":" + flag.feature_key
            var bucket = int(abs(seed_str.hash())) % 100
            return bucket < flag.rollout_percentage

    return false

# 崩溃故障上报与熔断判定
static func report_feature_failure(
    flag: FeatureToggleAggregate.FeatureFlagEntry,
    max_tolerable_failures: int = 3
) -> Dictionary:
    flag.failure_count += 1
    if flag.failure_count >= max_tolerable_failures:
        flag.is_circuit_broken = true
        return {
            "circuit_broken": true,
            "feature_key": flag.feature_key,
            "msg": "特性 [%s] 崩溃次数超标 (%d)，已触发自动熔断回滚！" % [flag.feature_key, flag.failure_count]
        }
    return { "circuit_broken": false, "current_failures": flag.failure_count }
```

## 三、 金丝雀分流与熔断求解器 (`CanaryRolloutSolver`)

1. **双轨分流策略**：白名单账户强制命中；`PERCENTAGE_CANARY` 以账户确定性哈希取模百分比分流（100 样本 50% 灰度稳定落在 30~70 区间）；
2. **熔断自动保护**：`report_feature_failure` 连续崩溃超标即 `circuit_broken` 置位，之后任何账户均不再启用该特性，实现异常自动降级；
3. **调试热注入**：`FeatureDebugPipeline.apply_debug_command` 支持开发者控制台动态创建/调整特性策略与灰度百分比并即时热重载。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM37-003`（见归档库档案卷）。
