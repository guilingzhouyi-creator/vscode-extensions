# 后端架构需求表42（第四十二卷：旁路遥测数据总线、账户注册登录生命周期与留存统计系统）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**隐藏式旁路遥测总线 (Sidecar Telemetry Bus)、全生命周期账户行为漏斗 (Account Lifecycle Funnel)、在线留存时序分析与异常注销审计中枢**。系统必须满足：
> 1. **旁路异步无感采集 (Zero-Impact Sidecar Ingestion)**：
>    - 遥测总线作为旁路监听器，绝不阻塞主游戏循环或核心战斗逻辑；
>    - 采用内存环形缓冲区 (Ring Buffer)，批量异步刷盘或推流；
> 2. **账户全生命周期事件漏斗 (Account Lifecycle Event Pipeline)**：
>    - 完整追踪：`ACCOUNT_REGISTER_ATTEMPT` $\rightarrow$ `ACCOUNT_REGISTER_SUCCESS` $\rightarrow$ `LOGIN_AUTH_SUCCESS` $\rightarrow$ `CHARACTER_CREATE` $\rightarrow$ `ENTER_WORLD` $\rightarrow$ `HEARTBEAT_TICK` $\rightarrow$ `LOGOUT_NORMAL` / `SESSION_TIMEOUT_CRASH`；
> 3. **在线时长与用户留存指标计算器 (Retention & Session Duration Solver)**：
>    - 统计每日活跃时长 (DAU Session Length)、跨天留存率 (D1/D7/D30)、心跳丢失原因审计；
> 4. **单机离线本地聚合与联机上报双态自适应**：
>    - 单机离线模式下，数据保存在 `.kalar_telemetry` 本地时序数据库；联机状态下支持安全加密批量上传。

## 二、 遥测旁路环形缓冲与生命周期求解器 (`TelemetrySidecarEngine`)

```gdscript
# 脚本路径: res://core/domain/telemetry/telemetry_sidecar_engine.gd
class_name TelemetrySidecarEngine
extends RefCounted

var _event_ring_buffer: Array[TelemetryEventDTO] = []
var max_buffer_capacity: int = 1000

# 异步记录遥测埋点
func record_event(
    event_name: String,
    account_id: String,
    payload: Dictionary = {},
    current_utc: int = 0
) -> void:
    var evt = TelemetryEventDTO.new()
    evt.event_id = str(randi()) + "_" + str(current_utc)
    evt.event_name = event_name
    evt.account_id = account_id
    evt.timestamp_utc = current_utc
    evt.payload_attributes = payload

    _event_ring_buffer.append(evt)
    if _event_ring_buffer.size() > max_buffer_capacity:
        _event_ring_buffer.pop_front() # 溢出保护

# 提取未上传/未刷盘事件批次
func flush_events_batch() -> Array[TelemetryEventDTO]:
    var batch = _event_ring_buffer.duplicate()
    _event_ring_buffer.clear()
    return batch
```

## 三、 遥测旁路引擎与生命周期漏斗 (`TelemetrySidecarEngine`)

1. **旁路无感写入**：`record_event` 异步采集事件入环形缓冲区，容量溢出自动淘汰最旧条目，主流程零阻塞；
2. **批次冲刷重置**：`flush_events_batch` 批量提取缓冲事件并安全清空，适配单机本地时序库与联机批量上报双形态；
3. **生命周期漏斗**：`AccountLifecyclePipeline.track_stage_transition` 追踪注册 → 进世界 → 登出等阶段流转（`LifecycleStage` 枚举），并采集会话时长支撑留存统计。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM42-003`（见归档库档案卷）。
