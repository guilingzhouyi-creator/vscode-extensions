# 后端架构需求表34（第三十四卷：物质守恒物品销毁、熔炉焚化与炼金蚀化处置系统）

> [!IMPORTANT]
> **【系统定性与第一性原理】**：
> 本卷定义卡拉尔高魔世界引擎的**物理物质守恒定律 (Law of Conservation of Matter)、拒绝背包一键凭空销毁、特定空间设施销毁与炼金消耗性道具分解中枢**。系统必须满足：
> 1. **万物物质守恒定律 (Strict Matter Conservation)**：
>    - 真实物理世界中，任何物质无法凭空彻底湮灭；
>    - **严禁在随身背包界面中设计“一键直接删除物品/原地将衣服变没”的非物理作弊按钮**；
> 2. **三类合规物品销毁与处置途径 (Legitimate Disposal Pathways)**：
>    - **定居点公共焚化炉 / 铁匠熔炼炉 (Town Incinerator & Smelter)**：
>      - 玩家必须肉身前往铁匠铺高温熔炉或城镇垃圾焚化坑，投入废品进行物理熔解；
>      - 产出物：废弃炉渣 (SLAG_ASH) 与微量分解魔素尘埃 (MANA_DUST)；
>    - **便携式炼金强酸与蚀化道具 (Portable Chemical Acid & Solvent Items)**：
>      - 借助随身携带的消耗性道具（如【强效王水溶剂】、【虚空蚀化之尘】、【初阶分解法卷】）；
>      - 消耗一剂溶剂，对目标物品施加化学溶解，生成溶解残渣；
>    - **极端地质天灾深渊遗弃 (Environmental Lava / Void Pit)**：
>      - 站在火山口熔岩流、深不见底的地脉裂隙或深海悬崖边，将物品抛入不可逆环境；
> 3. **销毁二次确认与贵重物品保护锁 (Valuable Item Protection Lock)**：
>    - 绑定强化等级 $\ge +7$、带有符文插槽或史诗阶位以上的贵重物品，需输入二次安全口令方可执行熔炉销毁。

## 一、 物品处置设施与溶剂实体契约 (`ItemDisposalFacilityDTO`)

```gdscript
# 脚本路径: res://core/domain/disposal/item_disposal_facility_dto.gd
class_name ItemDisposalFacilityDTO
extends RefCounted

enum DisposalMethod {
    TOWN_HIGH_HEAT_FURNACE,  # 城镇高温熔炉/焚化炉
    PORTABLE_ACID_SOLVENT,   # 便携式强酸腐蚀溶剂
    ENVIRONMENTAL_LAVA_PIT   # 地质熔岩深渊裂隙
}

var method: DisposalMethod = DisposalMethod.TOWN_HIGH_HEAT_FURNACE
var facility_town_id: String = ""
var facility_pos: Vector2 = Vector2.ZERO
var max_operate_radius: float = 3.0

# 产物转换率 (质量守恒: 1.0kg 装备 -> 0.8kg 炉渣 + 0.2kg 尘埃)
var slag_ash_yield_ratio: float = 0.8
var mana_dust_yield_ratio: float = 0.2
```

## 二、 物品销毁求解器 (`MatterDisposalSolver`)

```gdscript
# 脚本路径: res://core/domain/disposal/matter_disposal_solver.gd
class_name MatterDisposalSolver
extends RefCounted

# 执行合规物质销毁
static func execute_disposal(
    player_pos: Vector2,
    facility: ItemDisposalFacilityDTO,
    target_item: RefCounted,
    solvent_item: RefCounted = null
) -> Dictionary:
    # 1. 途径检定
    if facility.method == ItemDisposalFacilityDTO.DisposalMethod.TOWN_HIGH_HEAT_FURNACE:
        if player_pos.distance_to(facility.facility_pos) > facility.max_operate_radius:
            return { "success": false, "code": "ERR_NOT_AT_FACILITY", "msg": "未在焚化炉或熔炼炉工作台旁，无法销毁" }

    elif facility.method == ItemDisposalFacilityDTO.DisposalMethod.PORTABLE_ACID_SOLVENT:
        if solvent_item == null:
            return { "success": false, "code": "ERR_NO_SOLVENT", "msg": "缺少便携式蚀化溶剂，无法溶解该物品" }

    # 2. 贵重物防误毁检定
    if target_item.get("is_locked", false):
        return { "success": false, "code": "ERR_ITEM_LOCKED", "msg": "该物品已加锁保护，禁止投入熔炉" }

    var mass = target_item.get("mass_kg", 1.0)
    var slag_weight = mass * facility.slag_ash_yield_ratio
    var dust_amount = int(mass * 10.0 * facility.mana_dust_yield_ratio)

    return {
        "success": true,
        "destroyed_item_id": target_item.get("item_id", ""),
        "yield_slag_kg": slag_weight,
        "yield_mana_dust": dust_amount,
        "msg": "物品已在高温与强酸中彻底分解转化为物质残渣"
    }
```

## 三、 物质守恒处置管线 (`MatterDisposalSolver`)

1. **禁原地删除**：无合规设施时 `execute_disposal` 返回 NO_DISPOSAL_FACILITY——物品严禁在背包中凭空消失，物质守恒为第一性约束；
2. **三大合规途径**：处置必须绑定 `ItemDisposalFacilityDTO` 设施（城镇高温熔炉 / 便携强酸 / 极端熔岩裂隙）并通过空间邻近检定；
3. **守恒转世产出**：`DisposalPipeline.process_item_disposal` 焚化原物品并生成炉渣（MATERIAL_SLAG_ASH）与魔素尘埃（MATERIAL_MANA_DUST），质量不灭只换形态；
4. **贵重安全锁**：高强化/史诗贵重物品须二次口令 `CONFIRM_DESTROY`，否则 VALUABLE_LOCK_ACTIVE 拦截防误毁。

**归档细则**：阶段 3 施工细则 `KALAR-DEV-2026-RM34-003`（见归档库档案卷）。
