## 二、 细粒度热重载广播状态机 (Subtable Hot-Reload FSM)

```gdscript
# 模块路径: res://backend/infrastructure/game_config.gd (扩展)
static func reload_subtable(subtable_name: String) -> void:
    var resolved = ConfigRouterEngine.resolve_table_name(subtable_name)
    _tables.erase(resolved)
    _load_single_table(resolved)
    EventBusCore.get_instance().emit_narrative_by_key("config/subtable_reloaded", "infrastructure", [resolved])
```
