```powershell
$GodotBin = if ($env:GODOT_BIN) { $env:GODOT_BIN } else { "godot" }
& $GodotBin --headless --path . --import
& .\scripts\ps1\test-run.ps1 -GodotBin $GodotBin
& .\scripts\ps1\check-gdscript.ps1 -Scope tests -GodotBin $GodotBin
& .\scripts\ps1\check-gdscript.ps1 -Scope backend -GodotBin $GodotBin
python .\scripts\py\audit_config.py --strict
python .\scripts\py\audit_test_coverage.py --strict
& .\scripts\ps1\audit-arch.ps1
& .\scripts\ps1\audit-all.ps1 -serial
& .\scripts\ps1\audit-docs.ps1 --baseline benchmarks/reports/docs_baseline.json
& .\scripts\ps1\bench-sweep.ps1 -Runs 3
```

全量测试除 runner 断言通过外，还要用 verbose 日志检查 ObjectDB、RID、资源泄漏和节点路径错误；基准报告必须含有效指标，空指标报告不算通过。
