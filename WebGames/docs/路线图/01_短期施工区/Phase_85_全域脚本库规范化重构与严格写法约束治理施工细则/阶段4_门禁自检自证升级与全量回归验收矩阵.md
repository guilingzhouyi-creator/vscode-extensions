## 一、 门禁引擎演进与自检自证护栏 (Gate Evolution & Post-Governance)

### 1.1 `audit_script_comment.py` 静态门禁引擎全面升级

将现存 Phase 75 旧门禁引擎升级为全仓长效静态审查引擎：

1. **扫描范围全域化**：
   - 纳入根目录 `scripts/sh/`、`scripts/ps1/` 以及 `WebGames/scripts/validate-mermaid.mjs`，消除盲区，覆盖全量 74 份脚本；
2. **六字段契约硬性看守**：
   - 强制断言 `模块归属`、`文件路径`、`架构定位`、`依赖与触发`、`职责说明`、`退出语义与设计依据` 六字段，对齐后端规范；
3. **等宽分隔线断言**：
   - 强制分隔线严格为 78 字符等宽集中分隔结构（`# ==============================================================================`）；
4. **语言特异性写法断言**：
   - PowerShell：强制检查包含 `[CmdletBinding()]`、`Set-StrictMode -Version Latest` 与 `$ErrorActionPreference = 'Stop'`；
   - Python：强制检查 0 个未声明类型签名的裸函数，强制 0 处裸 `except:`；
5. **未决标记与施工批次黑话禁令**：
   - 阻断 `TODO/FIXME/XXX/HACK` 等未决标记；
   - 阻断 `Phase \d+`、`P\d+\.\d+` 等历史施工黑话。

### 1.2 `audit_pair_parity.py` 同构双实现门禁深化

1. **换行符静态护栏**：
   - 增加对 `.ps1` 必须为 CRLF、`.sh`/`.py` 必须为 LF 的自动化阻断断言；
2. **根目录同构双实现纳管**：
