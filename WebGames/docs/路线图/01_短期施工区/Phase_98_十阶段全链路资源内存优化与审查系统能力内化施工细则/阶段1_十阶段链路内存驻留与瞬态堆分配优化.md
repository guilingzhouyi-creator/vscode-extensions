## 一、 数据结构设计与代码契约

### 1.1 快照所有权

`SessionFlowContextDTO.to_dto(deep_copy: bool = false)` 和 `from_dto(data: Dictionary, deep_copy: bool = false)` 提供浅/深两种传输语义。浅传输会共享嵌套字典和数组；持久化、跨所有者保留或可能在 DTO 后续被复用时，调用方必须选择深拷贝。

| 数据面 | 当前契约 | 所有权要求 |
| :--- | :--- | :--- |
| 标量会话字段 | 账号、角色、槽位、世界和阶段状态按值传输 | 调用方可独立保留标量结果 |
| 领域快照字典/数组 | 默认浅传输共享容器引用 | 仅在源对象生命周期内使用；跨生命周期必须深拷贝 |
| 深快照 | `deep_copy = true` 对嵌套字典和数组复制 | 后续复用 DTO 不得改变已交付快照 |

### 1.2 阶段缓存与停机队列

- `LifecycleStageHookRegistry` 按 `GameConfig.config_reload_version()` 缓存从 `session_stage_pipeline` 构建的阶段索引、别名与必需槽位；阶段别名仍以配置为真源。
- `GameLifecycleService` 注册停机描述符时按现有比较器就地插入，执行时直接遍历；本阶段不重新定义优先级方向。后续优先级方向以 Phase 99 阶段 3 的明确裁定为准。
- 不把 `to_dto(false)` 称为“只读”；GDScript 容器仍可变，所有权由调用约定保证。
