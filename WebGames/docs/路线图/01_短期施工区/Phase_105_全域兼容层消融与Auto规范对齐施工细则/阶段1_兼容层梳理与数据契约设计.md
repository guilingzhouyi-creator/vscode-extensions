## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

### 1. 导航直连契约模型
前端导航统一收敛至 `NavManager` 契约，彻底消融 `ViewRouter` 跳板：

```gdscript
# 模块路径: res://frontend/navigation/nav_manager.gd
# 契约说明: 前端各视图与返回按钮直接调用 NavManager
NavManager.get_instance().pop_screen(transition_type)
NavManager.get_instance().push_screen(screen_id, params, transition_type)
```

### 2. Boss 部位列表渲染复用数据契约
消除循环内瞬态 `HBoxContainer` 与 `Label` 频繁分配，采用节点池化与就地更新契约：

```gdscript
# 模块路径: res://frontend/views/combat_view/combat_subpanels.gd
# 契约结构: Boss 部位渲染就地刷新契约
class BossPartRowBinding extends RefCounted:
	var row: HBoxContainer
	var name_label: Label
	var hp_bar: ProgressBar
	var status_label: Label
```

### 3. 单源货币换算数据契约
```gdscript
# 模块路径: res://frontend/domain_boundary/mocks/mock_economy_service.gd
# 契约说明: 换算比率唯一读取 domains.currency
var gold_rate: int = GameConfig.get_int("domains.currency", "rates/gold", 10000)
var silver_rate: int = GameConfig.get_int("domains.currency", "rates/silver", 100)
```
