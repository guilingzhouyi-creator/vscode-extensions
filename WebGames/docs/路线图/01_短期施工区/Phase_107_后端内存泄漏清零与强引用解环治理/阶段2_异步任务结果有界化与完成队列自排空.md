# 施工细则：后端内存泄漏清零与强引用解环治理 —— 阶段2：异步任务结果有界化与完成队列自排空

> [!NOTE]
> **【施工目标】**：对 `AuxiliaryWorkerPool` 异步任务与结果缓存执行有界化治理。为 `_cached_results` 引入基于 FIFO 的容量预算控制（默认 64 项上限），杜绝大体量资源数据永久常驻；治理 `_completed_tasks` 完成队列，在回调通知完成后及时解绑 `callback` 闭包与大对象引用，阻断 DTO 链条式内存滞留。
> **施工开始日期**：2026-10-11

## 📌 第一性原理溯源指针

* **精准上游规范指针**：[AGENTS.md 工作区全局刚性公理](../../../../../AGENTS.md) §二.1、§三、§四.12
* **核心不变量约束断言**：
  - `Inv-MEM2-1 (结果缓存硬性容量预算)`：`_cached_results` 键值规模严格受控于 `max_cached_entries` 预算（默认 64 项），新增条目超限时必须按最旧插入顺序先出淘汰，严禁无上限单调增长；
  - `Inv-MEM2-2 (任务闭包与大对象即时解除)`：在 `_notify_task_finished` 触发回调完毕后，必须显式清空 `task.callback = Callable()` 与 `task.result_data = null`（若无持久化需求），防止闭包上下文连带常驻；
  - `Inv-MEM2-3 (队列有界缓冲与自愈)`：`_completed_tasks` 缓冲队列设置上限（默认 128 项），超限时自动弹出最旧项，保障非帧驱动模式下内存自愈。
* **防漂移最高指示**：严禁在单例服务中维护无淘汰机制的静态容器；异步回调必须保证闭包生命周期与任务完成时刻原子解绑。

## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

### 1. 结果缓存容量钳制与 FIFO 淘汰
在 `auxiliary_worker_pool.gd` 中维护缓存插入顺序列表与容量上限：

```gdscript
# 模块路径: res://backend/domains/persistence_protocol/auxiliary_worker_pool.gd
const DEFAULT_MAX_CACHE_ENTRIES: int = 64
const DEFAULT_MAX_COMPLETED_TASKS: int = 128

var _cached_results: Dictionary = {}
var _cache_keys_fifo: Array[String] = []
var _max_cache_entries: int = DEFAULT_MAX_CACHE_ENTRIES

func _cache_result(path: String, data: Variant) -> void:
	if _cached_results.has(path):
		_cached_results[path] = data
		return
	while _cache_keys_fifo.size() >= _max_cache_entries:
		var oldest_key := _cache_keys_fifo.pop_front()
		_cached_results.erase(oldest_key)
	_cached_results[path] = data
	_cache_keys_fifo.append(path)
```

### 2. 完成任务闭包与大对象解绑
在 `_notify_task_finished` 中执行回调后，即时解除闭包强引用：

```gdscript
# 模块路径: res://backend/domains/persistence_protocol/auxiliary_worker_pool.gd
func _notify_task_finished(task: AsyncLoadTask) -> void:
	if _running_tasks.has(task.task_id):
		_running_tasks.erase(task.task_id)

	# 1. 执行回调通知
	if task.callback.is_valid():
		var ok := (task.status == STATUS_COMPLETED)
		task.callback.call(ok, task.result_data, task.error_code)
		# 2. 回调执行完毕后立即解绑闭包，释放捕获的外部上下文与批处理 DTO
		task.callback = Callable()

	# 3. 完成队列防膨胀保护
	while _completed_tasks.size() >= DEFAULT_MAX_COMPLETED_TASKS:
		_completed_tasks.pop_front()
	_completed_tasks.append(task)
```
