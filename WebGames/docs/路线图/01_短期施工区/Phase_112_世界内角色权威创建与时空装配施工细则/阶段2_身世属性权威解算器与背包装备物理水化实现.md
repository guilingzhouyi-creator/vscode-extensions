## 一、 第一性原理与架构解耦契约

### 1. 权威身世轮盘与因果解算管线

解算器核心逻辑承载于 `AuthoritativeReincarnationSolver.resolve_reincarnation_package`：

```mermaid
sequenceDiagram
  autonumber
  participant Req as 请求契约 (RequestDTO)
  participant RNG as 确定性随机数 (DeterministicRNG)
  participant Solver as 解算核心逻辑 (Solver)
  participant Cfg as 角色创角配置 (core.json)
  participant Out as 装配字典 (ResultDict)

  Req->>Solver: 传入 AuthoritativeCharacterCreationRequestDTO
  Solver->>Solver: 种子收敛 (seed_val -> request_seed -> hash -> 1337)
  Solver->>RNG: DeterministicRNG.from_seed(effective_seed)
  Solver->>Cfg: 读取 authoritative_reincarnation.origins_pool
  RNG-->>Solver: 加权抽取身世 origin_id
  Solver->>Cfg: origin_race_map 映射种族 race_id 与 birth_region_map
  Solver->>RNG: 点数加权分配 6 维基础属性 (baseline=3, total=21)
  Solver->>Solver: 叠加身世加成并刚性钳制到 [1, 6]
  Solver->>RNG: 加权抽取因果正负天赋对 (paired_presets)
  Solver->>Solver: 推导生理机能与初始钱包概况
  Solver-->>Out: 输出权威组装字典包
```

### 2. 背包装备物理水化装配流水线

新手初始物资物理水化由 `StarterLoadoutDispatcher.hydrate_starter_loadout_into_profile` 完成：

1. **套件与物资读取**：根据角色的 `race_id` 查询 `domains.starter_loadout` 配置中的 `race_kit_map`，缺省回退至 `defaults/fallback_kit`（如 `KIT_HUMAN_DEFAULT`）；
2. **货币发放**：解析套件 `initial_gold`，累计写入 `profile.personal_resources["gold"]`；
3. **聚合根初始化**：实例化 `WearableInventoryAggregate`，绑定属主 `owner_account_id = profile.character_id`；
4. **物品实体水化**：
   - 循环前预先提取 `items.core` 中已登记物品原型，构建 $O(1)$ 哈希字典查找集（ADV-PRF-001）；
   - 提取各物品 `canonical_id`、`count`、重量与容积；
   - 逐项实例化 `ItemEntity` 并签发 `SRV_` 前缀权威 UID；
   - 若物品为武器且主手槽位空闲，优先装备进 `equipped_slots["MAIN_HAND"]`；其余物品塞入背包 `storage_items`（裸身容量为 0 时安全兜底防丢失）；
5. **双向原子写回**：调用 `inventory_agg.serialize()` 将深度数据同步写入 `profile.inventory`，将 `equipped_payloads` 写入 `profile.equipment`。
