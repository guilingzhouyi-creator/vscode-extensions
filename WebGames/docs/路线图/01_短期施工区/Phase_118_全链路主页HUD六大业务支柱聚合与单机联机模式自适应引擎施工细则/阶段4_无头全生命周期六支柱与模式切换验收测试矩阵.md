  - `Inv-LIFECYCLE-CLOSED-LOOP-2 (全链路生命周期闭环公理)`：必须完整覆盖十阶段生命周期序列（注册 ➔ 网关 ➔ 创角 ➔ 序章 ➔ HUD ➔ ESC ➔ 退出世界 ➔ 切换网关 ➔ 注销 ➔ 退出游戏），任一环节断裂一票否决；
  - `Inv-LIGHT-ASSET-PURITY-3 (轻资产快照纯度与无重资产污染公理)`：快照序列化 JSON 字符长度必须 $\le 4096$，且字典内绝对不能存在全量背包 items 或历史全量 log 数组；
  - `Inv-STORAGE-AIRTIGHT-GUARD-4 (存储路径物理气密拦截公理)`：尝试将单机存档写往非 `user://offline_vault/` 路径或携带 `..` 相对路径时，`SaveReadinessGuard` 必须 100% 触发阻断拦截；
  - `Inv-ZERO-RESIDUAL-TOKEN-5 (会话零残留与凭证脱敏公理)`：测试生命周期完成关机后，`AuthService.validate_token` 必须失效，内存会话与注册资源 100% 回收释放。
