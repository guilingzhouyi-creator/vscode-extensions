# 施工细则：存档与数据架构算法优化与瞬态分配消除 —— 阶段3：数据复制精简与深拷贝防御性开销消除

> [!NOTE]
> **【施工目标】**：消除核心路径上的过度防御性深拷贝与重复瞬态字典分配。在 `TertiaryTimelineEngine` 中建立静态紧张类型不可变负载缓存表，彻底消除时钟脉冲触发时反复分配 `{"tension_type": ...}` 字典的微小堆碎片；优化实体与数据载荷的序列化结构，规避空容器深度递归克隆。
> **施工开始日期**：2026-10-11

## 📌 第一性原理溯源指针

* **精准上游规范指针**：[AGENTS.md 工作区全局刚性公理](../../../../../AGENTS.md) §二.2、§三、§四.2
* **核心不变量约束断言**：
  - `Inv-ALG3-1 (静态载荷只读不可变复用)`：常见事件载荷字典（如各类型紧张度标记）必须在初始化或缓存区统一定义并只读复用，严禁每次事件实例化重复创建等价临时字典；
  - `Inv-ALG3-2 (空容器浅引用免拷贝)`：对未发生修饰的空集合（如空元素抗性表 `elemental_resistances`、空铭刻符文列表），在序列化与数据传输时严禁执行多层深度递归 `duplicate(true)`。
* **防漂移最高指示**：载荷内容与键值格式严格保持向后兼容。

## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

### 1. 时间轴静态负载字典复用表
在 `tertiary_timeline_engine.gd` 中：

```gdscript
# 模块路径: res://backend/domains/physics_thermodynamics/tertiary_timeline_engine.gd
static var _cached_tension_payloads: Dictionary = {
	"PRESSURE_SURGE": {"tension_type": "PRESSURE_SURGE"},
	"ENVIRONMENT_PULSE": {"tension_type": "ENVIRONMENT_PULSE"},
	"FORCE_ROUND_ADVANCE": {"tension_type": "FORCE_ROUND_ADVANCE"}
}

static func _get_tension_payload(type_key: String) -> Dictionary:
	if _cached_tension_payloads.has(type_key):
		return _cached_tension_payloads[type_key]
	var payload := {"tension_type": type_key}
	_cached_tension_payloads[type_key] = payload
	return payload
```

在 `_build_next_tension_event()` 中：
```gdscript
evt.payload = _get_tension_payload(selected_type)
```

### 2. 容器深拷贝保护
在 `ItemEntity` 序列化与克隆逻辑中，避免对空容器执行昂贵的深度递归遍历。
