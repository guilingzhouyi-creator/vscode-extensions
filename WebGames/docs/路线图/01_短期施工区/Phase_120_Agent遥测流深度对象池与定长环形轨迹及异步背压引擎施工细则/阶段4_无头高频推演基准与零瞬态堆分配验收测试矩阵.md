* **核心不变量约束断言**：
  - `Inv-ZERO-HEAP-ASSERT-1 (循环零堆分配硬性断言)`：在 1000 次原位切片求解与装箱循环中，活跃分配计数增量强制为 0（`ADV-PRF-002` 刚性守恒）；
  - `Inv-RING-ORDER-DETERMINISM-2 (轨迹时序单调保序断言)`：`get_trajectory_window(k)` 返回的 $k$ 个切片，其 `sequence_index` 与 `timestamp_ms` 必须严格单调递增，杜绝跨环乱序；
  - `Inv-BINARY-ROUNDTRIP-LOSSLESS-3 (二进制双向无损互逆断言)`：任何合法生成的遥测数据包，经 `encode_to_bytes` 紧凑序列化后再经 `decode_from_bytes` 反序列化，所有关键标量与差分必须 100% 差分等价；
  - `Inv-BINARY-SIZE-BUDGET-4 (二进制体积刚性包络断言)`：单包编码后的 `PackedByteArray.size()` 严格 $\le 256$ 字节，体积压缩率 $\ge 80\%$。
* **防漂移最高指示**：测试脚本禁止在 `tests/unit/` 根目录散落平铺，必须严格收口至 `tests/integration/pipelines/` 并登记入 `test_registry.gd`；断言失败必须输出清晰质性技术事实。

| **TC-ATH-06** | `test_async_dispatcher_backpressure_drop_oldest_strategy` | 队列超载（写入 200 包，容量 128），验证 `DROP_OLDEST` 策略 | 队列条数稳定收敛于 128，最旧帧被安全淘汰，队列头部对齐最新帧序列 | `Inv-ASYNC-BACKPRESSURE-SAFETY-4` |
| **TC-ATH-07** | `test_deterministic_test_mode_single_thread_synchronism` | 启用 `deterministic_mode = true`，派发遥测包 | 派发方法调用期间消费者同步收到回调，零异步延迟，零多线程竞态 | `Inv-DETERMINISTIC-TEST-MODE-5` |
| **TC-ATH-08** | `test_binary_telemetry_codec_roundtrip_lossless_equivalence` | 构建完整遥测包，执行 `encode_to_bytes` 再 `decode_from_bytes` | 反序列化还原的标量、比率、差分列表与行动指令与原包 100% 差分等价 | `Inv-BINARY-ROUNDTRIP-LOSSLESS-3` |
| **TC-ATH-09** | `test_binary_telemetry_size_budget_and_compression_ratio` | 计算标准遥测包的紧凑二进制字节流长度与 Dictionary 序列化对比 | `PackedByteArray.size() <= 256` 字节，相较于 JSON 字典压缩率 $\ge 80\%$ | `Inv-BINARY-SIZE-BUDGET-4` |
