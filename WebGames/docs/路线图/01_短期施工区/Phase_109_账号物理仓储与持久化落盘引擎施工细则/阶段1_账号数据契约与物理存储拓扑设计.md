## 📌 第一性原理溯源指针

* **精准上游规范指针**：[AGENTS.md 工作区全局刚性公理](../../../../../AGENTS.md) §二.1、§三、§四.1
* **核心不变量约束断言**：
  - `Inv-ACC-STORE-1 (账号契约单一真源)`：账号序列化与反序列化以 `AccountProfileAggregate.serialize()` 与 `AccountProfileAggregate.deserialize()` 为全域唯一事实来源，严禁存在未类型化字段漂移与自造权限；
  - `Inv-ACC-STORE-2 (物理拓扑隔离)`：账号仓储物理隔离收敛于 `user://accounts/` 拓扑域，严禁与常规世界存档目录 `user://saves/` 发生路径混淆与交叉污染；
  - `Inv-ACC-STORE-3 (双轨存储与自愈索引)`：全局索引表与独立账号分片构成双轨存储冗余，当全局索引表发生缺失或损毁时，底层引擎具备自扫描分片目录重构全局索引的确定性自愈能力；
  - `Inv-ACC-STORE-4 (配置驱动无硬编码)`：存储目录、文件名、临时后缀、备份后缀及保留策略全部经 `GameConfig` 从 `domains.account`（`config/domains/account/core.json`）读取，禁止代码内字面量写死。
* **防漂移最高指示**：严禁在代码中写死物理绝对路径；严禁跳过 AccountProfileAggregate 直接拼装裸 JSON 字典入库。

### 2. 物理目录拓扑结构与文件命名契约

账号物理存储采用「全局注册表主控 + 单账号分片隔离」的双轨拓扑结构：

```text
user://accounts/
├── account_registry.json         # 全局账号注册表（主索引表）
├── account_registry.json.bak     # 全局注册表备份（支持多版本轮转）
├── account_registry.json.tmp     # 原子写入临时中转文件
├── ACC_USR_1001.json             # 账号 ACC_USR_1001 独立分片数据
├── ACC_USR_1001.json.bak         # 账号 ACC_USR_1001 备份
├── ACC_USR_1002.json             # 账号 ACC_USR_1002 独立分片数据
└── ACC_GUEST_9999.json           # 游客账号独立分片数据
```

全局注册表 `account_registry.json` 信封顶层结构：

```json
{
  "format_version": "1.0.0",
  "engine": "KalarWorldEngine_Godot4",
  "updated_timestamp_utc": 1728630000,
  "account_count": 2,
  "accounts": {
    "ACC_USR_1001": { ... },
    "ACC_USR_1002": { ... }
  }
}
```

### 3. 配置单源收敛规范

在 `config/domains/account/core.json` 中扩展 `storage` 节点：

```json
{
  "storage": {
    "registry_file": "user://accounts/account_registry.json",
    "accounts_dir": "user://accounts/",
    "atomic_write": true,
    "backup_suffix": ".bak",
    "tmp_suffix": ".tmp",
    "backup_fail_policy": "abort",
    "backup_retention": 3,
    "auto_restore_enabled": true,
    "orphan_tmp_cleanup": true,
    "save_individual_shards": true,
    "max_account_id_length": 64,
    "format_version": "1.0.0"
  }
}
```
