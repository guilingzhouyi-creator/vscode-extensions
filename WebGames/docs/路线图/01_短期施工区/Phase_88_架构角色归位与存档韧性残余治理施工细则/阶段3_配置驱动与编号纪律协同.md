## 一、 配置与一致性协同内容

### 1.1 配置驱动（`A5` 能力开关）

| 配置路径 | 类型 | 默认值 | 消费者 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| `infrastructure.persistence → recovery/orphan_tmp_cleanup` | bool | true | `SaveManager._cleanup_orphan_tmp_files()` | 是否在启动/写档入口回收孤儿 `*.tmp` |
| `infrastructure.persistence → recovery/auto_restore_enabled` | bool | true | `SaveManager._fail_or_recover()` | 正档损坏时是否自动从 `.bak` 恢复并重读 |
| `messages.auto_restored` | string | `Primary save was corrupt; automatically restored from backup: %s` | `_fail_or_recover()` 告警出口 | 自动恢复留痕文案 |
| `messages.orphan_tmp_cleaned` | string | `Cleaned %d orphan temp save file(s) at startup.` | `_cleanup_orphan_tmp_files()` 告警出口 | 清理留痕文案 |

> 键与消费者一一对应，无死配置；文案统一经 `SaveManager._msg()` 出口读取，符合「用户可见文案出口归 service」契约。
