## 一、 `AGENT_INTERACTION.md` 刷新方案

### 1.1 增补主页 HUD 交互流转时序图
```mermaid
sequenceDiagram
    autonumber
    participant Agent as 外部决策 Agent / LLM
    participant Channel as AgentActionChannel (专属输入通道)
    participant Engine as 主页 HUD 运行时内核
    participant Bus as CompanionObserverBus

    Engine->>Engine: 聚合主页 HUD 权威快照与因果差分
    Engine->>Bus: 广播 agent_hud_packet_streamed 事件
    Engine-->>Agent: 下发标准原子遥测包 (AgentHudTelemetryPacketDTO)
    
    alt 人类前台正在交互 (is_writable=false)
        Agent->>Agent: 识别 control_lease.agent_control_mode="READ_ONLY_OBSERVER"
        Agent->>Agent: 挂起上行指令发射，保持纯粹只读观测
    else 处于空闲决策窗口 (is_writable=true)
        Agent->>Channel: 上行动作包 (AgentActionPacketDTO, directive_id, params)
        Channel->>Channel: 校验 sequence_index 与前置条件
        Channel->>Engine: 零硬件输入争抢，直投领域用例执行
        Engine->>Engine: 结算业务逻辑与状态突变
        Engine-->>Agent: 下发最新包含因果差分的遥测包
    end
```

### 1.2 增补 7 大动态行动空间指令规格表
详述 `ALLOCATE_POTENTIAL_STAT`, `REST_AND_ADVANCE_TIME`, `CLAIM_QUEST_OBJECTIVE`, `INSPECT_INVENTORY_SLOT`, `TOGGLE_MODE_ADAPTATION`, `MARK_MAIL_READ`, `DISMISS_UI_NOTICE` 的参数域、前置条件与阻断原因码。
