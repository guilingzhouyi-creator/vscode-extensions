### 1.2 B-2 运行时契约脱节（`Inv-P87-2`）

* `.github/workflows/godot-ci.yml`：在 Godot 安装步骤之后新增「固定 Python 版本（门禁脚本运行时契约）」步骤（`actions/setup-python@v5`，`python-version: '3.12'`），并修正全量审查聚合步骤名中的失实计数（「7 项 python 审计」→「20 项静态门禁」）。

### 1.3 B-3 入口路径不可移植（`Inv-P87-4`）

* 统一改写 11 个脚本的根目录解析：由 `ROOT_DIR="$(cd "$SCRIPT_DIR/../.." && pwd)"` 改为 `ROOT_DIR="$(cd "$SCRIPT_DIR/../.." && { pwd -W 2>/dev/null || pwd; })"`，并加行内注释说明 MSYS 与非 MSYS 双平台语义。
* 覆盖脚本：`test-run.sh`、`audit-all.sh`、`audit-arch.sh`、`audit-docs.sh`、`audit-perf.sh`、`bench-run.sh`、`bench-sweep.sh`、`check-gdscript.sh`、`check-mermaid.sh`、`package-webgames.sh`、`archive-volume.sh`。

### 1.4 B-4 引用语义误用（`Inv-P87-5`）

* `backend/infrastructure/game_config.gd:163`：`var old_tables: Dictionary = _tables` → `var old_tables: Dictionary = _tables.duplicate(true)`，并加注释说明引用类型别名导致的回滚失效与变更集恒空。
* 连带效果：`reload_config()` 的四个契约（原子交换 / 失败回滚 / 必需表拒发布后快照不被污染 / 变更集驱动缓存失效）恢复成立；`:205` 的空结果回滚分支由死代码恢复可达。

### 1.5 B-5 安全出口旁路（`Inv-P87-6`）

* `backend/infrastructure/error_reporter.gd`：`emit_error` 中 `record.context` 改为经 `RedactionRule.apply(context)` 产出，与规范链路 `LogCollector.log()` 对齐；消除「`ErrorReporter → EventBusCore.emit_log_record → LogFileExporter` 明文落盘」缺口。

### 1.6 防复发断言与测试

* `scripts/py/audit_script_comment.py`：新增规则 `PY-ANNOTATION-IMPORT`（`_check_py_annotation_bindings`）——AST 扫描注解引用的 typing 名字绑定完备性，声明 `from __future__ import annotations` 时免检；同步扩展该脚本六字段题头「职责说明」与模块 docstring。
* `tests/unit/infrastructure/test_editor_hot_reload.gd`：新增 `TC-SV-35`（变更集精准识别）与 `TC-SV-36`（拒绝发布时保留旧运行快照与版本），延续该套件既有 `TC-SV-17~27` 编号序列，不新建测试文件。
