### 2. `auth_service.gd` 孤立废弃枚举清理

```gdscript
# 模块路径: res://backend/domains/account/auth_service.gd
# 彻底移除未被引用的孤立枚举 AuthState
```

### 3. `world_recombination_stub.gd` 桩代码透明化
当配置开启且调用生成逻辑时，显式通过 `EventBusCore` 记录占位警告，防止上层误判：

```gdscript
# 模块路径: res://backend/domains/world_state/world_recombination_stub.gd
static func generate_new_world(default_template: Dictionary, history_worlds: Array[Dictionary], config: Dictionary = {}) -> Dictionary:
	var enabled: bool = bool(config.get("enabled", GameConfig.get_bool("domains.world", "continuity/enabled", false)))
	if not enabled:
		return {"success": true, "world": template.duplicate(), "mode": MODE_DEFAULT_ONLY}
	EventBusCore.get_instance().emit_log("warn", "WorldRecombinationStub: 多世界重组高级算法尚未完全落地，当前输出为模板合成占位数据")
```
