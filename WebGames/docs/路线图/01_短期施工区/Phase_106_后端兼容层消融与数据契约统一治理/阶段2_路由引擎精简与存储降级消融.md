## 一、 核心业务细类与算法实现 (Business Implementation & Solver)

### 1. `config_router_engine.gd` 52 条冗余别名消融
`_primary_aliases` 中仅保留实质非标准映射项，其余统一由通用规则自动补齐 `.core`：

```gdscript
# 模块路径: res://backend/infrastructure/config_router_engine.gd
static var _primary_aliases: Dictionary = {
	"domains.combat": "domains.combat.mechanics",
}
```

### 2. `config_route_dto.gd` 文档与注释对齐
更新 `RouteResolutionMode.DIRECT_PASSTHROUGH` 的说明文档，纠正对 `domains.inventory` 的错误描述：

```gdscript
# 模块路径: res://backend/infrastructure/config_route_dto.gd
enum RouteResolutionMode {
	DIRECT_PASSTHROUGH, # 未拆分子表直通（适用于未分级的通用基础设施表）
	EXACT_SUBTABLE,     # 精确匹配子表（如 "domains.combat.damage_formulas"）
	LEGACY_COMPAT_ALIAS # 历史平滑兼容别名（如旧单表访问 "domains.combat"）
}
```

### 3. `primary_storage_engine.gd` 状态提取规范化
在 `_extract_minimal_state` 中清理深层历史废弃字段回退，统一以规范字段为主导：

```gdscript
# 模块路径: res://backend/domains/persistence_protocol/primary_storage_engine.gd
var account_id: String = String(account_data.get("account_id", DEFAULT_ACCOUNT_ID))
var char_name: String = String(char_data.get("name", slot_id))
var world_mode: String = String(data.get("world_mode", DEFAULT_WORLD_MODE))
```

### 4. `authority_sync_stub.gd` 模式读取收敛
```gdscript
# 模块路径: res://backend/infrastructure/authority_sync_stub.gd
static func current_sync_mode() -> SyncMode:
	var mode_str: String = GameConfig.get_string("infrastructure.admin", "sync/mode", "offline_text")
	if mode_str == "online_authority" or mode_str == "online":
		return SyncMode.ONLINE_AUTHORITY
	return SyncMode.OFFLINE_TEXT
```
