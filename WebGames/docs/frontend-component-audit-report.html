审查总结

WebGames 前端组件层存在 "有组件但不用" 的核心问题：4 个 K-组件已实现，但 .tscn 场景引用率 0%，.gd 代码引用率仅 47%（KVirtualList 完全未引用）。同时 17 个视图中存在 10 类重复 UI 模式，合计 660-925 行可消除的重复代码。

现有 4 个组件平均质量 6.5/10，主要缺陷为：KBadge 信号断连不安全（内存泄漏风险）、KButton 缺少 hover/pressed 四态、KItemSlot 未接入 i18n、全部组件未接入 ThemeManager。KVirtualList 质量最高(8/10)但沦为僵尸组件。

建议按 Phase 1-4 路线图执行：先创建 3 个 P0 组件（KBackButton/KPageHeader/KTabBar）消除最高频重复，再创建 3 个 P1 组件（KSplitPanel/KStatusBar/KSearchBar），最后改进现有组件并激活 KVirtualList。完成后组件复用指数预计可从 58 提升至 85+。
