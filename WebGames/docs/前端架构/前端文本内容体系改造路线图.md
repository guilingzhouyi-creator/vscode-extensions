# 前端文本内容体系改造路线图

> **核心数据流**: 业务数据 → UI 配置中间体 → i18n Key/翻译 → Placeholder 填充 → 视觉 UI 渲染
>
> **铁律**: 后端不依赖显示文本; UI 不重复维护文案; 组件内不散落字符串拼接; i18n 不解决布局问题

---

| 维度 | 数量 | 说明 |
|---|---:|---|
| .tscn 硬编码 text | 712 处 | 全部 18 个场景文件 |

## 二、中间体层架构

### 2.1 四层架构

```
┌─────────────────────────────────────────────────────────┐
│                   UI 渲染层 (UI Render Layer)             │
│  Label / Button / RichTextLabel / ItemList / TabBar     │
│  职责: 仅渲染, 不做文本拼接、不做条件判断、不做数据格式化     │
└────────────────────────┬────────────────────────────────┘
                         │ final_text, visual_config
┌────────────────────────┴────────────────────────────────┐
│              可视化配置中间体 (Intermediary Layer)         │
│                                                         │
│  ┌──────────┐  ┌──────────────┐  ┌───────────────────┐ │
│  │ Resolver  │  │ Placeholder  │  │  Visual Adapter   │ │
│  │ (i18n 翻译) │  │ Filler (填充) │  │ (字号/换行/截断)   │ │
│  └──────────┘  └──────────────┘  └───────────────────┘ │
│  ┌─────────────────────────────────────────────────────┐│
│  │           Binding Registry (节点↔Key 绑定)            ││
│  └─────────────────────────────────────────────────────┘│
│  职责: 编排翻译→填充→适配, 但不含业务逻辑                  │
└────────────────────────┬────────────────────────────────┘
                         │ i18n_key, params, format_config
┌────────────────────────┴────────────────────────────────┐
│                 i18n 层 (i18n Layer)                     │
│  LocalizationSolver.translate(key, {param}) → template  │
│  职责: 语言转换, 不解决布局问题                             │
└────────────────────────┬────────────────────────────────┘
                         │ business_data, snapshot
┌────────────────────────┴────────────────────────────────┐
│              内容数据层 (Content Data Layer)              │
│  Mock JSON / EventBusCore Snapshots / GameConfig 配置表       │
│  职责: 提供原始数据, 不含展示逻辑                           │
└─────────────────────────────────────────────────────────┘
```

### 2.2 文件结构

```
frontend/i18n/
├── ui_text_resolver.gd       # i18n 翻译入口 (tr 函数)
├── placeholder_filler.gd     # 业务数据 → {param} 填充
├── visual_adapter.gd         # 动态视觉适配 (字号/换行/截断)
├── ui_binding_registry.gd    # 节点↔i18n Key 绑定注册表
└── ui_intermediary.gd        # 中间体编排层 (统一入口)

config/i18n/
├── zh_CN.json                # 扩展: 新增 ui.* 命名空间
└── en_US.json                # 扩展: 新增 ui.* 命名空间
```

### 2.3 各模块职责边界

| 模块 | 输入 | 输出 | 禁止 |
|---|---|---|---|
| **ui_text_resolver** | i18n key + params | 翻译后的模板字符串 | 数据格式化、布局调整 |
| **placeholder_filler** | 模板字符串 + 数据字典 | 填充后的最终文本 | 语言转换、业务判断 |
| **visual_adapter** | UI 节点 + 文本 + 空间约束 | 字号/换行/截断配置 | 修改文本内容 |
| **ui_binding_registry** | UI 节点 + i18n key | 绑定关系 + 刷新通知 | 翻译、填充 |
| **ui_intermediary** | 节点 + key + data + config | 注入到节点的最终渲染文本 | 业务逻辑、i18n 核心 |

### 2.4 i18n Key 命名规范

```
ui.<view_id>.<section>.<element>

示例:
ui.fe01.splash.logo           → "卡拉尔世界引擎"
ui.fe01.splash.status         → "正在初始化确定性母机…"
ui.fe01.login.title           → "账号登录"
ui.fe01.login.username_ph     → "请输入用户名"
ui.fe01.login.error_short     → "用户名长度需 ≥{min}字符"
ui.fe02.hud.status_bar.gold   → "金币: {amount}"
ui.fe02.hud.status_bar.mana   → "魔晶: {amount}"
ui.fe03.attributes.title      → "六维属性"
ui.fe03.attributes.str        → "力量 (STR)"
ui.fe04.combat.boss_name      → "BOSS 名称"
ui.fe05.wallet.total_value   → "总价值: {value} 铜币"
```

### 2.5 占位符规范

与后端 Phase 24 统一文案配置系统对齐, 采用 `{param_name}` 语义化占位符:

| 占位符 | 来源 | 示例 |
|---|---|---|
| `{min}` | 配置常量 | "用户名长度需 ≥{min}字符" |
| `{amount}` | 业务数据 | "金币: {amount}" |
| `{name}` | 业务数据 | "欢迎, {name}" |
| `{value}` | 格式化结果 | "总价值: {value} 铜币" |
| `{cur}` / `{max}` | 业务数据 | "HP: {cur} / {max}" |
| `{percent}` | 计算结果 | "完成度: {percent}%" |

### 2.6 视觉适配规则

| 规则 | 触发条件 | 适配动作 |
|---|---|---|
| 字号缩放 | 文本长度 > 容器宽度 × 0.9 | 逐级降字号 (20→18→16→14→12) |
| 自动换行 | 文本含空格且容器宽度 < 200px | autowrap = WORD_SMART |
| 省略截断 | 文本长度 > 容器宽度且无法换行 | ellipsis_char = "…" |
| CJK 适配 | locale 含 zh/ja/ko | 最小字号 14 (vs Latin 12) |
| 紧凑模式 | viewport < 800×600 | margins 减半, 字号 -2 |
| Tab 标题 | 文本长度 > 6 字符 | 字号降为 14 |

## 三、实施路线

### P0: 核心基础设施 (5 个文件)

| 文件 | 行数估 | 职责 |
|---|---:|---|
| `frontend/i18n/ui_text_resolver.gd` | ~120 | tr(key, params) 入口, 包装 LocalizationSolver |
| `frontend/i18n/placeholder_filler.gd` | ~100 | fill(template, data) + 格式化工具 |
| `frontend/i18n/visual_adapter.gd` | ~80 | adapt_label/adapt_button + viewport 监听 |
| `frontend/i18n/ui_binding_registry.gd` | ~100 | bind/unbind/refresh_all |
| `frontend/i18n/ui_intermediary.gd` | ~80 | resolve(node, key, data) 统一编排 |

### P1: i18n 词条扩展

扩展 `config/i18n/zh_CN.json` 和 `en_US.json`, 新增 `ui.*` 命名空间, 覆盖全部 17 系统的 UI 文案。

### P2: 逐系统迁移 (17 系统)

每个系统的迁移步骤:
1. 提取 .tscn 和 .gd 中所有硬编码文本
2. 为每个文本分配 i18n key
3. 在 zh_CN.json / en_US.json 中登记
4. .tscn 中 text 改为占位符 `{ui.fe01.splash.logo}`
5. .gd 中通过 `ui_intermediary.resolve()` 注入
6. 验证: 切换语言 → 全部文本变化

### 迁移优先级

| 批次 | 系统 | 硬编码数 | 复杂度 |
|---|---|---:|---|
| B1 | account_entry + main_hud | ~60 | 低 (已有 GameConfig 基础) |
| B2 | settings_center + character_progression | ~30 | 中 |
| B3 | combat + economy + guild_social | ~58 | 中 |
| B4 | world_map + quest + mail | ~50 | 中 |
| B5 | gacha + crafting + grimoire | ~75 | 高 |
| B6 | monster + notification + system_save + misc | ~125 | 高 |

## 四、验收标准

1. **零硬编码**: .tscn 和 .gd 中 0 处中文/英文直接文本 (除注释和 print)
2. **i18n 覆盖**: zh_CN.json 和 en_US.json 各含 ~500+ ui.* 词条
3. **语言切换**: 切换 locale 后全部 UI 文本即时变化
4. **占位符正确**: 所有 {param} 被正确填充, 无残留花括号
5. **视觉适配**: 不同窗口尺寸下文本不溢出、不截断关键信息
6. **零接线**: 不接 EventBusCore, i18n 数据来自配置表和 Mock
