## 一、 领域代码与实现细节 (Domain Implementation)

```gdscript
# 模块路径: res://core/vol21/stage1_数据结构与实体定义.gd
class_name ChatCommandParser extends RefCounted:
    static func parse(txt: String) -> Dictionary:
        if not txt.begins_with("/"): return { "is_cmd": false }
        var parts = txt.substr(1).split(" ", false)
        return { "is_cmd": true, "verb": parts[0].to_lower() if parts.size() > 0 else "" }
```
