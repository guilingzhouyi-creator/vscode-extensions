## 一、 核心模块拆解与重构设计

### 1. `headless_spatial_hash_grid_3d.gd` 克隆合并与嵌套降维
* **消除 3 处 AABB 网格坐标克隆（`HYG-CLN-001`）**：
  提取 `_compute_min_cell(center: Vector3, radius: float) -> Vector3i` 与 `_compute_max_cell(center: Vector3, radius: float) -> Vector3i` 两个纯值类型方法（`Vector3i` 为栈值类型，零堆分配），替代 `register_listener`、`unregister_listener`、`dispatch_spatial` 中重复 3 次的 6 行 `floori` 边界计算。
* **消解 `unregister_listener` 6 层嵌套（`CPX-NEST-001`）**：
  提取 `_remove_listener_from_cell(cell_key: Vector3i, listener_id: int) -> void` 处理单网格桶内逆序扫描与空桶回收，使外层三维网格遍历最大嵌套深度降至 **3 层**。
* **拆解 `dispatch_spatial` 圈复杂度（`CC=13` $\to$ $\le 6$）**：
  提取 `_collect_cell_candidates(cell_key: Vector3i, event_id: StringName, origin: Vector3) -> void` 与 `_deliver_candidate(idx: int, packet: RefCounted) -> int`，保持 `_visited_ids` 与 `_candidate_indices` 预分配缓冲池零堆分配。

### 2. `contract_completeness_guard.gd` 极值圈复杂度（CC=18）与克隆消除
* **消除 4 处状态记录字典克隆（`HYG-CLN-001`）**：
  提取 `_make_domain_detail(status: String, reason: String, scripts: int, methods: int) -> Dictionary` 统一构造 `INFRA`、`MISSING`、`COVERED` 审计条目。
* **拆解 `audit_domain_coverage`（`CC=18` $\to$ $\le 5$）**：
  拆分为 `_classify_single_domain(domain: String) -> Dictionary` 与 `_collect_domain_names(scan_dir: DirAccess) -> Array[String]`，主流程仅负责聚合计数与生成报告字典。

### 3. `item_registry_solver.gd` 极值圈复杂度（CC=17）与静态类型收敛
* **拆解 `register_prototype`（`CC=17` $\to$ $\le 6$）**：
  提取 `_validate_prototype_identity(proto: ItemPrototype, trace_id: String) -> Result`（校验非空、`item_id` 格式、命名空间与显示名）与 `_validate_prototype_numeric_bounds(proto: ItemPrototype, trace_id: String) -> Result`（校验 `max_stack`、`base_value`、`rarity` 范围及重复注册）。
* **补齐静态类型（`GOV-TYP-001`）**：
  将 `resolve_by_namespace` 中的 `var key = ...` 改为 `var key: String = str(k)`，将 `validate_batch_load` 中的 `var proto = ...` 改为 `var proto: ItemPrototype = ...`。
