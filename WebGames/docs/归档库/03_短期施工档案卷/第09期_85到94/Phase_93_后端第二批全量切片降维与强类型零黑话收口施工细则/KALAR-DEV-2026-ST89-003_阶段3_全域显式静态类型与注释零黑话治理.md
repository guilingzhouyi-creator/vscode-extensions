## 一、 强类型与注释净化转换规范

1. **动态 Variant 显式标注模式**：
   - `var raw = dict.get("key")` $\rightarrow$ `var raw: Variant = dict.get("key")`
   - `var item = arr[idx]` $\rightarrow$ `var item: Variant = arr[idx]`
   - `var result = null` $\rightarrow$ `var result: Variant = null`
2. **静态类型推导模式**：
   - `var count = 0` $\rightarrow$ `var count := 0`
   - `var entries = []` $\rightarrow$ `var entries := []`
3. **注释批次黑话净化模式**：
   - 剥离行内与题头注释中的 `Phase 01` ~ `Phase 91`、`P01` ~ `P91`、`S1-01` 等批次编号，统一收敛为领域第一性原理描述。
