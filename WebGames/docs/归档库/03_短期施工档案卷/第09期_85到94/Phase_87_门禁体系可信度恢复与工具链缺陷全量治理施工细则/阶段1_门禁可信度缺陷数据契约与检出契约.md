* **核心不变量约束断言**：
  * `Inv-P87-1 (门禁可运行性)`：任一注册门禁脚本必须可被 `python -m py_compile` 通过，且模块导入期不抛异常；门禁脚本崩溃**不得**与「审查未通过」共用同一可观测语义（崩溃须自证为崩溃）。
  * `Inv-P87-2 (运行时契约显式化)`：脚本头声明的运行时版本必须由 CI 显式固定（`actions/setup-python`），禁止隐式依赖 runner 默认解释器。
  * `Inv-P87-3 (注解名字绑定完备性)`：`.py` 注解引用的 typing 名字必须已绑定（模块级导入或任意作用域导入），或声明 `from __future__ import annotations`。
  * `Inv-P87-4 (入口路径可移植性)`：凡将路径外传给原生可执行程序（`godot.exe` / `python3.exe`）的脚本，必须经 `pwd -W` 归一并提供非 MSYS 平台回退；禁止裸 POSIX `/c/...` 路径外传。
  * `Inv-P87-5 (热重载快照隔离)`：`GameConfig.reload_config()` 的旧快照必须与运行快照物理隔离；失败路径必须真实回滚（旧表可用）且版本号不推进；成功路径变更集必须能反映真实差异。
  * `Inv-P87-6 (脱敏出口完备性)`：任何进入 `EventBusCore.emit_log_record` 的记录，其 `context` 必须已完成构造期脱敏——不得存在绕过 `RedactionRule` 的发射旁路。
  * `Inv-P87-7 (文档数字可复现)`：质量现状类数字必须由可复现命令口径产出，且与门禁口径（如 `audit_config.py`）一致；禁止人工维护易变数字。
* **防漂移最高指示**：本卷**严禁**放宽任何既有门禁规则、**严禁**修改基线文件消音新增违规、**严禁**新建门禁/护栏文件（新增断言必须归并演进至既有同域门禁或护栏）；所有改动必须保持 768 项既有断言全通过。
