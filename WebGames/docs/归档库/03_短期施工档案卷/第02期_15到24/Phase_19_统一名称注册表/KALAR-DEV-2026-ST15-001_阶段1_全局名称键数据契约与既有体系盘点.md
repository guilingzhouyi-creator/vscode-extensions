| # | 既有机制 | 位置 | 能力现状 | 缺口 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **物品名称三元组**：canonical_id / numeric_id / english_name（小写归一）+ `loc_name_key` | `item_namespace_registry/`（ItemNamespaceRegistry + ItemLoaderPipeline + ItemRegistryCatalog + ItemRegistrySolver） | 键体系完整；`loc_key_to_canonical` 已做**物品域内名称键冲突检测**（`name_key_collision`） | 名称键仅物品域内唯一，未全局化；`loc_name_key` 未接入 i18n 解析 |

| 3 | **i18n 词库**：`LocalizationRegistryCatalog` | `localization_i18n/localization_registry_catalog.gd` | `register_translation(locale, loc_key, template)` / `load_locale_dict(locale, dict)`；`current_locale`/`fallback_locale`（默认 zh_CN / en_US） | 词典为空壳（无任何登记表）；`loc_key` 注释示例（`item.iron_sword.name`）与名称键体系命名一致但未统一定义 |
| 4 | **i18n 解析**：`LocalizationSolver.translate` | `localization_solver.gd` | **通用 loc_key 解析已存在**：locale 词典 → fallback_locale 回退 → 参数插值 → `[key]` 兜底 | 无 `resolve_name_key` 便捷入口；未登记时仅返回 `[key]` 无告警留痕；无「英文兜底必达」校验 |
| 5 | **语言切换热推**：`I18nHotReloadPipeline.switch_language` | `i18n_hot_reload_pipeline.gd` | 全局语言切换 + 热更新 + 界面刷新推流 | 与名称键体系无接线（名称解析应走同一 catalog） |

## 二、 数据契约定义（全局名称键规范）

### 2.1 全局名称键 GlobalNameKey

```
<域>.<条目>.<字段>
```

- **域（domain）**：既有领域短名，与 `config/domains/*.json` 表名对齐（`item` / `magic` / `monster` / `quest` / `npc` / `elite` / `combat` / `account` …）；新域须在 `audit_docs.py NAMING_RULES` 或名称键校验清单登记；
- **条目（entry）**：该域内 canonical 条目标识（物品 canonical 名 / 魔法 rank key / 怪物 id / 任务 id …），小写归一、禁中文、禁空格；
- **字段（field）**：`name` / `title` / `desc` / `prefix` / `suffix` …（语义自描述，全小写）；
- **键值唯一性**：同一 GlobalNameKey 在全库**至多登记一次**（物品域已由 `loc_key_to_canonical` 保证，全局化后跨域唯一）；
- **英文唯一 fallback**：`en_US` 词典必须覆盖全部已登记名称键（audit 校验必达）；`en_US` 值 = 机器可读英文名，`zh_CN` = 展示中文名。

### 2.2 resolve_name_key 解析契约（新增于 LocalizationSolver）

```
resolve_name_key(catalog, key, locale_override = "") -> String
```

解析链：`locale 词典查表` → `fallback_locale 回退` → `英文兜底（en_US 词典）` → `未登记：[key] 原样返回 + 未登记告警计数（warn 级留痕，不抛 Fatal）`。

- 名称键不得作为逻辑判断依据（延续既有约定）；逻辑层永远引用 GlobalNameKey（英文键），显示层才 resolve；
- 未登记告警：`LocalizationSolver.missing_name_keys` 静态计数可查询（遥测/审计用）。

### 2.3 登记与校验

- 登记：`localization_registry_catalog.gd` 新增 `register_name_key(key, en_name, zh_name)` 便捷方法（内部写入 `en_US`/`zh_CN` 词典 + 登记键集合）；
- 校验（audit 新增）：名称键唯一性（全库无重复登记）、英文 fallback 必达（en_US 覆盖 100%）、键格式三段规范、禁中文入键（键本体 100% 英文）。
