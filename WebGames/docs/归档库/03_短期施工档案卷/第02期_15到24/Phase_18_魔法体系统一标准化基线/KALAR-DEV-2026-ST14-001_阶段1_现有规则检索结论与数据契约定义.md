## 二、 魔法体系统一数据契约（英文规范化标识）

```gdscript
# 模块路径: res://backend/domains/item_namespace_registry/magic_tier_snapshot.gd
class_name MagicTierSnapshot extends RefCounted
# 施法形态（复用既有 MagicForm 语义，英文枚举唯一规范）
enum MagicForm { PRIMORDIAL, INCANTATION, INTEGRATED, SUPERTIER }
# 魔法资质（复用既有 ManaAptitude 四档，英文枚举唯一规范）
enum ManaAptitude { MANA_ADAPTOR, WORD_SPEAKER, AWAKENED, HEAVEN_RULER }
# 位阶魔法四等十一阶（用户纠正：异能 1-3 / 英雄 4-6 / 神圣 7-9 / 真神 10-11；仅咒术法式内部）
enum MagicRank {
	MORTAL_1, MORTAL_2, MORTAL_3,   # 异能级 1~3 阶（用户亦称「普通」）
	HEROIC_1, HEROIC_2, HEROIC_3,   # 英雄级 4~6 阶
	DIVINE_1, DIVINE_2, DIVINE_3,   # 神圣级 7~9 阶
	GOD_1, GOD_2,                   # 真神级 10~11 阶（神级/超位）
}
# 施法者战斗实力称号（独立维度，13 级单调；前三档为魔术师 = 非魔法范畴）
enum ProfessionRank {
	THIRD_RATE_TRICKSTER,   # 三流魔术师（魔术 ≠ 魔法）
	SECOND_RATE_TRICKSTER,  # 二流魔术师（魔术 ≠ 魔法）
	QUASI_MAGIC_USER,       # 准魔法使/师
	NOVICE_MAGE,            # 初级魔士
	INTERMEDIATE_MAGE,      # 中级魔士
	SENIOR_MAGE,            # 高级魔士
	PLATINUM_MAGE,          # 铂金魔士
	GOLD_MAGE,              # 黄金魔士
	STELLAR_MAGE,           # 星辉魔士
	LEGION_MAGISTRATE,      # 军魔导士
	ROYAL_MAGISTRATE,       # 王魔导士
	HOLY_ARCHMAGE,          # 圣魔导师（对齐既有 ARCHMAGE 职业）
	PRIMORDIAL_ARCHDEMON,   # 始源魔神（对齐 MagicForm.PRIMORDIAL）
}
```

**契约边界（含用户纠正修订）**：

- 魔法体系 = 形态（4）+ 资质（4 档）+ 位阶（**四等十一阶**）+ 实力称号（13 级）四个**独立维度**；每维度各自单调（不跨维度合并）；
- **魔术/魔法边界**：魔术（戏法、非灵能）**不属于魔法范畴**；「三流/二流魔术师」为战斗实力称号维度的非魔法低端档位，不进入魔法位阶体系；
- **资质门槛与稀有度**：修炼魔法**必须具备魔适者（MANA_ADAPTOR）体质**（必要门槛）；言灵者/觉醒者/天权者亦可修炼且资质更强；四档稀有度——魔适者 ≥1/100、言灵者 ≥1/10000、觉醒者 ≥1/1000000、天权者未指定（配置驱动）；
- 位阶等级序（用户纠正）：1-3 阶 = 异能级（普通）、4-6 阶 = 英雄级、7-9 阶 = 神圣级、10-11 阶 = 真神级（神级/超位）；魔法级别从高到低：神级（超位）→ 神圣级 → 英雄级 → 异能级；
- `spell_tier` 正式枚举化映射至 `MagicRank`（默认 MORTAL_1）；后端字段/ID/Key/枚举一律英文，显示名走 `name_key`（如 `magic.rank.divine_2` / `magic.profession_rank.holy_archmage`）由 i18n 层映射中文。
