## 一、 与物品品质体系的映射判定（维度边界声明）

| 维度 | 归属体系 | 档位 | 判定 |
| :--- | :--- | :--- | :--- |
| 物品品质 `QualityTier` | Phase 17 物品体系 | COMMON~ANCIENT 6 档 | **物品维度**（稀有度/强度权重基线） |
| 施法形态 `MagicForm` | 魔法体系 | 4 形态 | **施法方式维度**（相变损耗/咏唱模型） |
| 魔法资质 `ManaAptitude` | 魔法体系 | 4 档有序 | **天赋资质维度**（魔适者为修炼门槛 + 四档稀有度） |
| 位阶魔法 `MagicRank` | 魔法体系 | 四等十一阶（异能 1-3 / 英雄 4-6 / 神圣 7-9 / 真神 10-11） | **法术规模等级维度**（句子规模法式；真神=神级/超位） |
| 战斗实力 `ProfessionRank` | 魔法体系 | 13 级称号（三流魔术师→始源魔神） | **施法者实力维度**（前三档魔术师 = 非魔法范畴） |

**映射判定结论（写入基线规范）**：

1. **无严格一一映射**：魔法体系（施法者/法术维度）与物品品质体系（物品维度）属不同概念域，**不得强行建立映射**；
2. **仅允许参考关系（Reference-only）**：
   - 魔法物品（`MANA_CRYSTAL` / `MANUSCRIPT_GRIMOIRE` / 法杖类装备）的品质用 Phase 17 `QualityTier` 标注——物品维度正交叠加于魔法体系之上；
   - 法术强度数值尺度可参考 `QualityTier.strength_weight`（1.0~5.0）作为基线参考值，非映射换算；
3. **维度拆分强制**：形态/资质/位阶/实力称号为四个独立维度，任何一处不得将其压缩为单一等级（如不得用资质档位代替位阶等级、不得用实力称号代替位阶、不得将魔术师档位并入魔法位阶）；
4. **既有冲突项保留域内语义**：「阶位」「tier」多义词汇在各自域内自洽，本基线以 `MagicRank` 为魔法等级唯一术语，其余在文档明确区分不合并。

## 二、 核心业务细类与算法实现 (Business Implementation & Solver)

```gdscript
# 模块路径: res://backend/domains/item_namespace_registry/magic_tier_registry.gd
class_name MagicTierRegistry extends RefCounted
const CONFIG_TABLE: String = "domains.magic_tiers"

var _ranks: Dictionary = {}             # rank(int) -> {name_key, strength_weight, phase_loss_range, ...}
var _aptitudes: Dictionary = {}         # aptitude(int) -> {name_key, backfire_threshold}
var _forms: Dictionary = {}             # form(int) -> {name_key, phase_loss_min, phase_loss_max}
var _ready: bool = false

func reload_configuration() -> void:
	_ranks = GameConfig.get_dict(CONFIG_TABLE, "rank_tiers", {})
	_aptitudes = GameConfig.get_dict(CONFIG_TABLE, "mana_aptitudes", {})
	_forms = GameConfig.get_dict(CONFIG_TABLE, "magic_forms", {})
	_ready = _validate_invariants()

## 不变量：位阶四等十一阶严格单调；真神（GOD_1/GOD_2）仅与超位形态从属；资质四档有序；实力称号 13 级单调
func _validate_invariants() -> bool:
	# 位阶等级值严格连续递增（1~11：异能 1-3 / 英雄 4-6 / 神圣 7-9 / 真神 10-11）
	var rank_levels: Array[int] = []
	for rank in _ranks:
		rank_levels.append(int(_ranks[rank].get("level", 0)))
	rank_levels.sort()
	for i in range(rank_levels.size()):
		if rank_levels[i] != i + 1:
			return false
	# 资质阈值严格递增
	var thresholds: Array[int] = []
	for a in _aptitudes:
		thresholds.append(int(_aptitudes[a].get("backfire_threshold", 0)))
	thresholds.sort()
	for i in range(thresholds.size() - 1):
		if thresholds[i] >= thresholds[i + 1]:
			return false
	return true

func is_ready() -> bool:
	return _ready

func get_rank_baseline(rank: int) -> Dictionary:
	return _ranks.get(rank, {})

func get_aptitude_baseline(aptitude: int) -> Dictionary:
	return _aptitudes.get(aptitude, {})

func get_form_baseline(form: int) -> Dictionary:
	return _forms.get(form, {})

# 模块路径: res://backend/domains/item_namespace_registry/magic_baseline_resolver.gd
class_name MagicBaselineResolver extends RefCounted
var _registry: MagicTierRegistry

func _init(registry: MagicTierRegistry) -> void:
	_registry = registry

## 确定性解析：法术声明（形态 + 位阶 + 资质）→ 统一基线快照；非法声明优雅拦截
## - 从属不变量：真神位阶（GOD_1/GOD_2）必须配对 MagicForm.SUPERTIER；
## - 未登记位阶/形态/资质 → 对应 UNREGISTERED_* 错误码（不产生基线消费）。
func resolve(magic_form: int, magic_rank: int, mana_aptitude: int) -> Dictionary:
	if not _registry.is_ready():
		return {"success": false, "code": "REGISTRY_NOT_READY"}
	if (magic_rank == MagicTierSnapshot.MagicRank.GOD_1 or magic_rank == MagicTierSnapshot.MagicRank.GOD_2) \
			and magic_form != MagicTierSnapshot.MagicForm.SUPERTIER:
		return {"success": false, "code": "SUPERTIER_FORM_MISMATCH"}
	var rank_bl: Dictionary = _registry.get_rank_baseline(magic_rank)
	if rank_bl.is_empty():
		return {"success": false, "code": "UNREGISTERED_RANK"}
	var form_bl: Dictionary = _registry.get_form_baseline(magic_form)
	if form_bl.is_empty():
		return {"success": false, "code": "UNREGISTERED_FORM"}
	return {
		"success": true,
		"magic_form": magic_form,
		"magic_rank": magic_rank,
		"mana_aptitude": mana_aptitude,
		"strength_weight": rank_bl.get("strength_weight", 1.0),
		"phase_loss_min": form_bl.get("phase_loss_min", 0.0),
		"phase_loss_max": form_bl.get("phase_loss_max", 0.0),
		"backfire_threshold": _registry.get_aptitude_baseline(mana_aptitude).get("backfire_threshold", 1),
	}
```

**既有消费方对齐（本卷只读接线，行为零变化）**：

| 既有实现 | 对齐动作 |
| :--- | :--- |
| `lifecycle_solver.evaluate_mana_backfire_risk(sheet, spell_tier)` | `spell_tier` 语义对齐 `MagicRank` 枚举值（等级 1~11），阈值读取改经资质基线（行为等价） |
| `physical_verb_registry.MagicForm` / `thermodynamics_solver` 相变能损 | 形态枚举与相变损耗区间以 `magic_forms` 配置为唯一事实源（数值不变） |
| `multi_profession_engine` 职业 `rank_tier` / `ARCHMAGE` | 职业位格（独立维度）保持，不做位阶换算；`HOLY_ARCHMAGE`（圣魔导师）与既有 ARCHMAGE 职业语义对齐声明（实力称号第 12 级） |
