## 一、 实现设计（新增叙事事件流域，复用既有基建）

### 1.1 NarrativeFlowResolver（剧情事件流解析器，新类）

```gdscript
class_name NarrativeFlowResolver
extends RefCounted

## 未填充参数告警计数（遥测/审计只读，禁业务分支）
static var missing_params_count: int = 0

## 事件流解析：narrative.<域>.<事件流ID> → 配置模板 → {param} 填充
static func resolve_flow(
	domain: String,
	flow_id: String,
	params: Dictionary = {},
	locale_override: String = ""
) -> Dictionary:
	var table_name := "narratives." + domain
	var template: String = str(GameConfig.get_dict(table_name, flow_id, ""))
	if template.is_empty():
		return {"success": false, "code": "FLOW_NOT_FOUND", "domain": domain, "flow_id": flow_id}
	# 占位符未填充校验：扫描 {param} 全部出现于 params（缺失 → 拦截 + 告警）
	var missing := _missing_params(template, params)
	if not missing.is_empty():
		missing_params_count += missing.size()
		return {"success": false, "code": "MISSING_PARAMS", "flow_id": flow_id, "missing": missing}
	# 复用 i18n 插值管线（{param} 语义化，Phase 19 已验证）
	var text := LocalizationSolver.translate(
		LocalizationRegistryCatalog.get_shared(), "narrative." + domain + "." + flow_id,
		params, locale_override)
	if text.begins_with("["):
		# 名称键未登记时兜底直接模板填充（配置模板即事实源）
		text = _fill(template, params)
	return {"success": true, "flow_id": flow_id, "text": text}

static func _missing_params(template: String, params: Dictionary) -> Array:
	var missing: Array = []
	for m in RegEx.create_from_string(r"\{([a-z_][a-z0-9_]*)\}").search_all(template):
		var name := m.get_string(1)
		if not params.has(name):
			missing.append(name)
	return missing

static func _fill(template: String, params: Dictionary) -> String:
	var text := template
	for k in params.keys():
		text = text.replace("{" + str(k) + "}", str(params[k]))
	return text
```

- **复用**：`{param}` 插值优先经 `LocalizationSolver.translate`（名称注册表可解析时走词典，未登记时兜底直接模板填充）——与 Phase 19 统一；
- **未填充拦截**：缺失参数 → `MISSING_PARAMS` + `missing_params_count` 计数（不输出残留 `{param}`/`%s`）。

### 1.2 事件流会话状态机（热重载零打断）

```gdscript
## 事件流会话：热重载时按 flow_id 保持触发状态，仅刷新文案模板
class_name NarrativeFlowSession
extends RefCounted

var flow_id: String = ""
var has_triggered: bool = false
var triggered_timestamp_utc: int = 0

## 热重载迁移：新会话继承旧会话触发状态（按 flow_id 匹配，文案自动用新配置）
static func migrate_on_reload(old_sessions: Array, flow_ids: Array) -> Array:
	var new_sessions: Array = []
	for fid in flow_ids:
		var s := NarrativeFlowSession.new()
		s.flow_id = fid
		for old in old_sessions:
			if old.flow_id == fid:
				s.has_triggered = old.has_triggered
				s.triggered_timestamp_utc = old.triggered_timestamp_utc
				break
		new_sessions.append(s)
	return new_sessions
```

- 与既有 `NarrativeEventAggregate.has_triggered/triggered_timestamp` 语义一致；热重载后事件流**触发状态保持、文案模板刷新**（零打断）；
- 既有 `NarrativeCausalityOrchestrator`（AST 求值/仲裁/派发）零改动——文本生成出口改为 `NarrativeFlowResolver.resolve_flow`。

### 1.3 热切换接线

| 触发点 | 动作 |
| :--- | :--- |
| `GameConfig.reload()` | 事件流解析器下次查询自动读取最新配置（每次 `GameConfig.get_dict` 实时读取，零缓存失配）；会话表经 `NarrativeFlowSession.migrate_on_reload` 重建 |
| `I18nHotReloadPipeline.switch_language` | 语言切换后 `resolve_flow` 的 `locale_override` 自动生效（文本即时切换） |
| 剧情触发（因果编排派发后） | 文本生成统一走 `NarrativeFlowResolver.resolve_flow`（禁直接 `%` 格式化） |

### 1.4 %s → {param} 迁移（文案与消费方）

| 存量 | 迁移动作 |
| :--- | :--- |
| `config/narratives/*.json` 全部 `%s`/`%.1f`/`%d` 模板 | 改写为 `{param}` 语义化（`{attacker}`/`{target}`/`{skill_name}`/`{damage}`/`{remaining_hp}`），S1-02 全量归零 |
| 代码消费方（`%` 格式化剧情文本处） | 改 `NarrativeFlowResolver.resolve_flow` 传参填充；占位符参数与文案语义绑定（禁位置依赖） |
