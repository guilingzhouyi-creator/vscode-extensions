## 一、 实现设计（新增描述解析器，消费已注册物品）

### 1.1 ItemDescriptionResolver（物品描述解析器，新类）

```gdscript
class_name ItemDescriptionResolver
extends RefCounted

## 描述未填充参数告警计数（遥测/审计只读）
static var missing_params_count: int = 0

## 描述解析：基于已注册物品 + 状态 → 模板条件组合 → {param} 填充
## 唯一入口：canonical_id 必须存在于 ItemRegistryCatalog（禁独立身份空间）
static func resolve(
	catalog: ItemRegistryCatalog,
	canonical_id: String,
	state: Dictionary = {},
	locale_override: String = ""
) -> Dictionary:
	var proto = catalog.lookup_canonical(str(canonical_id))
	if proto == null:
		return {"success": false, "code": "UNREGISTERED_ITEM", "canonical_id": canonical_id}
	# 模板选择：按状态条件组合（quality_tier / quantity / durability / enchant …）
	var template := _select_template(canonical_id, state)
	if template.is_empty():
		return {"success": false, "code": "DESC_TEMPLATE_MISSING", "canonical_id": canonical_id}
	# 状态注入：已注册属性 + 状态派生（占位符参数语义化）
	var params := _build_params(proto, state)
	var missing := _missing_params(template, params)
	if not missing.is_empty():
		missing_params_count += missing.size()
		return {"success": false, "code": "MISSING_PARAMS", "canonical_id": canonical_id, "missing": missing}
	var key := "item." + canonical_id + ".desc"
	var text := LocalizationSolver.resolve_name_key(
		LocalizationRegistryCatalog.get_shared(), key, locale_override)
	if text.begins_with("["):
		text = _fill(template, params)  # 名称键未登记时兜底模板直接填充
	return {"success": true, "canonical_id": canonical_id, "text": text}
```

- **不绕过注册系统**：`resolve` 第一步查 `ItemRegistryCatalog.lookup_canonical`（未注册 → `UNREGISTERED_ITEM`），描述永远基于已注册物品；
- **不反向定义属性**：`_build_params` 仅取 proto 已注册字段（属性/名称/品质）+ state 状态字段（数量/耐久等运行时状态），**禁新增核心属性字段**；模板经 audit 校验（S3）防属性定义注入；
- **状态组织**：`_select_template` 按状态条件组合选择描述模板段（品质档/数量档/耐久档/附魔段…），描述 = 已注册物品的派生视图。

### 1.2 与两三位一体的协作（数据契约）

| 协作方 | 方向 | 契约 |
| :--- | :--- | :--- |
| 物品系统（本体层） | 本体 → 描述（只读） | 描述消费 item_entity/item_prototype 已注册字段与运行时状态，不写回 |

| 事件侧（Phase 22/23） | 描述 → 事件（只读上下文） | 物品描述文本/状态可作事件概率条件上下文（经配置表，无直接类依赖） |
| 名称注册表（Phase 19） | 键/词典 | `item.<canonical>.desc` 登记 + en_US 底座 + `{param}` 插值 |
