## 一、 实现设计（新增概率解析器，只算不执行）

### 1.1 EventProbabilityResolver（事件动态概率解析器，新类）

```gdscript
class_name EventProbabilityResolver
extends RefCounted

const CONFIG_TABLE: String = "domains.event_probability"

## 概率解析：基础概率 → 条件修正（上下文/状态）→ 动态调整（buff/环境）→ 事件关联
## 输出唯一契约：{ probability, modifiers, adjusted_by }——只算不执行
static func resolve(event_id: String, world_context: Dictionary) -> Dictionary:
	var events_cfg: Dictionary = GameConfig.get_dict(CONFIG_TABLE, "events", {})
	var entry: Dictionary = events_cfg.get(event_id, {})
	if entry.is_empty():
		return {"success": false, "code": "EVENT_NOT_CONFIGURED", "event_id": event_id}

	var prob: float = float(entry.get("base_probability", 0.0))
	var modifiers: Array = []
	var adjusted_by: Array = []

	# 1) 条件修正：world_context 满足的条件组合 → 修正系数（只读上下文，不写事件状态）
	var conditions: Array = entry.get("conditions", [])
	for cond in conditions:
		if _eval_condition(cond.get("when", {}), world_context):
			var factor: float = float(cond.get("factor", 1.0))
			prob *= factor
			modifiers.append({"kind": "condition", "id": cond.get("id", ""), "factor": factor})

	# 2) 动态调整：buff/环境修正（配置驱动，禁止内嵌事件执行指令）
	var adjustments: Array = entry.get("adjustments", [])
	for adj in adjustments:
		if _eval_condition(adj.get("when", {}), world_context):
			var delta: float = float(adj.get("delta", 0.0))
			prob += delta
			modifiers.append({"kind": "adjustment", "id": adj.get("id", ""), "delta": delta})

	# 3) 事件关联：关联事件已发生 → 概率联动（经事件状态上下文只读查询）
	var links: Array = entry.get("links", [])
	for link in links:
		if _linked_triggered(link, world_context):
			prob *= float(link.get("factor", 1.0))
			adjusted_by.append(link.get("linked_event_id", ""))

	# 值域钳制：确定性 0~1（越界配置在启动校验拦截，此处兜底）
	prob = clampf(prob, 0.0, 1.0)
	return {
		"success": true,
		"event_id": event_id,
		"probability": prob,
		"modifiers": modifiers,
		"adjusted_by": adjusted_by,
	}

static func _eval_condition(when: Dictionary, ctx: Dictionary) -> bool:
	# 复用 Phase 20 事件 AST 求值模式（TOWN_EQUALS/MIN_LEVEL/HOUR_BETWEEN…），
	# 上下文只读（物品状态/城镇/等级/时钟…经配置键引用）
	return NarrativeCausalityOrchestrator.evaluate_ast_condition(when, ctx)

static func _linked_triggered(link: Dictionary, ctx: Dictionary) -> bool:
	# 关联事件触发状态：经事件状态上下文只读查询（event_state.triggered 集合）
	var triggered: Array = ctx.get("event_state.triggered", [])
	return str(link.get("linked_event_id", "")) in triggered
```

- **只算不执行**：`resolve` 输出仅概率值 + 修正明细；**零动作派发/零事件生命周期指令/零触发判定写回**——触发判定与执行归事件层（NarrativeCausalityOrchestrator 等）查询本解析器；
- **确定性**：纯函数式（输入 context → 输出概率），无随机内部状态（随机采样归事件层触发决策，不在此）；
- **配置驱动**：基础概率/条件修正/调整/关联 100% 来自 `domains.event_probability` 表（零硬编码）；配置不得含执行逻辑（S3 audit 拦截）。

### 1.2 与事件层/跨侧的协作（数据契约）

| 协作方 | 方向 | 契约 |
| :--- | :--- | :--- |
| 事件系统（事件层） | 事件 → 概率（查询） | 事件触发决策可**查询** `resolve(event_id, ctx)` 概率，概率层**不调用**事件执行——无循环依赖 |
| 事件发生描述（Phase 23） | 概率 → 描述（只读） | 概率结果/修正明细可作描述上下文（经配置键），描述生成于事件发生后 |
| 物品侧（Phase 21） | 物品状态 → 概率条件（只读） | `world_context` 经配置键引用物品注册状态（`{item_owned}`），无直接类依赖 |
| 名称注册表（Phase 19） | 事件键 | 事件 ID 沿用既有事件标识，`{param}` 插值共享 |
