## 一、 实现设计（复用 Phase 20 基建，新增结果分支层）

### 1.1 EventDescriptionResolver（事件发生描述解析器，新类）

```gdscript
class_name EventDescriptionResolver
extends RefCounted

## 事件描述解析：事件 + 上下文 + 结果 → 结果分支模板 → {param} 填充
## 时序：事件层执行/判定完成后调用（result 由事件层写入，描述层只读消费）
static func resolve(
	event_id: String,
	context: Dictionary = {},
	result: Dictionary = {},
	locale_override: String = ""
) -> Dictionary:
	var flows_cfg: Dictionary = GameConfig.get_dict("narratives.events", "descriptions", {})
	var entry: Dictionary = flows_cfg.get(event_id, {})
	if entry.is_empty():
		return {"success": false, "code": "EVENT_DESC_MISSING", "event_id": event_id}

	# 结果分支选择：result.outcome 匹配分支（success/failure/partial…），缺省 base
	var outcome := str(result.get("outcome", "base"))
	var template: String = str(entry.get(outcome, entry.get("base", "")))
	if template.is_empty():
		return {"success": false, "code": "DESC_BRANCH_MISSING", "event_id": event_id, "outcome": outcome}

	# 参数注入：context（事件上下文）+ result（事件执行结果）只读合并
	var params := _build_params(context, result)
	# 复用 Phase 20 NarrativeFlowResolver：占位符未填充拦截 + 热切换 + {param} 插值
	return NarrativeFlowResolver.resolve_flow("events", event_id, params, locale_override)

static func _build_params(context: Dictionary, result: Dictionary) -> Dictionary:
	var params: Dictionary = {}
	for k in context.keys():
		params[k] = context[k]
	for k in result.keys():
		if k != "outcome":
			params[k] = result[k]
	return params
```

- **复用声明（零重复建设）**：`{param}` 语法/未填充拦截（`MISSING_PARAMS` + 计数）/热切换重载/`FLOW_NOT_FOUND` 全部经 `NarrativeFlowResolver.resolve_flow`（Phase 20 已验收）；
- **结果分支**：`narratives.events` 配置按 `result.outcome`（success/failure/partial…）选模板，缺省 base——描述随实际结果变化；
- **不承担判定**：`result` 由事件层执行后写入（outcome/产出/损失），描述层只读合并填充——零判定、零写回、零动作派发。

### 1.2 与事件侧三层/跨侧的协作（数据契约）

| 协作方 | 方向 | 契约 |
| :--- | :--- | :--- |
| 事件系统（事件层） | 事件执行 → 描述（只读） | 事件层写入 `result`（outcome/产出），描述层生成于其后（时序保证不承担判定） |
| 概率层（Phase 22） | 概率结果 → 描述（只读） | `{probability_pct}`/修正明细经 context 注入（如 `{adjusted_by}`），无直接依赖 |
| 物品侧（Phase 21） | 物品状态 → 描述（只读） | `{item_name}`/`{item_quality}` 经名称注册表 resolve 注入 |
| 名称注册表（Phase 19） | 键/词典 | `narrative.events.<事件ID>` 登记 + en_US 底座 |
