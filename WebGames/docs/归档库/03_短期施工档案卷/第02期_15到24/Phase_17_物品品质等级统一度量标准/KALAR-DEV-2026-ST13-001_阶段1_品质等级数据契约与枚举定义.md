## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

```gdscript
# 模块路径: res://backend/domains/item_namespace_registry/item_quality_snapshot.gd
class_name ItemQualitySnapshot extends RefCounted:
	# 1. 主品质等级枚举（六档，等级值严格单调递增，禁止跨级倒置）
	enum QualityTier {
		COMMON,     # 普通   = 等级 1
		FINE,       # 精品   = 等级 2
		EPIC,       # 史诗   = 等级 3
		LEGENDARY,  # 传奇   = 等级 4
		MYTHIC,     # 神话   = 等级 5
		ANCIENT,    # 古代   = 等级 6
	}
	# 2. 神话级内部区间端点（仅 Mythic 档内生效，非独立主等级）
	enum MythicInterval {
		NONE,            # 非神话级或未细分
		QUASI_ARTIFACT,  # 准神器：神话级低端边界
		TRUE_ARTIFACT,   # 真神器：神话级高端边界
	}

	# 3. 核心属性与字段定义
	var canonical_id: String = ""
	var tier: QualityTier = QualityTier.COMMON
	var mythic_interval: MythicInterval = MythicInterval.NONE
	var tier_level: int = 1            # 1~6，由 QualityTier 单调映射
	var strength_weight: float = 1.0   # 强度基线权重（由配置表驱动）
	var rarity_weight: float = 1.0     # 稀有度/掉落权重（由配置表驱动）

	# 4. DTO 数据交换契约
	func to_dto() -> Dictionary:
		return {
			"canonical_id": canonical_id,
			"tier": tier,
			"mythic_interval": mythic_interval,
			"tier_level": tier_level,
			"strength_weight": strength_weight,
			"rarity_weight": rarity_weight,
		}

	static func from_dto(data: Dictionary) -> ItemQualitySnapshot:
		var snap = ItemQualitySnapshot.new()
		snap.canonical_id = data.get("canonical_id", "")
		snap.tier = data.get("tier", QualityTier.COMMON)
		snap.mythic_interval = data.get("mythic_interval", MythicInterval.NONE)
		snap.tier_level = data.get("tier_level", 1)
		snap.strength_weight = data.get("strength_weight", 1.0)
		snap.rarity_weight = data.get("rarity_weight", 1.0)
		return snap
```

**契约合法性边界（硬性不变量，阶段 2 校验器强制）**：

| 不变量 | 定义 | 违例示例 |
| :--- | :--- | :--- |
| `INV-1 单调等级序` | `tier` 与 `tier_level` 一一映射且严格递增（COMMON=1 < FINE=2 < EPIC=3 < LEGENDARY=4 < MYTHIC=5 < ANCIENT=6） | 配置将 ANCIENT 等级值定义为 3 → 跨级倒置，校验拒绝 |
| `INV-2 唯一主映射` | 每件物品恰好映射一个主品质等级；禁止未定义/多映射/映射冲突 | 物品同时声明 EPIC 与 LEGENDARY → 拒绝 |
| `INV-3 区间端点从属` | `mythic_interval != NONE` 当且仅当 `tier == MYTHIC` | 传奇级物品声明真神器 → 拒绝 |
| `INV-4 端点连续语义` | 准神器为神话低端边界、真神器为神话高端边界，二者强度权重满足 `QUASI < TRUE`，且均为神话级内部连续区间端点 | 真神器权重低于准神器 → 拒绝 |
