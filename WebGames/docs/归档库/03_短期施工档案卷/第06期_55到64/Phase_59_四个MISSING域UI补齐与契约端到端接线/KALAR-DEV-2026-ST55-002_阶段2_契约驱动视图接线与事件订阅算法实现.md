## 📌 第一性原理溯源指针

* **精准上游证据指针**：
  - `docs/audit/AUDIT_REPORT_UI缺失.md:66-68`：Phase 57 前所有 17 视图零接线（EventBus 订阅 0、后端 API 调用 0、Mock 数据 100%）；
  - `docs/audit/AUDIT_REPORT_UI缺失.md:112-117`：视觉堆与合同堆的镜像根因；
  - `frontend/views/main_hud.gd`（Phase 57 前 4 处 EventBus 例外）：本阶段沿用其订阅范式向其他视图扩展；
  - `backend/domains/contract_registry/contract_parser.gd`（Phase 57 S2 建立）：本阶段直接消费其 `resolve_dto_mapping`、`route_domain_event`、`dispatch_ui_command` 三算法；
  - Phase 47 S3 `WorldGatewayFSM._notify_event` 经 `EventBus.emit_domain_event` 官方入口范式：本阶段所有 4 个域的接线**必须**沿用此范式。

* **核心不变量约束断言**：
  - `Inv-MJ-1`（契约驱动单一路径）：所有视图字段填充**必须**通过 `ContractParser.resolve_dto_mapping` 消费契约条目，禁止直接读取后端 Service 的私有字段或内部方法；
  - `Inv-MJ-2`（EventBus 唯一订阅入口）：所有 EventBus 订阅**必须**经 `ContractParser.route_domain_event` 路由，禁止裸 `connect_signal` 或 `EventBus.connect_event` 直接连接；
  - `Inv-MJ-3`（COMMAND 参数前置校验）：所有 UI 命令**必须**通过 `ContractParser.dispatch_ui_command` 分发，参数校验由契约条目的 `params_schema` 承担；
  - `Inv-MJ-4`（Mock 数据降级）：Phase 59 后 4 个域的接线**必须**完全依赖真实后端数据，Mock 数据仅保留为契约完整性测试的测试夹具；
  - `Inv-MJ-5`（视图接线最小侵入）：每个现有视图的接线代码增量**必须** ≤ 30 行，且不修改既有视图的节点结构或信号声明；
  - `Inv-MJ-6`（契约层错误不崩溃）：`resolve_dto_mapping`、`route_domain_event`、`dispatch_ui_command` 的返回错误**必须**在视图侧统一降级为 `PushError` 而非异常抛出，避免契约层问题导致 UI 崩溃。

* **防漂移最高指示**：
  - 本阶段**只**实现接线算法与视图消费代码，**不**修改后端 Service 或 FSM 的接口签名；
  - 严禁在视图 `.gd` 中硬编码契约条目 ID（如 `CT-GW-WM-01`），**必须**通过 `ContractRegistryIndex.find_by_domain_view` 查询；
  - 严禁绕过契约层直接 `EventBus.connect_event("world_gateway.mode_switched", ...)`。

### 1. ViewContractBinder（视图契约绑定器）

```gdscript
# 契约：视图基类扩展，为每个视图提供统一的契约绑定接口。
# 位置：frontend/views/base_view_contract_binder.gd

class_name BaseViewContractBinder
extends Control

# ---- 生命周期钩子 ----
func _ready() -> void:
	_contract_init()

# ---- 契约初始化（子类覆写）----
func _contract_init() -> void:
	# 子类在此声明其绑定的契约条目 ID 集合
	# 例如：world_map_view 绑定 ["CT-GW-WM-01", "CT-GW-WM-02", "CT-GW-WM-03"]
	pass

# ---- 契约驱动的字段填充（DTO）----
func _refresh_contract_field(contract_id: String, backend_dto: Dictionary) -> void:
	var entry := ContractRegistryIndex.get_contract(contract_id)
	if entry == null:
		PushError("CT-MJ-MISSING_CONTRACT: " + contract_id)
		return
	var result := ContractParser.resolve_dto_mapping(backend_dto, entry)
	if "error" in result:
		PushError("CT-MJ_FIELD_RESOLVE_FAILED: " + result.error)
		return
	_apply_view_fields(result)

# ---- 契约驱动的事件订阅（EVENT）----
func _subscribe_contract_events() -> void:
	var entries := ContractRegistryIndex.find_by_view(_view_name())
	for entry in entries:
		if entry.endpoint_kind == ContractRegistryEntry.EndpointKind.EVENT:
			_contract_connect_event(entry)

func _contract_connect_event(entry: ContractRegistryEntry) -> void:
	# 经 ContractParser.route_domain_event 路由，禁止裸 connect
	# 实际实现：将 entry.signal_name 映射到本地 signal handler
	pass

# ---- 契约驱动的命令分发（COMMAND）----
func _dispatch_contract_command(contract_id: String, params: Dictionary) -> Dictionary:
	var entry := ContractRegistryIndex.get_contract(contract_id)
	if entry == null:
		return {"accepted": false, "error_code": "CT_ERR_MISSING_ENTRY"}
	return ContractParser.dispatch_ui_command({
		"command_id": entry.method_name,
		"view_name": _view_name(),
		"params": params
	})

# ---- 视图名（子类覆写）----
func _view_name() -> String:
	return get_class()
```

### 6. 契约错误降级（视图侧统一处理）

```gdscript
# 位置：frontend/views/base_view_contract_binder.gd（追加错误处理）

func _handle_contract_error(contract_id: String, error_code: String, context: Dictionary) -> void:
	var log_level: String = "error"
	match error_code:
		"CT_ERR_MISSING_ENTRY", "CT_ERR_SCHEMA_INVALID":
			log_level = "error"
			PushError("Contract error %s in %s: %s" % [error_code, contract_id, context])
		"CT_ERR_PARAMS_INVALID":
			log_level = "warning"
			PushWarning("User input rejected by contract %s: %s" % [contract_id, error_code])
			_show_toast("输入不符合要求")
		"CT_ERR_FIELD_TYPE_MISMATCH":
			log_level = "error"
			PushError("Field type mismatch in %s: %s" % [contract_id, context])
		_:
			log_level = "warning"
			PushWarning("Unknown contract error %s in %s" % [error_code, contract_id])
```
