## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

### 1. 可空依赖入参契约（L2）

```gdscript
# 契约：涉及资产转移/销毁的域服务，依赖入参（inventory 等）为 null 一律在入口拒绝：
#   return {"success": false, "error_code": "MISSING_INVENTORY_CONTEXT"}（语义对齐 mail 域 MISSING_CONTEXT 族）
# 禁止：if inventory != null: …（null 分支跳过资产操作后仍扣款/减货/返回 success）
# 落点：shop_proximity_transaction_solver（交易前置段）、ground_loot_pickup_solver（拾取前置段）
# 附带：入口契约收紧后，两处「inventory==null 仍扣款/移除」的幽灵路径从语义上消除
```

### 2. 递归遍历环检测契约（L4）

| 契约项 | 设计 |
| :--- | :--- |
| 访问集 | `_recalculate_node_upwards` 携带 `visited: Dictionary`（节点路径 → true）；入口处先判 visited，命中即终止（防环） |
| 终止语义 | 命中环不再无限递归；返回当前已计算结果 + `push_warning`（脏数据现场可审计，不静默） |


### 4. 状态栈幂等契约（L7）

```gdscript
# game_loop_fsm.gd:31-37 幂等压栈语义修正：
#   同状态重复 push（无论是否带 context）一律不追加新栈帧：
#   if new_state == current_state:
#       若带 context → 仅刷新当前帧 context（不 append）
#       return
#   否则 append（既有语义）
# 不变量：栈深 == 不同状态切换次数 + 1；pop 语义与注释「幂等」一致
```

### 5. 公共底座防御契约（L8）

| 契约项 | 设计 |
| :--- | :--- |
| 配置返回引用 | `get_value`（275 行）/`get_many`（343 行）/`get_array`/`get_dict` 返回 **duplicate 副本**（按取值器语义分层：基础类型（int/float/String/bool）返回即值，容器类型（Array/Dictionary）返回深拷贝）——防调用方就地修改污染配置表 |
| 路径缓存有界 | `_split_path` 缓存（354-361）增加容量上限（对齐 FifoBudget 有界裁剪惯例，上限值取自既有 infra 配置族如 `infrastructure.admin idempotency/max_records` 同族或就近既有键，禁造新表） |
| LCG 常量固化 | `deterministic_rng.gd`：`set_seed` 时快照 multiplier/increment/mask 为实例字段；`next_state` 读快照而非每步实时读配置——运行期 reload_config 不再静默改变同种子序列（Inv-DF-5；Phase 54 登记项归本卷落地） |
