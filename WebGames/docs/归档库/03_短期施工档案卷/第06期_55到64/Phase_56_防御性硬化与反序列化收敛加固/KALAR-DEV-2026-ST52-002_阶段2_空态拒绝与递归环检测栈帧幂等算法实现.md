```gdscript
# 模块路径: backend/domains/notification_red_dot/red_dot_tree_solver.gd（24-25 行）
# 新增私有递归（带 visited 访问集，Inv-DF-2）：
```

### 4. L7 修复：状态栈幂等压栈

```gdscript
# 模块路径: backend/infrastructure/game_loop_fsm.gd（31-37 行）
func push_state(new_state: int, context_payload: Dictionary = {}) -> void:
    if new_state == current_state:
        # 幂等语义修正：同状态重复 push 不再追加栈帧（原仅 context 为空才拦截）
        if not context_payload.is_empty():
            state_contexts[current_state] = context_payload.duplicate(true)   # 仅刷新当前帧上下文
        return
    state_stack.append(new_state)
    current_state = new_state
    if not context_payload.is_empty():
        state_contexts[current_state] = context_payload.duplicate(true)
```

**行为对照**：修复前同状态带 context 双 push → 栈深 +2、需两次 pop；修复后栈深不变、仅 context 刷新（与头注释「幂等：重复压同状态仅刷新上下文」一致）。既有正常路径（不同状态切换）零变化。
