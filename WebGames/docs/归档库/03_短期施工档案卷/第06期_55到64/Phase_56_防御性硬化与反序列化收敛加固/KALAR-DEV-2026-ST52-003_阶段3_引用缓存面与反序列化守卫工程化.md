### 2. L8 修复：配置返回面拷贝与缓存有界 + LCG 固化

```gdscript
# ① game_config.gd 返回面防御性拷贝（Inv-DF-5）——按取值器族分层：
#    get_value（275 行）/get_many（343 行）：容器命中分支返回前 duplicate(true)
#    get_array / get_dict：新增 duplicate(true)（基础类型键值即值，容器深拷贝）
#    性能注记：仅容器路径多一次拷贝（低频配置读取），热路径零影响（对齐既有注释的性能权衡说明）

# ② _split_path 路径缓存（354-361 行）有界化：
#    命中计数/插入计数达上限（读取既有 infra 配置族上限键，如 admin idempotency/max_records 同族；
#    若无适用键则登记复用该键族默认 1000，禁止造新表）时整表重建清空
#    （对齐 FifoBudget.trim_oldest 有界惯例的简化版：满即整体重建，路径段表小、重建成本可忽略）

# ③ deterministic_rng.gd LCG 常量实例固化（Inv-DF-5；Phase 54 阶段3 登记项归本卷落地）：
var _lcg_multiplier_snap: int = 0
var _lcg_increment_snap: int = 0
var _lcg_mask_snap: int = 0

func set_seed(seed_value: int) -> void:
    _lcg_multiplier_snap = GameConfig.get_int("domains.deterministic", "lcg/multiplier", 1103515245)
    _lcg_increment_snap = GameConfig.get_int("domains.deterministic", "lcg/increment", 12345)
    _lcg_mask_snap = GameConfig.get_int("domains.deterministic", "lcg/mask", 2147483647)
    _state = seed_value & _lcg_mask_snap
    if _state == 0:
        _state = 1

func next_state() -> int:
    _state = (_state * _lcg_multiplier_snap + _lcg_increment_snap) & _lcg_mask_snap
    return _state
# 语义：实例一经 seed 即锁定 LCG 参数，运行期 reload_config 不再静默改变同种子序列；
# 全局实例在首次 global() 时 seed（既有 _default_seed 路径）→ 参数随之固化
```
