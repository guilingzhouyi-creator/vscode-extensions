## 第一性原理溯源指针

- **视图拆分的第一性原理**：一个视图承担多个正交语义时，必须拆分，否则测试与回归成本非线性增长。`character_progression.gd` 同时承担角色成长与背包两个语义，是典型耦合违反。
- **深层契约的第一性原理**：契约注册表是"接口事实"的唯一来源。当后端服务已提供能力而前端未接线时，契约注册表应显式登记"缺失条目"以便守卫捕获。
- **工程化第一性原理**：任何新增视图必须同时完成 (a) 场景 (b) 导航 (c) 文案 (d) 值域 (e) 契约 (f) 兼容。缺一即技术债。

### 3.2 `frontend/views/character_progression.gd` 降级改造

**改造内容**：移除背包 tab，仅保留"进入背包视图"的导航按钮（跳转至 inventory_view）。

```gdscript
# frontend/views/character_progression.gd
# 变更点：移除 _bag_slot_container / _bag_items_refresh / _open_bag_tab 相关代码
#         新增 _open_inventory_view() 导航方法

func _ready() -> void:
    _setup_tabs()           # 现有 tab 初始化
    _setup_nav_buttons()   # 新增：导航按钮
    _bind_contract()        # 阶段 2 契约绑定

func _setup_tabs() -> void:
    # 保留：等级 / 天赋 / 技能 / 装备 4 个 tab
    # 移除：背包 tab（迁移至 inventory_view）
    _tab_container.add_child(_make_tab_level())
    _tab_container.add_child(_make_tab_talent())
    _tab_container.add_child(_make_tab_skill())
    _tab_container.add_child(_make_tab_equip())

func _setup_nav_buttons() -> void:
    var btn_go_inventory := Button.new()
    btn_go_inventory.text = tr("nav.go_inventory")
    btn_go_inventory.pressed.connect(_open_inventory_view)
    _nav_container.add_child(btn_go_inventory)

func _open_inventory_view() -> void:
    # 通过 ui_registry 注册表切换视图，不硬编码路径
    EventBus.emit_ui_command("view.open", {"view_name": "inventory_view"})
```

**降级验收要点**：
- 移除的 3 个方法符号（`_bag_slot_container` / `_bag_items_refresh` / `_open_bag_tab`）必须为 0 引用（`grep -r` 应返回空）
