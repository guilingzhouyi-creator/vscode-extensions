## 一、 数据结构设计与代码契约

### 1. RegistryContract（注册契约条目，audit_runner.py 自检消费）

```python
# 位置：scripts/py/audit_runner.py（仅契约注释 + 常量，不改逻辑）
ENGINE_PREFIXES = ("audit_", "report_", "archive_")  # 修复：下划线，与磁盘命名一致
REGISTRY_EXEMPT = {"audit_runner.py", "audit_common.py", "audit_gd_style.py"}
# 校验语义：engine_files = {f endswith .py} ∩ {startswith ENGINE_PREFIXES} - EXEMPT
# 差集 engine_files - registered → 孤儿阻断；registered - 磁盘存在 → 悬空阻断
```

### 2. SliceContract（切片契约，--slice 语义冻结）

```python
# 位置：scripts/py/audit_runner.py（契约注释）
# --slice <name>：子串匹配 task.scopes ∪ task_id ∪ script_name（如 inventory 命中 scopes 含 config 的任务子集）
# 优先级：--task > --group > --diff > --slice > 默认 audit 组；与 --task/--group 混用时直接返回 exit 2 用法错误
```

### 3. GdThresholdContract（.gd 专用阈值契约，WebGames/auto-refactor.config.json 唯一源）

```json
{
  "thresholds": {
    "magicNumberMin": 10,
    "hardcodedStringMinLength": 8,
    "duplicateLiteralThreshold": 5,
    "complexityWarn": 15,
    "complexityFail": 25
  },
  "analyzers": {
    "governance": { "enabled": true, "options": { "maxNestingDepth": 5, "maxInheritanceDepth": 2 } }
  }
}
```

取值依据：magicNumberMin 10 对齐游戏数值常用小量（2~9 为合法步长/槽位）；minLength 8 对齐 audit_hardcode.py:28；duplicate 5 对齐文案键复用现实；complexity 15/25 高于通用 10/20 以容忍求解器分支（SIM-CMP-001 嵌套≤5 不变，只放宽圈复杂度）。
