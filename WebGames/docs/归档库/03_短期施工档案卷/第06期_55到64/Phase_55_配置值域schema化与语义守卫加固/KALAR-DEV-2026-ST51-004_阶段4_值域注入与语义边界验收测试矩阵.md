### 2. 核心注入用例设计（代表例）

```gdscript
# L1 代表：tier_size 除零回归（修复前红：int/int 除零运行错误）
# 注入：配置 domains.potential point_cost/tier_size=0（运行时热重载或直改表）
# 断言：calculate_point_cost_for_next_stat(3) 返回非崩溃值（守卫后等效 tier_size=1 语义）

# L1 代表：drop_lowest 负值越界回归（修复前红：range(-4,4) → rolls[-5] 越界）
# 注入：drop_lowest=-4（dice count=4）
# 断言：roll_4d6_drop_lowest 正常返回 1~24 区间值，无越界运行错误

# L3 代表：金库负数取款回归（修复前红：-= -100 变入账）
# 注入：withdraw_from_treasury(org, op, -100, 0)（权限满足）
# 断言：返回 INVALID_AMOUNT；treasury_gold_coins 分毫未动

# L12 代表：别名键类型错误回归（修复前红：for null 崩溃）
# 注入：movement/direction_aliases 某键值为 String
# 断言：返回 INVALID_DIRECTION_ALIAS 安全降级，无崩溃

# 静态 schema 注入（audit_config 侧）：临时把 tier_size 表值改 0 → 值域段 exit 1；测后还原
```

### 3. 边界/容错用例

- 守卫对**正常配置**零影响回归（各域成功路径数值与改造前一致）；
- 倒置/相等区间（deadzone outer==inner、value_min==value_max 合法相等边界不误杀）；
- schema 校验对既有全量配置 0 error（基线 0 新增），仅对注入坏表红。
