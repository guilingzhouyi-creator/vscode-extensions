* **核心不变量约束断言**：
  - `Inv-CT-1`（契约唯一性）：任一后端域 ↔ 前端视图的映射在 Registry 中**唯一且稳定**，禁止重复登记或同名异义条目；
  - `Inv-CT-2`（契约完整性）：任一 FULL/PARTIAL 域**必须**至少登记 1 条 DTO 契约、1 条 Event 契约、1 条 Command 契约（三者齐备方可判定接线就绪）；
  - `Inv-CT-3`（契约版本化）：任一契约条目**必须**声明 `contract_version`（整数递增），版本变更必须同步登记 `breaking_change_note`；
  - `Inv-CT-4`（契约降级防线）：任一契约字段读取**必须**提供类型守卫（Phase 56 S1 已建立的 `_sanitize_section` 范式）与缺省兜底，未知字段静默丢弃、缺失字段取兜底而非崩溃；
  - `Inv-CT-5`（契约不可写注册表）：Registry 只读，只能通过 `contracts.json` 配置表驱动，禁止运行时通过代码硬编码注入（防伪造）；
  - `Inv-CT-6`（INFRA 域豁免）：4 个 INFRA 域（`world_state`/`feature_toggle_canary`/`telemetry_account_lifecycle`/`event_extractor`）显式标注 `infra_exempt: true`，不参与契约完整性校验但保留可选 GM 只读契约入口。

* **防漂移最高指示**：
  - 本阶段**只**建设契约元数据模型与注册表索引结构，**不**触碰任何实际 DTO/FSM/API 实现代码，也**不**修改任何视图 `.gd` 或 `.tscn`；
  - 契约条目以**声明式配置**（`contracts.json`）为唯一权威源，禁止在 `.gd` 中硬编码映射表；
  - 严禁将本阶段扩展为"契约层落地 + 视图接线"的混合阶段——那是 Phase 58/59/60 的范围，本阶段止步于「可被后续 Phase 消费的注册表骨架」。

## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

### 1. ContractRegistryEntry（契约注册表条目）

```gdscript
# 契约：单一契约端点条目。所有注册表条目共享此结构。
# 位置：backend/domains/contract_registry/contract_registry_entry.gd

class_name ContractRegistryEntry

# ---- 契约标识 ----
@export var contract_id: String = ""          # 唯一 ID，格式：CT-{DOMAIN}-{VIEW}-{SEQ}
@export var contract_version: int = 1         # Inv-CT-3，整数递增

# ---- 域 ↔ 视图 ↔ 端点三元坐标 ----
@export var domain_name: String = ""          # 后端域，如 "character_creation"
@export var view_name: String = ""            # 前端视图，如 "account_entry"
@export var endpoint_kind: EndpointKind = EndpointKind.DTO
enum EndpointKind {
	DTO,              # Domain DTO → View ViewModel 转换契约
	EVENT,            # Domain Event → View Signal 订阅契约
	COMMAND,          # View Command → Domain Service 调用契约
	GM_READONLY,      # INFRA 域 GM 只读契约入口（可选）
}

# ---- 契约字段映射（DTO/Event 契约用）----
@export var source_path: String = ""          # 后端来源，如 "CharacterCreationService.character_baseline"
@export var target_path: String = ""          # 前端目标，如 "account_entry_view.creation_panel.baseline_label"
@export var field_mapping: Array[Dictionary] = []   # [{backend_field, view_field, transform_kind, transform_config}]
@export var transform_kind: String = "identity"     # identity/cast/format/enum_map/aggregate/filter

# ---- 事件契约专属字段（Event 契约用）----
@export var event_name: String = ""           # EventBus 事件名，如 "character.creation.completed"
@export var signal_name: String = ""          # 前端 View Signal 名，如 "_on_character_created"
@export var event_filter: Dictionary = {}     # 事件过滤器（domain/actor/resource 前置匹配）

# ---- 命令契约专属字段（Command 契约用）----
@export var service_path: String = ""         # 后端 Service 全限定名
@export var method_name: String = ""          # 后端方法名
@export var params_schema: Array[Dictionary] = []  # 参数 schema（Phase 55 S1 VD_* 值域范式复用）
@export var response_dto: String = ""         # 响应 DTO 类型名

# ---- 契约生命周期与审计 ----
@export var breaking_change_note: String = "" # 破坏性变更说明（Inv-CT-3）
@export var infra_exempt: bool = false         # INFRA 域豁免标记（Inv-CT-6）
@export var deprecated: bool = false
@export var replacement_contract_id: String = ""
@export var created_at: String = ""
@export var last_reviewed_at: String = ""
```

### 2. ContractRegistryIndex（注册表索引）

```gdscript
# 契约：所有契约条目的容器与查询接口。
# 位置：backend/domains/contract_registry/contract_registry_index.gd

class_name ContractRegistryIndex

# ---- 静态单例（只读）----
static var _instance: ContractRegistryIndex = null
static var _entries: Array[ContractRegistryEntry] = []

# ---- 初始化：从 contracts.json 加载 ----
static func ensure_loaded() -> void:
	if _instance != null: return
	_instance = ContractRegistryIndex.new()
	_instance._load_from_config()

# ---- 索引查询 API（后续 Phase 58/59/60 消费）----
static func find_by_domain(domain: String) -> Array[ContractRegistryEntry]
static func find_by_view(view: String) -> Array[ContractRegistryEntry]
static func find_by_domain_view(domain: String, view: String) -> Array[ContractRegistryEntry]
static func find_by_endpoint(kind: EndpointKind) -> Array[ContractRegistryEntry]
static func get_contract(contract_id: String) -> ContractRegistryEntry
static func has_contract(contract_id: String) -> bool

# ---- 契约完整性自检（CI 门禁消费）----
# 返回：{missing_dto: [...], missing_event: [...], missing_command: [...]}
static func audit_completeness() -> Dictionary

# ---- 契约版本兼容性检查 ----
static func is_breaking_change(from: ContractRegistryEntry, to: ContractRegistryEntry) -> bool
```
