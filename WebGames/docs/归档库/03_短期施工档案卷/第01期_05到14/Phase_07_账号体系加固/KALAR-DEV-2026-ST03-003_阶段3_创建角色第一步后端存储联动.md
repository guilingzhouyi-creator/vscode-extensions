## 一、 核心业务逻辑实现 (Core Business Logic)

```gdscript
# 模块路径: res://backend/domains/account/account_profile.gd
func bind_character_to_slot(slot_id: String, dto: SaveSlotSummaryDTO) -> Dictionary:
    if slot_id.is_empty() or dto == null:
        return {"success": false, "error_code": "INVALID_SLOT"}
    save_slot_summaries[slot_id] = dto
    active_slot_id = slot_id
    EventBus.get_instance().emit_domain_event("account.slot_bound", {"args": [slot_id], "summary": {"character": dto.character_name}})
    return {"success": true, "slot_id": slot_id}

# 模块路径: res://backend/infrastructure/game_loop_fsm.gd
func push_character_select_context(slot_id: String, character_name: String) -> void:
    push_state(EngineState.CHARACTER_SELECT, {"slot_id": slot_id, "character_name": character_name})
```

* **配置驱动**：槽位默认 `slot_id/character_name/profession_tier_name` 全经 `domains.account:save_slot/defaults`；创角种族/天赋经 `domains.character_creation` 分流，首版文字版经鼠标点击热区 `TextInteractionSolver.hit_test_mouse_click` 与快捷键 `dispatch_shortcut("open_inventory")` 触发。
