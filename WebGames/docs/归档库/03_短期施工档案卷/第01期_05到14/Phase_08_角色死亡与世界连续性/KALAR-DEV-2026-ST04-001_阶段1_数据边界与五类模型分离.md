## 📌 第一性原理溯源指针

* **精准上游规范指针**：本任务第1节“清理玩家角色状态，不清理世界状态；角色重新开始，不代表世界重新开始”与第3节五类数据模型。
* **核心不变量约束断言**：`角色死亡仅影响角色数据集合，世界数据集合零回退；新角色零继承死亡角色完整状态`。
* **防漂移最高指示**：严禁将五类数据塞入同一存档对象；同名概念以本任务重新确认的职责为准，不得默认复用旧架构字段语义！

## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

```gdscript
# 模块路径: res://backend/domains/account/account_profile.gd
class_name AccountProfileAggregate extends RefCounted:
    var account_id: String = ""
    var entitlements: Array[String] = [] # 预留：模式鉴权字段列表（可扩展，不固化示例）
    var save_slot_summaries: Dictionary = {} # slot_id -> SaveSlotSummaryDTO（角色容器）
    var world_state_ref: String = "" # 指向当前游玩世界实例 ID（与角色解耦）
```

```gdscript
# 模块路径: res://backend/domains/world_state/world_instance.gd
class_name WorldInstance extends RefCounted:
    var world_id: String = ""
    var world_time: Dictionary = {} # 世界时间（文字版：WorldClockMaster 快照）
    var world_state: Dictionary = {} # 世界持续状态（NPC/环境/事件/资源/社会）
    var history_fragments: Array[Dictionary] = [] # 可重组状态片段（预留）

# 模块路径: res://backend/domains/account/character_profile.gd
class_name CharacterProfile extends RefCounted:
    var character_id: String = ""
    var attributes: Dictionary = {}
    var inventory_snapshot: Dictionary = {}
    var quest_progress: Dictionary = {}
    var relationship_state: Dictionary = {}
```

| 数据类 | 归属 | 死亡是否清理 | 存储位置 |
| :--- | :--- | :--- | :--- |
| 账号 | 权限主体容器 | 否 | `AccountProfileAggregate` |
| 角色 | 玩家实体本体 | 是（精确子集） | `CharacterProfile` + `SaveSlot` |
| 世界 | 持续演化 | 否（继续推进） | `WorldInstance` |
| 历史影响 | 可重组片段 | 否（只增） | `WorldInstance.history_fragments` |
| 权限 | 资格描述 | 否 | `AccountProfile.entitlements` + `EntitlementService` |

## 二、 边界与合法性约束 (Validation Constraints)

| 约束字段 | 类型 | 边界范围 | 违规处理 |
| :--- | :--- | :--- | :--- |
| `entitlements` | `Array[String]` | 元素非空，小写 `mode.version` 形 | 非法元素静默丢弃 |
| `world_state_ref` | `String` | 空或已存在 `world_id` | 空时回退官方默认世界 |
| `character_id` | `String` | 非空 | 空时拒绝绑定 |
