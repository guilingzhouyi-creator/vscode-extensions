## 一、 配置驱动与工程化改造 (Generalization)

```gdscript
# 模块路径: res://backend/domains/world_state/world_recombination_stub.gd
class_name WorldRecombinationStub extends RefCounted:
    static func generate_new_world(default_template: Dictionary, history_worlds: Array[Dictionary], config: Dictionary) -> Dictionary:
        if not GameConfig.get_bool("domains.world", "continuity/enabled", false):
            return {"success": true, "world": default_template.duplicate(), "mode": "DEFAULT_ONLY"}
        # 预留：随机组合不同来源事件/环境/社会状态（当前仅返回模板+历史片段数，不落地完整重组）
        var fragments: Array = []
        for w in history_worlds:
            fragments.append_array(w.get("history_fragments", []))
        var composed: Dictionary = default_template.duplicate()
        composed["recombined_fragments_count"] = fragments.size()
        composed["sources"] = ["default", "history"]
        return {"success": true, "world": composed, "mode": "RECOMBINED_STUB"}

# 模块路径: res://backend/domains/account/entitlement_service.gd
class_name EntitlementService extends RefCounted:
    static func has_entitlement(account: AccountProfileAggregate, entitlement: String) -> bool:
        if account == null or entitlement.is_empty():
            return false
        return account.entitlements.has(entitlement)
    static func add_entitlement(account: AccountProfileAggregate, entitlement: String) -> void:
        if not has_entitlement(account, entitlement):
            account.entitlements.append(entitlement)
```

| 配置开关 | 路径 | 默认 | 关闭时行为 |

| 权限存储 | `domains.account:entitlements/encrypted` | `true` | 客户端篡改无效，经解密后统一入口判断 |

## 二、 安全与分责约束

* **安全存储**：`entitlements` 经 `SaveManager.compute_sha256 + 加密` 落盘，客户端改本地无效；`EntitlementService` 为唯一鉴权入口
* **分责**：业务模块 `A/B/C` 一律 `EntitlementService.has_entitlement(account, "online")`，禁止各模块直读 `account.entitlements` 或自建判断规则
