## 一、 核心业务逻辑实现 (Core Business Logic)

```gdscript
# 模块路径: res://backend/domains/item_namespace_registry/item_instance_factory.gd
class_name ItemInstanceFactory extends RefCounted:
    static func build_instance(proto: ItemRegistryCatalog.ItemPrototypeTemplate, display_name: String, uid_prefix: String) -> ItemEntity:
        var item := ItemEntity.from_payload(ItemRegistrySolver.build_instance_payload(proto, display_name))
        item.item_uid = ItemUIDGenerator.generate_uid(uid_prefix)
        return item
```
