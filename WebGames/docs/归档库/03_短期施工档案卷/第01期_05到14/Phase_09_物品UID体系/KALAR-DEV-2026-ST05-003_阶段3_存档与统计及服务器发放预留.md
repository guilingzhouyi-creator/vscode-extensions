## 一、 配置驱动与工程化改造 (Generalization)

```gdscript
# 模块路径: res://backend/domains/item_namespace_registry/server_grant_registry.gd
class_name ServerGrantRegistry extends RefCounted:
    var grants: Dictionary = {}  # grant_id -> { uid, source, claimed_at }
    static func register_grant(grant_id: String, uid: String, source: String) -> Dictionary:
        if grants.has(grant_id):
            return {"success": false, "error_code": "GRANT_ALREADY_EXISTS"}
        grants[grant_id] = {"uid": uid, "source": source, "claimed_at": int(Time.get_unix_time_from_system())}
        return {"success": true, "grant_id": grant_id, "uid": uid}
```

| 层 | 落点 | uid 维度 |
| :--- | :--- | :--- |
| 存档 | `item_entity.serialize/deserialize` | `item_uid` 字段；旧档缺失走 `migrate_legacy_uid` |
| 统计 | `ItemStatisticsSolver.record_item_event` | `meta.uid` 旁路（聚合仍按 canonical） |
| 服务器预留 | `ServerGrantRegistry` | `grant_id → uid` 幂等只增 |
