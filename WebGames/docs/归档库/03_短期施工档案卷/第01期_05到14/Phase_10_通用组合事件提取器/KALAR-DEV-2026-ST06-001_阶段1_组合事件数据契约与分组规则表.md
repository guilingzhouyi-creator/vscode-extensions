## 一、 组合事件 DTO 契约 (CompositeEventDTO)

```gdscript
# 模块路径: res://backend/domains/event_extractor/composite_event_dto.gd
class_name CompositeEventDTO extends RefCounted
var event_name: String = ""          # 组合事件名（规则表驱动，如 "transaction.cdkey_redeemed"）
var account_id: String = ""          # 账号 UID（隔离维度，必填）
var transaction_id: String = ""      # 事务相关性键（一次业务动作一个键，组合分组依据）
var item_flows: Array = []           # 物品流数组：[{ canonical_id, event_type, quantity }...]
var currency_delta: Dictionary = {}  # 货币增量（可选，如 { "gold": -100, "copper": 5000 }）
var meta: Dictionary = {}            # 事务元数据（来源渠道/原因码/审计锚点）
var timestamp_utc: int = 0
```

**约束**：`account_id` 与 `transaction_id` 均非空；`item_flows` 内 `event_type ∈ {item.granted, item.consumed, item.destroyed, item.traded, item.forged, item.clawed_back}`；`quantity > 0`。

## 二、 分组规则表 Schema（config/domains/event_extractor.json）

```jsonc
{
  "enabled": true,
  "batch_size": 200,
  "grouping_rules": [
    {
      "rule_id": "rule_cdkey_redeem",
      "source_event": "item.granted",
      "group_key": "transaction_id",        // 原始事件 payload 中取事务键的字段名
      "composite_event": "transaction.cdkey_redeemed",
      "projection": "account_summary"
    }
  ],
  "projections": {
    "account_summary": { "scope": "account", "include": ["current_quantity", "total_gained"] }
  }
}
```

* **组合键**：`(account_id, transaction_id)` 二元组；同一组合键的原始事件折叠为一个 `CompositeEventDTO`；
* **投影规则**：配置驱动的派生视图（按账号 / 按 canonical_id / 分类子树），供运营查询，杜绝硬编码聚合。
