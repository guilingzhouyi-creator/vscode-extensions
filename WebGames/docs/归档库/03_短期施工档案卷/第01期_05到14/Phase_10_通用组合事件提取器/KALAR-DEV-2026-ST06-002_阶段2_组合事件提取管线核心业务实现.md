## 二、 关键行为与边界

| 行为 | 约定 |
| :--- | :--- |
| 空键守卫 | `transaction_id` 缺失的原始事件不组合、保持原样逐条落账（不吞没） |
| 减量触底 | 物化沿用 `apply_item_delta` 钳制语义：实际生效量 < 请求量时计入 `clamped_flows` 返回 |
| 幂等性 | 同一批次重复提取幂等（物化前校验已存在组合事件键则跳过） |
| 性能 | 批大小由 `event_extractor.json:batch_size` 驱动，环形缓冲批量刷盘不阻塞 |
