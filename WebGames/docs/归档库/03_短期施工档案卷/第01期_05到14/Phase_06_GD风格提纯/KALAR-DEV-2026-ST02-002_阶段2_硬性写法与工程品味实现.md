## 一、 核心业务逻辑实现 (Core Business Logic)

```gdscript
# 模块路径: res://backend/domains/admin_sandbox/clawback_service.gd
class_name ClawbackService extends RefCounted:
    static func clawback_item_prototype(admin: AdminPermissionAggregate, mode: String, canonical_id: String, quantity: int, reason: String, inventory: WearableInventoryAggregate, library: AccountItemLibraryAggregate = null) -> Dictionary:
        var gate := _gate(admin, mode)
        if not gate.success:
            return gate
        if inventory == null or canonical_id.is_empty() or quantity <= 0:
            return {"success": false, "error_code": "CLAWBACK_INVALID_TARGET"}
        # 卫语句 + 钳制 + 统计旁路（可空注入）
        var actual := mini(quantity, matches.size())
        if library != null:
            ItemStatisticsSolver.record_item_event(library, ItemStatisticsSolver.EVENT_ITEM_CLAWED_BACK, canonical_id, actual)
        return {"success": true, "actual_clawed": actual}
```

| 品味项 | 禁止写法 | 老练写法 |
| :--- | :--- | :--- |
| 控制流 | 深层嵌套 `if { if { } }` | 卫语句 `if not ok: return` |
| 硬编码 | `gold_rate = 10000` | `GameConfig.get_int("domains.currency", "rates/gold", 10000)` |
| 随机 | `randf()` | `DeterministicRNG.resolve(rng).randf()` |
| 错误 | `return null` | `return {"success": false, "error_code": "..."}` |
