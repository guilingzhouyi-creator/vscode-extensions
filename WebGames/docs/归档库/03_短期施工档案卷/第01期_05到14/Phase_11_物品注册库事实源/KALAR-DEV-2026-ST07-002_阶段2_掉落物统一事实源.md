## 一、 核心业务逻辑实现 (Core Business Logic)

```gdscript
# 模块路径: res://backend/domains/ground_loot/ground_dropped_item_aggregate.gd
class_name GroundDroppedItemAggregate extends RefCounted:
    # 掉落声明键（config/domains/ground_loot.json:drop_decl 或事件载荷）必须为已登记 canonical_id
    static func create_from_declaration(canonical_id: String, catalog: ItemRegistryCatalog, display_name: String) -> Dictionary:
        if canonical_id.is_empty():
            return {"success": false, "error_code": "EMPTY_ITEM_KEY"}
        var proto = catalog.get_prototype(canonical_id)
        if proto == null:
            return {"success": false, "error_code": "ITEM_NOT_REGISTERED", "canonical_id": canonical_id}
        var item := ItemInstanceFactory.build_instance(proto, display_name, "DRP_")
        return {"success": true, "item_entity": item}
```

| 链路 | 引用键 | 拦截点 |
| :--- | :--- | :--- |
| 怪物掉落 | 掉落表 canonical_id | 生成前 `catalog.get_prototype` |
| 事件掉落 | 载荷 canonical_id | 同上 |
| 地面拾取 | 掉落实体已校验 | `item_entity` 直持 |

* 新增 UID 前缀 `DRP_`（掉落物）登记入 `item_namespace_registry.json:uid.prefixes`
