## 一、 鉴权服务与物理仓储接入设计 (Auth Service & Repository Integration)

### 1. 双轨存储接入模型

为了在引入物理持久化落盘的同时保证所有既有测试套件与内存沙箱 100% 不受破坏，`AuthService` 采用双轨判定机制：

```text
                                  register_account(request, account_store)
                                                    │
                                   account_store 是否非空？
                                  ┌─────────────────┴─────────────────┐
                                  ▼                                   ▼
                           [是: 兼容内存轨]                    [否: 物理仓储轨]
                                  │                                   │
                           遍历字典查重                        AccountRepository 查重
                                  │                                   │
                           写入内存字典                        原子写盘 + 双层内存索引
```

### 2. 标准注册接口改造 (`register_account`)

```gdscript
static func register_account(request: AccountRegistrationDTO.Request, account_store: Dictionary = {}) -> AccountRegistrationDTO.Response:
	# 1. 凭证合法性与长度校验（卫语句提前返回）
	# 2. 查重分流：
	#    - 若 account_store 非空：遍历 account_store 进行大小写不敏感重名校验；
	#    - 若 account_store 为空：调用 AccountRepository.get_instance() 的 has_username() 查重；
	# 3. 聚合实体构建与属性填充；
	# 4. 存储分流：
	#    - 若 account_store 非空：account_store[acc.account_id] = acc；
	#    - 若 account_store 为空：调用 AccountRepository.get_instance().save_account(acc) 执行原子落盘；
	# 5. EventBus 广播与 Hook 派发。
```

### 3. 本地鉴权口令重铸落盘 (`authenticate_local`)

```gdscript
if matched:
	if needs_rehash:
		account.password_hash_sha256 = hash_password(pass_plain)
		account.salt_version = 1
		if not account.account_id.is_empty():
			AccountRepository.get_instance().save_account(account)
```

在口令重铸升级分支中，新计算的加盐哈希与 `salt_version = 1` 立即调用 `AccountRepository.get_instance().save_account(account)` 触发原子刷盘，使重铸结果跨越进程生命周期持久留存。

### 4. 复合鉴权自动注册与仓储索引 (`composite_authenticate`)

```gdscript
# 账号检索分流：
if not account_store.is_empty():
	for acc_id in account_store.keys():
		var existing: AccountProfileAggregate = account_store[acc_id]
		if existing != null and existing.username.to_lower() == request.username.to_lower():
			target_account = existing
			break
else:
	var repo := AccountRepository.get_instance()
	if not repo.is_loaded():
		repo.load_all()
	target_account = repo.find_by_username(request.username)
```

当账号不存在且允许自动注册时，调用 `register_account(reg_req, account_store)` 完成落盘后，通过 `AccountRepository.get_instance().find_by_id(reg_resp.account_id)` 重新取回聚合对象继续登录签发。
