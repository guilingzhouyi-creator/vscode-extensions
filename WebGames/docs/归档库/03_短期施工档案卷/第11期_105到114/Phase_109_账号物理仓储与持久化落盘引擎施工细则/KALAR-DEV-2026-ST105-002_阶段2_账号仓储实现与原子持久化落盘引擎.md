## 一、 仓储架构与原子落盘引擎设计 (Repository Architecture & Atomic Engine)

### 1. 双层内存高速索引与单例模型

仓储在内存中维护两层哈希表，确保登录与业务查询均为 $O(1)$ 复杂度：

```text
               ┌────────────────────────────────────────────────────────┐
               │              AccountRepository (单例)                   │
               └────────────────────────────────────────────────────────┘
                              │                           │
          _accounts_cache     │                           │  _username_index
     (account_id -> Aggregate)│                           │ (username_lower -> ID)
                              ▼                           ▼
            { "ACC_USR_1001": Aggregate }      { "heroofkalar": "ACC_USR_1001" }
            { "ACC_USR_1002": Aggregate }      { "adventurer":  "ACC_USR_1002" }
```

### 2. 事务级原子写算法 (tmp -> bak -> rename)

写盘流程严格遵循 ACID 文件系统事务语义：

1. 写入内容至临时文件 `<file_path>.tmp`，执行 `flush()` 与 `close()` 确保数据刷入物理介质；
2. 若目标文件 `<file_path>` 已存在，将其备份至 `<file_path>.bak`（按 `backup_retention` 配置执行备份轮转）；
3. 调用文件系统级原子操作 `DirAccess.rename_absolute(tmp_path, file_path)` 替换旧正档；
4. 若更名失败，自动移除 `<tmp>` 文件并回滚错误，正档不受任何破坏。

### 3. 容灾读取与防损自愈算法

读取全局注册表 `account_registry.json` 时实施三级防御防线：

1. **第一防线（正档读取）**：尝试打开并解析主注册表 JSON。解析成功且信封合法，直接反序列化注入内存缓存；
2. **第二防线（备份回退）**：若正档损坏（解析失败）或缺失，且已启用 `auto_restore_enabled`，尝试从 `<file_path>.bak` 恢复主档并重读；
3. **第三防线（分片逆向重建）**：若备份亦损毁或不存在，自动扫描 `user://accounts/` 目录下所有单账号分片文件（`ACC_*.json`），反序列化提取有效账号并重构全局注册表，完成全自动韧性自愈。

### 4. 核心 API 契约与查询接口

```gdscript
## 单例与生命周期
static func get_instance() -> AccountRepository
static func reset_for_tests() -> void

## 核心持久化与读取
func load_all() -> Dictionary
func save_account(account: AccountProfileAggregate) -> Dictionary
func delete_account(account_id: String) -> bool

## 高速缓存查询
func find_by_id(account_id: String) -> AccountProfileAggregate
func find_by_username(username: String) -> AccountProfileAggregate
func has_account(account_id: String) -> bool
func has_username(username: String) -> bool
func get_account_count() -> int
func list_account_ids() -> Array[String]
func get_all_accounts() -> Dictionary
```
