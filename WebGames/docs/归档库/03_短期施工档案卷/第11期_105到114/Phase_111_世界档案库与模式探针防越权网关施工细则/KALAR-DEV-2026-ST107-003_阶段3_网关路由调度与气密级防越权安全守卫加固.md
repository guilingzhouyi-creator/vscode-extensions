## 一、 防越权安全守卫与路由调度架构设计 (Anti-Bridge Guard & Routing Architecture)

### 1. 气密级防越权安全守卫 (`AntiBridgeGuard`)

`AntiBridgeGuard` 承担世界网关的边界安全守卫职能，针对三种典型越权与状态污染场景实施气密级阻断：

```text
       [WorldGatewayFSM]                 [AntiBridgeGuard]
               │                                 │
     select_mode(target_mode) ───────────► validate_mode_transition(...)
                                                 ├─► 1. 检查模式单向冻结 (Anti-Hot-Swap)
                                                 ├─► 2. 检查探针报告就绪性 (Readiness Probe)
                                                 └─► 3. 检查联机权限白名单 (Whitelist/Canary)
                                                 │
                                           [通过/阻断返回]
```

1. **跨模式热切换阻断 (`validate_mode_transition`)**：
   - 当会话模式已选定（`current_mode != UNSELECTED`）且试图变更为另一模式（`target_mode != current_mode`），判定为非法跨模式热切换，阻断并返回 `SECURITY_ERR_CROSS_MODE_HOT_SWAP`；
   - 必须通过 `exit_to_gateway()` 经过内存全量洗脱后，方可重新选定模式；
   - 检验前置探针报告就绪性：若探针报告未就绪，阻断并返回 `SECURITY_ERR_MODE_NOT_READY`；
   - 校验联机权限：目标模式为联机时，若缺乏灰度白名单资质，阻断并返回 `SECURITY_ERR_MULTIPLAYER_UNAUTHORIZED`。

2. **槽位与模式亲和性校验 (`validate_slot_mode_affinity`)**：
   - 校验存档槽位模式与目标运行模式的亲和关系；
   - 单机槽位严禁渗透至联机界域，阻断并返回 `SECURITY_ERR_SLOT_MODE_POISONING`。

3. **网络信道静默纪律 (`validate_network_channel_discipline`)**：
   - 单机模式（`SINGLE_PLAYER`）或未选定状态下，严禁向远程信道（如 `network.*`, `mp.*`, `multiplayer.*`, `realm.*`, `remote.*`）派发事件广播；
   - 违规立即阻断并抛出 `SECURITY_ERR_NETWORK_MUTE_VIOLATION`。

### 2. 联机界域只读目录扩展桩 (`RemoteRealmDirectoryProvider`)

为保持未来联机界域解耦与首期单机聚焦，提供无状态只读扩展桩：
- `list_realms(account_id: String) -> Array[Dictionary]`
- 聚合配置表 `worlds_catalog` 中的联机候选界域或只读卡片，返回包含 `realm_id`, `realm_name`, `ping_ms`, `status`, `is_canary`；
- 返回深拷贝副本，保障只读安全与零内存泄露。

### 3. 动态世界解析与解算器向后兼容升级 (`GameModeRoutingSolver`)

在 `GameModeRoutingSolver.resolve_mode_entry` 中接入双轨世界解析机制：
1. **优先静态表索引**：若 `all_worlds` 字典中已包含 `target_world_id`，直接复用既有逻辑；
2. **动态持久化世界档案解析**：若静态字典未命中，动态查询 `WorldArchiveRepository.get_instance().get_world_summary(target_world_id)`，将物理落盘的单机世界水化为 `WorldInstanceDTO`；
3. **严格 100% 向后兼容**：保留既有所有公开方法签名（`load_default_canary_flags`, `_resolve_multiplayer_entry`, `_resolve_single_player_entry`），无缝兼容所有既有单元测试套件。

### 4. 网关生命周期探测与内存全量洗脱 (`WorldGatewayFSM`)

在 `WorldGatewayFSM` 中补充气密防护与会话清理机制：
1. **就绪探测**：`enter_gateway()` 时自动调用 `ModeReadinessProbe.probe_all_modes(context.account_id)` 收集单机与联机健康报告；
2. **跃迁裁定**：`select_mode()` 前置委托 `AntiBridgeGuard.validate_mode_transition()` 进行气密级裁定；
3. **全量内存洗脱 (`exit_to_gateway`)**：重置模式至 `UNSELECTED`，清空 `selected_slot_id`、`selected_world_id`、`active_character_id`，重置阶段至 `GATEWAY_ENTERED`，广播 `world_gateway.memory_scrubbed` 领域事件，彻底杜绝脏状态跨会话残留。
