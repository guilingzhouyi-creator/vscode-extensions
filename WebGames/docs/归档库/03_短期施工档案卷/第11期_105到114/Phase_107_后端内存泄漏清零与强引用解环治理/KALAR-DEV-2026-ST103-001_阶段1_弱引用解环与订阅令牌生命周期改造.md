* **核心不变量约束断言**：
  - `Inv-MEM1-1 (令牌解环与单向归属)`：`EventBusSubscriptionToken` 对 `EventBusCore` 的持有必须严格通过弱引用 `weakref(bus)` 包装，严禁持有双向强引用，确保独立总线实例与测试上下文能够正常析构；
  - `Inv-MEM1-2 (解绑幂等与弱引用安全校验)`：`unbind()` 必须先判断 `_bus_ref.get_ref()` 是否有效，有效则委托解绑，无论总线是否已析构均安全重置激活状态；
  - `Inv-MEM1-3 (热路径死令牌修剪)`：派发热循环在遭遇 `!tok.callback.is_valid()` 时，必须将失效令牌加入延迟修剪批次，并在循环退出后批量调用 `_unregister_token()`，阻断路由表死项堆积。
* **防漂移最高指示**：严禁在 `RefCounted` 派生类之间建立未经弱引用的双向持有；派发热循环必须保证快照与原数组操作的隔离性。

## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

### 1. 订阅令牌弱引用包装改造
在 `event_bus_subscription_token.gd` 中，移除强引用字段 `var bus: EventBusCore`，改用弱引用内部包装：

```gdscript
# 模块路径: res://backend/infrastructure/event_bus/event_bus_subscription_token.gd
class_name EventBusSubscriptionToken
extends RefCounted

var _bus_ref: WeakRef = null
var channel_id: int = 0
var category_mask: int = 0
var callback: Callable = Callable()
var is_spatial: bool = false
var token_id: int = 0
var is_active: bool = false

func _init(
	p_bus: EventBusCore,
	p_channel: int,
	p_mask: int,
	p_cb: Callable,
	p_spatial: bool,
	p_tid: int = 0
) -> void:
	if p_bus != null:
		_bus_ref = weakref(p_bus)
	channel_id = p_channel
	category_mask = p_mask
	callback = p_cb
	is_spatial = p_spatial
	token_id = p_tid
	is_active = true

func unbind() -> bool:
	if not is_active:
		return false
	is_active = false
	if _bus_ref != null:
		var active_bus: Variant = _bus_ref.get_ref()
		if active_bus != null and active_bus.has_method("_unregister_token"):
			active_bus._unregister_token(self)
			return true
	return true
```

### 2. 热分发循环死亡令牌收集与剔除
在 `event_bus_core.gd` 的 `dispatch_now()` 中，收集失效回调令牌并在派发完毕后统一修剪：

```gdscript
# 模块路径: res://backend/infrastructure/event_bus/event_bus_core.gd
var dead_tokens: Array = []
for tok in targets:
	if not tok.is_active:
		continue
	if tok.callback.is_valid():
		tok.callback.call(packet)
	else:
		dead_tokens.append(tok)

for dead_tok in dead_tokens:
	_unregister_token(dead_tok)
```
