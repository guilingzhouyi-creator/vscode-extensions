## 一、 CLI 集成与配置路由规约

### 1.1 `kalar_mod.py` 扩展打包与工作台子命令

在统一 CLI 入口注入：
- **`pack` 子命令**:
  ```bash
  python mod_sdk/tools/kalar_mod.py pack <mod_dir> [-o output.kmod] [--force]
  ```
- **`workbench` 子命令**:
  ```bash
  python mod_sdk/tools/kalar_mod.py workbench [--workspace <dir>] [--watch]
  ```

### 1.2 `sync_mod_sdk.py` 自动化萃取升级

扩展 `sync_mod_sdk.py`，提取最新能力字典：
```python
"workbench_capabilities": {
    "supported_package_formats": [".kmod", "DIRECTORY"],
    "supported_actions": ["init", "check", "pack", "play", "watch"],
    "supported_compression": "ZIP_DEFLATE",
    "hash_algorithm": "SHA256"
}
```

### 1.3 开发者指引与 AI Agent 操作规范升级

在 `mod_sdk/MOD_SPEC.md` 增加专属章节：
- 第七章：单一应用台（Workbench）与一键 `.kmod` 构建规范；
- 第八章：面向 AI Agent 自动化结对开发的 STDIO 流式命令与沙箱测试 SOP。
