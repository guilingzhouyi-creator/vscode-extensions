## 📌 第一性原理溯源指针

* **精准上游规范指针**：
  - `backend/infrastructure/game_bootstrap.gd`（当前底层装配基线）
  - `backend/domains/version_governance/version_manifest_dto.gd`（版本契约）
  - `backend/domains/version_governance/version_activation_gate.gd`（启动门禁）
  - `backend/infrastructure/event_bus/event_bus_core.gd`（P72 分发中枢）
  - `config/infrastructure/domains.json`（全域领域元数据）
* **核心不变量约束断言**：
  - `Inv-VG3-1 (运行时上下文沙盒隔离)`：不同版本的运行时上下文（Context A vs Context B）其实例引用、配置快照与物品注册表必须完全内存物理隔离，一个版本的内存变更绝不污染另一版本；
  - `Inv-VG3-2 (装配门禁无漏洞拦截)`：`GameBootstrap` 的全域装配流程必须无条件先通过 `VersionActivationGate` 的授权判定，未获放行时必须返回错误码并终止装配；
  - `Inv-VG3-3 (控制面与数据面完全异步分流)`：P72 EventBus 0x0500 信道仅处理状态信令；补丁包资源拉取必须在后台独立执行，禁止阻塞 EventBus 的主分发循环；
  - `Inv-VG3-4 (配置热重载原子性)`：当触发 `CONFIG_HOTFIX` 补丁时，`GameConfig` 必须执行原子化全表重新扫描与校验，若校验失败必须 100% 回滚至上一版本配置缓存；
  - `Inv-VG3-5 (单机离线防篡改)`：单机运行模式下的本地授权证书必须包含设备散列绑定与不可逆签名，禁止用户通过本地记事本随意篡改版本号实现越权启动。

## 一、 底层装配重构与上下文模型 (Versioned Runtime Context)

### 1. 版本化运行时上下文容器 (`VersionedRuntimeContext`)
* 模块路径: `res://backend/domains/version_governance/version_runtime_context.gd`
* 职责: 封装指定游戏版本所持有的全部运行时依赖，彻底摆脱全局静态单例依赖。

```gdscript
class_name VersionedRuntimeContext
extends RefCounted

var version_string: String = "1.0.0"
var version_code: int = 10000
var activation_token: ActivationTokenDTO = null

# 本版本独立的依赖容器
var catalog: ItemRegistryCatalog = null
var magic_registry: MagicTierRegistry = null
var magic_rules: MagicRuleRegistry = null
var quality_registry: QualityTierRegistry = null
var config_snapshot: Dictionary = {}

var is_active: bool = false

func _init(v_str: String, v_code: int, token: ActivationTokenDTO) -> void:
	version_string = v_str
	version_code = v_code
	activation_token = token

## 装配当前版本独立的内部单例环境
func assemble_context() -> bool:
	if is_active:
		return true
	# 构建本版本对应的物品目录与注册表
	catalog = ItemLoaderPipeline.build_catalog_from_config()
	magic_registry = MagicTierRegistry.new()
	magic_registry.reload_configuration()
	magic_rules = MagicRuleRegistry.new()
	magic_rules.reload_configuration()
	quality_registry = QualityTierRegistry.new()
	quality_registry.reload_configuration()
	is_active = true
	return true

## 安全释放上下文
func dispose() -> void:
	catalog = null
	magic_registry = null
	magic_rules = null
	quality_registry = null
	is_active = false
```

### 2. `GameBootstrap` 底层装配改造 (支持版本门禁与上下文注入)
* 模块改造: `res://backend/infrastructure/game_bootstrap.gd`
* 改造要点: 在 `assemble()` 起始处植入 `VersionActivationGate`，并将全局装配代理至当前激活的 `VersionedRuntimeContext`。

```gdscript
# 在 GameBootstrap 中增补门禁与版本上下文管理：

static var _active_context: VersionedRuntimeContext = null

## 重构后的装配入口 (前置版本门禁拦截)
static func assemble_versioned(target_version: String, token: ActivationTokenDTO) -> Dictionary:
	# 1. 基础配置预加载
	GameConfig.ensure_loaded()

	# 2. 执行第一道版本激活门禁 (Fail-Fast)
	var gate_result := VersionActivationGate.evaluate_startup_eligibility(target_version, token)
	if not gate_result.get("allowed", false):
		return {
			"success": false,
			"error_code": gate_result.get("error_code", "VERSION_GATE_REJECTED"),
			"reason": gate_result.get("reason", "版本未获运行授权")
		}

	# 3. 释放旧上下文 (若有)
	if _active_context != null and _active_context.version_string != target_version:
		_active_context.dispose()
		_active_context = null

	# 4. 创建并装配新版本运行时上下文
	if _active_context == null:
		var v_code := 10000 # 从 manifest 解析
		_active_context = VersionedRuntimeContext.new(target_version, v_code, token)
		var ok := _active_context.assemble_context()
		if not ok:
			return {"success": false, "error_code": "CONTEXT_ASSEMBLY_FAILED"}

	_assembled = true
	return {
		"success": true,
		"version": target_version,
		"already_assembled": false,
		"item_count": _active_context.catalog._canonical_registry.size()
	}
```

## 三、 全域 EventBus 0x0500 信道端到端接线

在 P72 `EventBusCore` 中建立专门的版本治理信令分发循环：

```gdscript
# 控制面接入示例：派发版本授权与激活生命周期

static func broadcast_update_authorization(user_id: String, token: ActivationTokenDTO) -> void:
	var packet: EventPacket = EventPool.borrow()
	packet.channel_id = EventChannelDefinition.UPDATE_AUTHORIZED
	packet.category_mask = EventCategoryMask.CORE_STATE
	packet.source_entity_id = user_id
	packet.payload_dto = token

	# 核心控制因果流必须使用 dispatch_now() 即时因果派发
	EventBusCore.get_instance().dispatch_now(packet)
	EventPool.recycle(packet)

static func broadcast_version_activated(version_str: String) -> void:
	var packet: EventPacket = EventPool.borrow()
	packet.channel_id = EventChannelDefinition.VERSION_ACTIVATED
	packet.category_mask = EventCategoryMask.CORE_STATE
	packet.payload_data = {"version": version_str, "timestamp": int(Time.get_unix_time_from_system())}

	EventBusCore.get_instance().dispatch_now(packet)
	EventPool.recycle(packet)
```
