## 一、 事实分类体系与唯一属主契约 (Fact Taxonomy & Ownership Contract)

### 1. 六类配置事实与属主表声明

| 事实类 | 定义域 | 唯一属主表（SSOT） | 允许副本形态 |
| :--- | :--- | :--- | :--- |
| F-1 物品原型 | 物品 canonical_id/english_name/基础属性/搜索别名 | `items/core.json`（ItemLoaderPipeline 自动装配） | 他表仅引用 `canonical_id`/`numeric_id` |
| F-2 领域数值 | 数值平衡/初始资金/概率/成长曲线 | `domains.<域>`（别名复用按 domains.json 映射） | 他域可经 `depends_on` 声明读表，禁复制值 |
| F-3 用户可见文案 | 事件叙事/回执/公告/描述模板 | 叙事短文案 → `narratives.<域>`；条件化长模板 → `copywriting.<域>` | 经 EventBus/`GameConfig.msg`/CopywritingResolver 键读 |
| F-4 双语词条 | 名称/标签双语词典 | `i18n/zh_CN.json` + `i18n/en_US.json`（en_US 机器底座，zh_CN 展示层） | 结构表以 `name_key` 键引（如 `magic_tiers.json` 既有范式） |
| F-5 注册清单 | 域 id/错误码/契约条目/测试注册 | `infrastructure/domains.json` 域清单；`narratives.errors` 消息文本；`infrastructure/errors_catalog.json` 错误码元数据 | 他清单仅登记引用，双向一致由护栏保证 |
| F-6 演示快照 | 前端骨架默认值/演示数据 | `frontend/ui.json` + `frontend/views.json`（受控白名单） | 快照须带 `snapshot_of` 溯源 + 一致性门禁比对 |

### 2. 副本形态判据（什么算"合法共享"，什么算"真双写"）

| 副本形态 | 判定标准 | 处理 |
| :--- | :--- | :--- |
| 引用型（合法） | 只含属主表 id/key 指涉，零属性值复制 | 保留，登记引用关系入 manifest 备注 |
| 译文型（必要） | 同一语义键在 zh/en 各一份（`Inv-SS-4` 键集对称） | 保留；护栏校验键集 1:1 对称 |
| 受控快照型（受控） | 展示用值拷贝，带 `snapshot_of` 指向属主键路径 | 保留 + provenance 注解 + 一致性门禁 |
| 正式占位型（合法） | 骨架 `_comment` 声明式空表（如 `RESERVED_NARRATIVES` 先例） | 保留并登记占位白名单 |
| 真双写（违规） | 同一事实两组独立承载且各自演进（文本/字段已漂移） | 属主方保留，副本方合并或退役，reader 同步收敛 |

### 3. 防过度归一否决红线（平衡边界，防"为低冗余而低"）

- `X-1 语义异构禁并`：运行时状态默认与持久用户偏好默认是不同事实（如 `localization_i18n.defaults.current_locale` 运行时当前语言 vs `game_settings.defaults.ui_visual.language` 玩家设置项），禁止强行合并为单键；允许以 `_meta` 注解互指消除误读。
- `X-2 引用代价否决`：当收敛需新建中间表/跨层动态拼接、而现重复仅一处且无第二消费方时，**就地值 + provenance 注解** 优于新建引用链（演示快照属此类）。
- `X-3 粒度劣化否决`：收敛不得把业务条目级模板强行归并为全局泛模板而牺牲条件化语义与域内可读性（copywriting 四域边界保持）。
- `X-4 行为零改观铁律`：本卷只收敛**存储与读取通道**；除裁决明确"副本已漂移需由属主裁定真值"外，禁止顺带改动任何数值/文案语义——数值改动必须独立立项。

5. 迁移同步删除原域表内直书键，禁止"域表保留 + 通道新增"的过渡双写。
