  - `scripts/config/code_governance_rules.json`（`advanced_rules.<CODE>` 结构：level/name/description/fix_suggestion）；
  - `config/infrastructure/ssot_manifest.json`（阶段 1 交付的事实归属矩阵，本引擎唯一裁决输入源）。
* **核心不变量约束断言**：
  - `Inv-SS-6 (引擎-清单互证不变量)`：引擎检测结论必须与 manifest 裁决一致（清单裁决真双写处引擎必报；引擎新发现必须回流清单登记），双向差集 0。
  - `Inv-SS-7 (豁免不可静默扩张不变量)`：任何豁免/白名单条目必须落 `code_governance_rules.json.exemptions` 或 manifest 备注并附理由，引擎对白名单外同类违规保持 ERROR。
  - `Inv-SS-8 (快照溯源可检不变量)`：frontend 快照声明 `snapshot_of` 后，引擎必须能定位属主键路径并比对值；源表改值而未同步快照时引擎告警（WARN），`--strict` 下升级 ERROR。
  - `Inv-SS-9 (规则登记完备不变量)`：六路检测器每一 ERROR 类别在 `code_governance_rules.json.advanced_rules` 存在唯一规则号（ADV-CFG-00x），禁止未登记即断言的"幽灵规则"。
* **防漂移最高指示**：判重引擎只做**证据呈现与红线判定**，严禁提供自动改写（禁 `--fix` 静默合并配置）；一切收敛动作由阶段 3 人工/Agent 分批执行并保留 git diff 证据。

## 一、 核心检测器与判重算法实现 (Detection Engine & Algorithms)

### 1. 六路检测器规格

| 检测器 | 输入域 | 判定算法 | 输出等级 |
| :--- | :--- | :--- | :--- |
| R1 逐字节复制组 | `config/**/*.json` 全量 | 规范化 JSON（键序无关）→ md5 → 同摘要分组输出复制组；文件对进 manifest 校验 | ERROR（manifest 未豁免）/ WARN（豁免期） |
| R2 包装层对账 | manifest `duplicate_tables` 对（D1/D2/D3） | 按对账映射剥包装键（如 `descriptions/`、`descriptions.<条目>`）后逐叶值比较；漂移叶清单输出 | 漂移叶 ERROR；一致 WARN（待退役） |
| R3 语义孪生漂移 | manifest 登记的孪生对（D4/D5 类） | 键序归一 + 字段差集比对（缺字段/值漂移）逐叶输出 | 缺字段/值漂移 ERROR；全等 WARN |
| R4 错误消息双向互认 | `narratives/errors.json` ↔ `infrastructure/errors_catalog.json` | 错误码去下划线+小写归一化双向差集；message_key 悬空检测 | 孤儿键/悬空引用 ERROR |
| R5 演示快照溯源对账 | frontend 表内 `snapshot_of` 注解 | 解析注解定位属主表/键路径，值比对 | 漂移 WARN（`--strict` ERROR）；缺注解引用值不检 |
| R6 域表文案直书通道违规 | `domains/**/*.json` | CJK 直书扫描 − 豁免白名单（manifest/规则库 exemptions） | 白名单外 ERROR |

裁决元规则（接入 R2/R3/R6 判定前过滤）：X-1 语义异构默认值（如 locale 三默认，由 manifest 标注 `semantic_distinct: true`）豁免于 R3 真双写判定；X-3 粒度劣化（manifest 标注 `verdict: KEEP_WITH_NOTE`）不产生 ERROR。

### 3. 语义与输出契约

- **基线机制**：`--baseline findings.json` 允许已登记存量违规进入待办台账（与 `audit_docs --baseline` 语义一致）；**严禁以改动基线方式掩盖新增**（与全域治理纪律一致）；阶段 3 每收敛一批即回写基线归零对应项。
- **JSON Findings 条目**：`{ "detector": "R3", "rule_id": "ADV-CFG-00X", "severity": "ERROR|WARN", "fact_id": "D5", "tables": [...], "paths": [...], "message": "...", "evidence": "..." }`。
- **自证夹具 `--selfcheck`**：白盒构造 3 组最小样例（复制对→R1 必报；包装层值漂移对→R2 必报且报漂移叶；`semantic_distinct` 豁免对→R3 静默），夹具失败即退出码 2——引擎正确性自证内置于门禁。
