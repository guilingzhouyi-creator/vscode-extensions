## 一、 六刻度区间契约表 (Six-Period Boundary Contract)

按一天时间轴循环顺序（凌晨 → 早上 → 中午 → 下午 → 晚上 → 半夜），每区间 4 小时均分 24 小时，采用**半开区间 [start, end)**：

| 序号 | 刻度名 | 英文 key | 小时范围 | 边界语义（半开） | 旧三区间关联 |
| :---: | :--- | :--- | :--- | :--- | :--- |
| 1 | 凌晨 | `early_morning` | 02:00 ~ 05:59 | `2 <= hour < 6` | 原「上午」00~11 中 02~05 拆分 |
| 2 | 早上 | `morning` | 06:00 ~ 09:59 | `6 <= hour < 10` | 原「上午」00~11 中 06~09 拆分 |
| 3 | 中午 | `noon` | 10:00 ~ 13:59 | `10 <= hour < 14` | 沿用原「中午」12~13 并扩展 10~11 |
| 4 | 下午 | `afternoon` | 14:00 ~ 17:59 | `14 <= hour < 18` | 原「下午」14~23 中 14~17 收窄 |
| 5 | 晚上 | `evening` | 18:00 ~ 21:59 | `18 <= hour < 22` | 原「下午」14~23 中 18~21 拆分 |
| 6 | 半夜 | `midnight` | 22:00 ~ 01:59 | `hour >= 22 or hour < 2` | 原「下午」22~23 ＋ 原「上午」00~01 合并 |

**设计说明**：
1. **六刻度均分 24 小时**：每刻度 4 小时，两两互斥且并集恰为全部 24 个整点小时，杜绝死区与重叠；
2. **跨日连续区间**：「半夜」是唯一跨自然日的区间（22 点至次日 1 点），判定条件必须用**或运算**（`hour >= 22 || hour < 2`），是边界守卫生效的关键测试点；
3. **旧值语义延续**：「中午」「下午」两词沿用旧值语义（仅边界微调），「上午」退化为历史保留词，新落戳不再产出；
4. **判定顺序约定**：实现时按「半夜（跨日或分支优先）→ 凌晨 → 早上 → 中午 → 下午 → 晚上」顺序判断，或等价的查表实现，任一实现必须与常量表一致。

### 1.1 合法标签全集（解析层契约）

```text
合法落戳标签（新产出）  : 早上 / 中午 / 下午 / 晚上 / 半夜 / 凌晨
历史保留标签（仅解析）  : 上午（存量归档文档可含，不重写、不新产出）
```

### 1.2 常量契约（三实现共用同一份常量表）

```bash
# bash（timestamp.sh 内联）
PERIOD_MORNING=早上        # 6 <= h < 10
PERIOD_NOON=中午           # 10 <= h < 14
PERIOD_AFTERNOON=下午      # 14 <= h < 18
PERIOD_EVENING=晚上        # 18 <= h < 22
PERIOD_MIDNIGHT=半夜       # h >= 22 || h < 2
PERIOD_EARLY_MORNING=凌晨  # 2 <= h < 6
```

```python
# python（archive_volume.py 内 resolve_period_label 同源常量）
PERIOD_BOUNDS = ((2, "凌晨"), (6, "早上"), (10, "中午"),
                 (14, "下午"), (18, "晚上"), (22, "半夜"))
# 判定: hour >= 22 -> 半夜; 否则取第一个满足 hour < bound 的标签
```

PowerShell 用 hashtable 等价实现（`@{2='凌晨';6='早上';10='中午';14='下午';18='晚上';22='半夜'}`，取最后一个 `hour >= key` 的 value）。
