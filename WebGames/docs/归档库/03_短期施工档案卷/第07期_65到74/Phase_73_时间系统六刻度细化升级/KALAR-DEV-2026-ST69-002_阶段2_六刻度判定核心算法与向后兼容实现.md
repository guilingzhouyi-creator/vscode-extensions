## 一、 六刻度判定核心算法 (Core Solver)

### 1.1 bash 实现（`scripts/sh/timestamp.sh`）

```bash
# 职责: 输出当前系统日期 + 施工时段（六刻度：早上/中午/下午/晚上/半夜/凌晨）
# 时段六刻度定义（半开区间，与阶段1常量表一致）:
#   凌晨  = 02:00 ~ 05:59（2 <= hour < 6）
#   早上  = 06:00 ~ 09:59（6 <= hour < 10）
#   中午  = 10:00 ~ 13:59（10 <= hour < 14）
#   下午  = 14:00 ~ 17:59（14 <= hour < 18）
#   晚上  = 18:00 ~ 21:59（18 <= hour < 22）
#   半夜  = 22:00 ~ 01:59（hour >= 22 || hour < 2，跨日连续区间）
hour=$(date +%-H 2>/dev/null || date +%H | sed 's/^0//')

if [ "$hour" -ge 22 ] || [ "$hour" -lt 2 ]; then
  period="半夜"
elif [ "$hour" -lt 6 ]; then
  period="凌晨"
elif [ "$hour" -lt 10 ]; then
  period="早上"
elif [ "$hour" -lt 14 ]; then
  period="中午"
elif [ "$hour" -lt 18 ]; then
  period="下午"
else
  period="晚上"
fi
```
