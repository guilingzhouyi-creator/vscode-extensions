## 📌 第一性原理溯源指针

* **精准上游规范指针**（现状审计 2026-09-07 实测）：
  - `tests/test_runner.gd` 测试退出日志实测：`WARNING: 56 RIDs of type "CanvasItem" were leaked. WARNING: 151 ObjectDB instances were leaked at exit. ERROR: 20 resources still in use at exit.`；
  - 泄漏根因：UI 视图组件继承 `Control`/`Node`（属于非引用计数的 `Object`），由测试与工厂动态实例化后未在退出前调用 `.free()` 或结构化清理；
  - `backend/infrastructure/event_bus.gd`：信号广播中心（`narrative_event_emitted`, `log_record_emitted`, `domain_event`），业务模块订阅后无全局解绑守卫；
  - `backend/domains/persistence_protocol/save_data_access_layer.gd` / `editor_hot_reload_manager.gd`：静态字典（`_domain_contracts`, `_dirty_domains`, `_last_hashes`），需明确生命周期与重置策略；
  - `backend/infrastructure/log_ring_buffer.gd` / `telemetry_aggregate.gd`：环形缓冲区与遥测窗口（内存有界设计的成功范式，需推广至全域缓存）。
* **核心不变量约束断言**：
  - `Inv-RM-1 (清晰所有权不变量)`：任何非 `RefCounted` 系统资源（Node, Control, File, Stream, Thread）必须具备唯一明确的 Owner；谁创建、谁负责销毁，严禁产生所有权悬空或双重销毁。
  - `Inv-RM-2 (生命周期单向闭环不变量)`：资源状态严格沿 `CREATE ➔ INITIALIZE ➔ USE ➔ IDLE ➔ RELEASE ➔ DISPOSE` 单向演进；`DISPOSE` 态对象严禁被再次访问或复用，重复释放必须幂等无害。
  - `Inv-RM-3 (缓存六要素完备不变量)`：全域所有 Cache/Pool 必须完整具备 Ownership, Lifetime, Capacity, Eviction, Invalidation, Refresh 六要素，严禁无上限静态字典持续膨胀。
  - `Inv-RM-4 (监听解绑零残留不变量)`：凡向 EventBus、Timer、时钟或服务注册的回调/闭包，必须在所属宿主进入 `RELEASE`/`DISPOSE` 时 100% 显式解绑。
  - `Inv-RM-5 (循环分配零常驻不变量)`：高频运行路径与循环内禁止瞬态堆分配，临时容器必须在单次消费后重置或作用域内清空，不逃逸到外层堆中。
* **防漂移最高指示**：严禁机械增加大量难以维护的复杂 Pool 或深度异步线程，必须基于证据（Evidence）优化；严禁以“降低执行频率”掩盖资源未释放本质！

### 1. 资源生命周期枚举与所有权描述符 (`resource_lifecycle_descriptor.gd`)

```gdscript
# 模块路径: res://backend/infrastructure/resource_governance/resource_lifecycle_descriptor.gd
class_name ResourceLifecycleDescriptor extends RefCounted

## 资源生命周期六阶段标准
enum LifecycleState {
	UNINITIALIZED = 0, # 已分配，未完成初始化
	INITIALIZED = 1,   # 初始化就绪
	IN_USE = 2,        # 正在被业务持有并使用
	IDLE = 3,          # 闲置态（等待复用或等待延迟释放）
	RELEASED = 4,      # 已解除业务引用与事件监听
	DISPOSED = 5       # 物理销毁（已调用 .free() / 关闭句柄）
}

## 资源分类标识
enum ResourceCategory {
	UI_CONTROL_NODE,   # 非 RefCounted UI 节点控件
	FILE_IO_HANDLE,    # 文件读写句柄与临时流
	EVENT_SUBSCRIPTION,# EventBus 信号回调与闭包
	DATA_CACHE_COLLECTION, # 内存字典、哈希表与静态缓存
	TIMER_COROUTINE,   # 定时器、异步任务与 Tick 调度
	CUSTOM_OBJECT      # 其它底层句柄或非引用计数对象
}

var resource_id: String = ""
var category: ResourceCategory = ResourceCategory.CUSTOM_OBJECT
var current_state: LifecycleState = LifecycleState.UNINITIALIZED
var owner_domain: String = ""
var created_tick_ms: int = 0
var last_accessed_ms: int = 0
var instance_ref: Variant = null # 弱引用或对象句柄

func to_dto() -> Dictionary:
	return {
		"resource_id": resource_id,
		"category": category,
		"current_state": current_state,
		"owner_domain": owner_domain,
		"created_tick_ms": created_tick_ms,
		"last_accessed_ms": last_accessed_ms
	}
```

### 2. 缓存策略规格模型 (`cache_policy_spec.gd`)

```gdscript
# 模块路径: res://backend/infrastructure/resource_governance/cache_policy_spec.gd
class_name CachePolicySpec extends RefCounted

enum EvictionPolicy {
	FIFO, # 先进先出
	LRU,  # 最近最少使用
	TTL,  # 基于生存时间过期淘汰
	MANUAL# 仅手动显式清理
}

var cache_name: String = ""
var owner_domain: String = ""
var max_capacity: int = 256
var ttl_seconds: float = 300.0 # <= 0 表示永不基于时间淘汰
var eviction_policy: EvictionPolicy = EvictionPolicy.LRU
var allow_hot_reload_clear: bool = true

func to_dto() -> Dictionary:
	return {
		"cache_name": cache_name,
		"owner_domain": owner_domain,
		"max_capacity": max_capacity,
		"ttl_seconds": ttl_seconds,
		"eviction_policy": eviction_policy,
		"allow_hot_reload_clear": allow_hot_reload_clear
	}

static func from_config(p_name: String, cfg: Dictionary) -> CachePolicySpec:
	var spec := CachePolicySpec.new()
	spec.cache_name = p_name
	spec.owner_domain = String(cfg.get("owner_domain", "system"))
	spec.max_capacity = maxi(1, int(cfg.get("max_capacity", 256)))
	spec.ttl_seconds = maxf(0.0, float(cfg.get("ttl_seconds", 300.0)))
	var pol_str: String = String(cfg.get("eviction_policy", "LRU")).to_upper()
	match pol_str:
		"FIFO": spec.eviction_policy = EvictionPolicy.FIFO
		"TTL": spec.eviction_policy = EvictionPolicy.TTL
		"MANUAL": spec.eviction_policy = EvictionPolicy.MANUAL
		_: spec.eviction_policy = EvictionPolicy.LRU
	spec.allow_hot_reload_clear = bool(cfg.get("allow_hot_reload_clear", true))
	return spec
```

### 3. 事件订阅注销凭证契约 (`event_subscription_token.gd`)

```gdscript
# 模块路径: res://backend/infrastructure/resource_governance/event_subscription_token.gd
class_name EventSubscriptionToken extends RefCounted

var source_signal: Signal
var callable_target: Callable
var is_active: bool = false

func _init(p_sig: Signal = Signal(), p_fn: Callable = Callable()) -> void:
	source_signal = p_sig
	callable_target = p_fn
	is_active = p_sig.is_valid() and p_fn.is_valid()

## 安全注销订阅，保证幂等性与零崩溃
func unsubscribe() -> bool:
	if not is_active:
		return false
	if source_signal.is_valid() and callable_target.is_valid():
		if source_signal.is_connected(callable_target):
			source_signal.disconnect(callable_target)
	is_active = false
	return true
```
