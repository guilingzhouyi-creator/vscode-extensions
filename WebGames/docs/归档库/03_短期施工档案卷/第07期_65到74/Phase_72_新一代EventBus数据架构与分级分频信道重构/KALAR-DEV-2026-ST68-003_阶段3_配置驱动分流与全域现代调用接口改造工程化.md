## 二、 首批核心领域现代调用改造示范（统一门面 + 统一借还 API）

不再使用 `emit_domain_event("hud.stat_mutated", {})`；试点服务经 `EventBusCore.get_instance()`（生产单例）与 `borrow_packet → dispatch_* → recycle_packet`。

### 1. `HudStateSyncService` 改造对接
* 模块路径: `res://backend/domains/world_state/hud_state_sync_service.gd`
* 说明: P71 交付该服务后，将其中推轨方法升级为 v2 原语（保留 P71 字符串叙事契约：事件包可选 `narrative_key/narrative_args`，渲染接线归 P74）。

```gdscript
static func publish_stat_mutation_v2(character_id: String, stat_name: String, old_val: float, new_val: float, cause: String = "") -> void:
	var bus := EventBusCore.get_instance()
	var packet := bus.borrow_packet(EventChannelDefinition.HUD_STAT_MUTATED, EventCategoryMask.CORE_STATE)
	packet.source_entity_id = character_id
	var mut := HudMutationEventsDTO.StatMutation.new()
	mut.character_id = character_id
	mut.stat_name = stat_name
	mut.old_value = old_val
	mut.new_value = new_val
	mut.delta = new_val - old_val
	mut.cause_event = cause
	packet.payload_dto = mut
	packet.narrative_key = "stat_mutated"
	packet.narrative_args = [stat_name, old_val, new_val]
	bus.dispatch_now(packet)
	bus.recycle_packet(packet)
```

### 2. `SpatialAudioSolver` 3D 空间声学改造对接（新增独立方法）
* 模块路径: `res://backend/domains/event_driven_audio/spatial_audio_solver.gd`
* 说明: **新增** `dispatch_spatial_audio_event` 静态方法（不改写既有 `evaluate_spatial_audio`）。

```gdscript
static func dispatch_spatial_audio_event(source_pos: Vector3, audio_cmd: RefCounted, max_dist: float) -> void:
	var bus := EventBusCore.get_instance()
	var packet := bus.borrow_packet(EventChannelDefinition.SPATIAL_AUDIO_PLAY, EventCategoryMask.SPATIAL_AUDIO)
	packet.payload_dto = audio_cmd
	bus.dispatch_spatial(packet, source_pos, max_dist)
	bus.recycle_packet(packet)
```
