## 一、 配置表结构映射 (Config Schema Mapping)

### 1.1 `config/infrastructure/log.json` 增补 `export` 段

```json
{
  "levels": { "debug": "DEBUG", "info": "INFO", "warn": "WARN", "error": "ERROR" },
  "default_level": "info",
  "format": "[%s] %s",
  "export": {
    "enabled": true,
    "directory": "user://logs",
    "file_prefix": "kalar",
    "max_bytes": 5242880,
    "max_files": 5,
    "min_level": "info",
    "include_channels": []
  }
}
```

**字段映射到 `LogExportConfigDTO`**：

| JSON 键 | DTO 字段 | 说明 |
| :--- | :--- | :--- |
| `enabled` | `enabled` | 总开关；false 时导出器零开销旁路跳过 |
| `directory` | `directory` | 导出目录；`user://logs` 用户数据区，禁止盘符/机器绝对路径 |
| `file_prefix` | `file_prefix` | 主文件名前缀（主文件 `kalar.log`；轮转归档按「前缀.unix时间戳.log」形态由导出器生成） |
| `max_bytes` | `max_bytes` | 单文件轮转阈值；0=不轮转 |
| `max_files` | `max_files` | 轮转保留份数；0=不清理 |
| `min_level` | `min_level` | 最低落盘级别（debug<info<warn<error） |
| `include_channels` | `include_channels` | 通道白名单；空数组=全部通道 |

**热重载语义**：`LogFileExporter._ensure_config_fresh()` 比对 `config_reload_version()`，热重载后自动重建（复用 Phase 64 P2 模式）。

## 三、 全域接线工程化 (Wiring & Engineering)

### 3.1 `EventBus` 接线

- `emit_log_record` 三路齐发（record 广播 + 前端信号转发 + 旁路导出），`log_message_posted` 既有消费方零改动；
- `ErrorReporter.emit_error` 内部统一构造 record 走 `emit_log_record`，全域错误上报唯一入口。

### 3.2 `main_dashboard` 日志终点适配（可选增强）

```gdscript
# frontend/views/main_dashboard.gd 增量：订阅 log_record_emitted，错误级高亮
func _ready() -> void:
    EventBus.get_instance().log_record_emitted.connect(_on_log_record)

func _on_log_record(record: LogRecordDTO) -> void:
    if record == null:
        return
    var color := _default_category_color()
    if record.level == "error":
        color = "#e57373"   # 错误级红显（与既有分类色体系并轨，色值可配置化）
    narrative_log.append_text("[color=" + color + "][LOG:" + str(record.level).to_upper() + "] " + record.message + "[/color]\n")
```

**要点**：错误级高亮为纯增量增强，既有 `_on_log_posted` 保留不删（兼容双路），色值收敛到 `frontend.ui` 配置段（零硬编码）。

### 3.3 热重载联动

- `GameConfig.reload_config()` 成功后，`LogFileExporter`/`ErrorCodeRegistry` 经 `config_reload_version()` 自动重建（与 Phase 64 全域静态缓存模式一致）；
- `EventBus` 广播 `config.security_reloaded` 事件后导出器下一跳消费即用新配置。
