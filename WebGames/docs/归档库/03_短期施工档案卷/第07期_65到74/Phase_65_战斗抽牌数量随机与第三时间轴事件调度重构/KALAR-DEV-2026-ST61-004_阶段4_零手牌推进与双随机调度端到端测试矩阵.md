## 一、 端到端测试用例矩阵清单 (Test Cases)

| 用例编号 | 测试场景 | 核心断言条件 |
| :--- | :--- | :--- |
| **TC-TR-01** | 首轮与普通回合数量随机 | 首次遇敌发牌数量在 $[3, 4]$ 区间；普通回合数量服从离散分布，大量抽样中 1~4 张均有产出且无 0 |
| **TC-TR-02** | 特殊影响产生 0 手牌 | 注入 `force_zero_hand` 减益时，`final_draw_count == 0`，`is_zero_hand_state == true`，未抛出异常 |
| **TC-TR-03** | 0 手牌时间轴持续推进保活 | 玩家 0 手牌且 0 AP，调用 `step_coordinator(3000)`，`round_ended == false`，时间轴成功前移 3000ms |
| **TC-TR-04** | 开局预排期与间距约束 | 回合启动即生成 2~4 个离散点，包含 NORMAL_DRAW 与 TENSION_PULSE，所有相邻点间距 $\ge 1500\text{ms}$ |
| **TC-TR-05** | 加发牌点到点触发抽卡 | 步进跨越 ADD_DRAW 点时，产生 `CARD_DISPATCHED` 事件且额外补充卡牌进入待发栏 |
| **TC-TR-06** | 跨回合修饰显式消费 | 第 1 回合留存的 `PendingTimelineModifier` 成功影响第 2 回合排期，且消费后标记已清空 |
| **TC-TR-07** | 前端只读快照脱敏验证 | 审查 `to_client_view()` 返回的字典，断言其无 `trigger_time_ms`、`next_event_in`，仅有 `progress_ratio` |
| **TC-TR-08** | 相同 Seed 确定性重演 | 两次使用 Seed=9999 初始化，生成的事件序列 ID、时刻与类型 100% 逐项完全吻合 |
