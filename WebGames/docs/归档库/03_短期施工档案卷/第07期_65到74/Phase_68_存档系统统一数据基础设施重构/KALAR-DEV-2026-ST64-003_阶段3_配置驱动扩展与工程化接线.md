## 一、 配置表结构映射 (Config Schema Mapping)

### 1.1 `config/infrastructure/domains.json` 增补 `save` 段

```json
{
  "id": "inventory",
  "narrative": "narratives.inventory",
  "save": {
    "enabled": true,
    "domain_version": 1,
    "serializer": "WearableInventoryAggregate",
    "strategy": "dirty",
    "hot_reload": { "allow": false, "requires_rebuild": false }
  }
}
```

**save 段字段映射**：

| JSON 键 | 消费方 | 说明 |
| :--- | :--- | :--- |
| `enabled` | `SaveDataAccessLayer._ensure_contracts_fresh` | 该域是否参与存档（false=排除） |
| `domain_version` | `SaveMigrationEngine.migrate_domain` | 域级数据版本（阶段1 三级版本模型） |
| `serializer` | 契约装配 | 提供 serialize/deserialize 的聚合类名（引用解析） |
| `strategy` | `SaveDataAccessLayer.flush_dirty` | `full`（全量）或 `dirty`（脏标记增量，高频域） |
| `hot_reload.allow` | `EditorHotReloadManager` | 是否允许编辑器热更新重载该域（Inv-SV-14） |
| `hot_reload.requires_rebuild` | `EditorHotReloadManager` | 更新是否需要重建运行时状态（战斗/经济=true，运行时拒绝热更） |

**实际登记建议（基于审计）**：

| 域 | enabled | strategy | hot_reload.allow | requires_rebuild | 依据 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| account | ✅ | full | false | false | 身份数据禁热更（一致性安全） |
| character | ✅ | full | false | true | 创角状态重建 |
| inventory | ✅ | **dirty** | false | false | 高频读写（Inv-SV-10/12） |
| item | ✅ | dirty | false | false | 高频持有数据 |
| lattice | ✅ | full | false | true | 技能 AST 重建 |
| world | ✅ | full | false | true | 世界状态重建 |
| progress | ✅ | full | false | false | 对账数据 |
| economy | ✅ | **dirty** | false | true | 高频 + 结算重建 |
| quest | ✅ | full | true | false | 任务配置可热更（规则层） |
| lifecycle | ✅ | full | false | false | 停机管线状态 |
| settings | ✅ | full | **true** | false | 玩家本地设置可热更 |

**关键决策**：战斗/经济域一律 `hot_reload.allow=false` 或 `requires_rebuild=true`——**运行时热更新绝不触碰确定性红线域**（与 P66/P67 红线一致）。

### 1.2 `config/infrastructure/persistence.json` 增补布局与迁移段

```json
{
  "format_version": "1.0.0",
  "engine": "KalarWorldEngine_Godot4",
  "schema_version": 1,
  "save_layout": {
    "root_sections": ["metadata", "account", "character", "inventory", "item",
                       "lattice", "world", "progress", "economy", "quest", "lifecycle", "settings"],
    "high_frequency_domains": ["inventory", "item", "economy"],
    "atomic_policy": "envelope"
  },
  "migration_rules": {
    "enabled": true,
    "registry": "persistence_protocol",
    "save_version_chain": ["1.0.0"]
  },
  "validation_rules": {
    "missing_field": "use_default",
    "type_mismatch": "coerce_or_drop",
    "unknown_domain": "warn_and_skip"
  },
  "hot_reload": {
    "enabled": true,
    "mode": "single_player_only",
    "hash_check": "content_sha256",
    "failure_policy": "rollback_and_keep_old_hash"
  }
}
```

**段字段映射**：

| JSON 段 | 消费方 | 说明 |
| :--- | :--- | :--- |
| `schema_version` | 布局迁移 | 存档布局整体版本（阶段1 三级版本之 Schema） |
| `save_layout.root_sections` | 布局组织 | 11 域 + metadata 的标准布局（按业务域组织，不过度碎片化） |
| `save_layout.high_frequency_domains` | 脏标记策略 | 高频域清单（inventory/item/economy 走增量保存） |
| `migration_rules` | `SaveMigrationEngine` | 迁移链配置（registry 指向持久化协议域；版本链可配置） |
| `validation_rules` | `SaveValidationService` | 缺失字段/类型不符/未知域三策略：use_default / coerce_or_drop / warn_and_skip |
| `hot_reload` | `EditorHotReloadManager` | 热更新总开关、单机限定、内容 Hash 校验、失败回滚策略 |

### 1.3 校验规则语义（一致性安全，对应 P68 第九节）

| 场景 | 配置策略 | 实现语义 |
| :--- | :--- | :--- |
| 缺失字段 | `use_default` | 从默认值来源（各域 config）恢复，不抛错 |
| 类型不符 | `coerce_or_drop` | 可强转则转（int/float/str），不可转则丢弃该字段并告警 |
| 未知数据域 | `warn_and_skip` | 跳过未知域 + 日志留痕（不阻断整档加载） |
| 部分损坏 | 域级隔离恢复 | 损坏域单独失败回滚，其余域正常恢复（阶段2 复制-校验模式） |
| 写入中断 | 原子写（既有） | tmp→bak→rename，正档不破坏（SaveManager 契约保持） |
| 迁移失败 | 回滚 | 保留旧档 + 错误码返回（Inv-SV-7） |
| 热更新失败 | `rollback_and_keep_old_hash` | 保持旧 hash 可重试，不静默半加载（Inv-SV-9） |
