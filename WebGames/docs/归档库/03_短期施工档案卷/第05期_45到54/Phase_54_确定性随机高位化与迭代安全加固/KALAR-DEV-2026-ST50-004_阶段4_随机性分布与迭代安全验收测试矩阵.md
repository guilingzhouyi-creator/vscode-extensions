# M2 核心注入：掷硬币交替回归（修复前红：旧实现 0,1,0,1 严格交替）
# 前置：DeterministicRNG.from_seed(20240917)

# 动作：对 4 元素池连续 pick 32 次
# 断言：无 ≤4 固定周期模式；4 个下标均出现

# 前置：setup 后推进至首个 RANDOM_DISPATCH 到期
# 动作：advance_time 数次跨过多个到期点
# 断言：事件在后续 advance 正常到期（连续 3 轮各有到期事件，无静默断供）

# M8 边界注入：interval_min_ms=0 死循环回归

# 断言：每次返回有限事件数、无卡死；scheduled_events 的 trigger 单调严格递增

# L10 核心注入：分隔符碰撞回归（修复前红：两字段对同键）
# 动作：_encode_composite_key(["rule1","a|b","c"]) vs (["rule1","a","b|c"])

### 3. 边界/容错用例

- `randi_range`：hi==lo → lo；hi<lo → lo（既有守卫回归）；`pick([])` → null；`pick` 单元素恒返回该元素；
- 时间轴空事件表 advance → 空返回、无副作用；
- 组合键含空串/长串（>10⁴ 字符）→ 编码无歧义、无性能异常。
