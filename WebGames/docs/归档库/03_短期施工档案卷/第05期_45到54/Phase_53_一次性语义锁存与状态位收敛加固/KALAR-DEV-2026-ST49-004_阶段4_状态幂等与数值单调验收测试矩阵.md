### 2. 核心注入用例设计（代表例）

```gdscript
# M6 核心注入：重复曝光 double-count 回归
# 前置：alias X 累积 30 赏金；第一次 trigger_unmask_exposure(X)
# 动作：第二次 trigger_unmask_exposure(X)
# 断言（修复前红）：base_true_infamy_bounty 只 +30 一次；第二次 transferred=0；
#       X.accumulated_infamy_bounty==0；X.is_compromised==true

# M7 核心注入：稳定性抬升回归
# 前置：stability=20（低于 failure_floor=40），failure_drop=15
# 动作：失败政变
# 断言（修复前红）：stability 仍 20（修复前 40 抬升）；再取 stability=60 → 45

# L9-b 核心注入：击败后重复结算
# 前置：boss hp 扣至 0（首次击败）
# 动作：再 apply_boss_damage ×3
# 断言（修复前红）：均返回 BOSS_ALREADY_DEFEATED；击败叙事/渠道结算仅发生一次

# L9-a 核心注入：水位只增不减
# 前置：同 sound_id 增计数至 max_concurrency_per_sound
# 动作：release_sound_instance 超量调用
# 断言（修复前红）：计数归零删键；再次 dispatch 不再 CONCURRENCY_LIMIT_REACHED
```

### 3. 边界/容错用例

- 败露时 alias 正处于 active（自动脱下）后 record_deed 落到真身；
- stability cur 恰等于 floor（cur==40、drop 任意）→ 不变（边界点不抬升不下跌）；
- 空 sound_id / 未登记 sound_id 的 release 调用 → 安全无副作用；
- 击败锁存后 serialize/deserialize 往返保持锁存位（存档续战不可复活）。
