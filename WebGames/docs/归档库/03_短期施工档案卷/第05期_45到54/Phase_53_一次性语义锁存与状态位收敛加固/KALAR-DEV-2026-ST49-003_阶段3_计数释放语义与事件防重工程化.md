## 一、 配置驱动与泛化扩展实现 (Configuration-Driven & Refactoring)

### 1. 音效水位释放事件回传通道契约（L9-a 接线登记）

| 契约项 | 落点 |
| :--- | :--- |
| 后端释放 API | `AudioBusPipeline.release_sound_instance(sound_id)`（阶段2 已定） |
| 回传事件 | 既有 `event_driven_audio` 域事件族新增生命周期事件（如 `audio.sound_finished`，载荷含 `sound_id`）；类别登记进 `config/infrastructure/event_categories.json` 既有音频类别段 |
| 宿主侧订阅 | 表现层音频宿主在播放自然结束/被截停处 emit 上述事件 → 后端 `release_sound_instance` |
| 本卷边界 | 后端 API + 事件契约 + 事件类别登记在**本卷闭环**；表现层宿主接线若超出后端域范围，按「高阶集成断言可延后至前端卷」条款登记，不阻塞本卷验收 |

一次性语义锁存模式（2026-09-04 登记，来源 Phase 53）：
