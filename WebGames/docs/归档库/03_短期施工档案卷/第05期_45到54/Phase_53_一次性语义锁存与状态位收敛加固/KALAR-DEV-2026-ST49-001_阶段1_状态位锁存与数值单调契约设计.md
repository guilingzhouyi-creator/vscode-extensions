## 一、 数据结构设计与代码契约 (Data Structures & Code Contracts)

### 1. 一次性语义锁存契约（M6 / L9-b 共用模式）

```gdscript
# 锁存模式：变更入口先查锁存位，锁存即幂等返回；首次执行置位 + 副作用原子完成
# 适用：alias.is_compromised（M6）/ boss.is_defeated（L9-b）
# 统一语义：
#   ① 入口守卫：if state.latch: return 幂等成功（携带首次结果或 ALREADY_* 错误码）
#   ② 执行体：副作用（合并/广播/结算）仅在 latch 由 false→true 的同一临界区发生一次
#   ③ 状态量清零：搬运类副作用完成后源字段归零（Inv-ON-2）
```

### 2. 败露状态字段契约（M6 落点）

| 字段 | 现状 | 契约修正 |
| :--- | :--- | :--- |
| `AliasProfile.is_compromised` | 置 true 但入口不查 | `trigger_unmask_exposure` 入口先查：已 compromised → 幂等返回（`success:true, transferred_infamy_bounty:0, already:true`） |
| `AliasProfile.accumulated_infamy_bounty` | 合并后残留 | 合并进 `base_true_infamy_bounty` 后**归零**（Inv-ON-2）；归零后再触发天然幂等（0 搬运） |
| `record_deed` 对已败露 alias | 仍向其累积 | 守卫：目标 profile 已 compromised → 恶名/声望直接路由真身 `base_true_*`（防锁存后通道继续累积） |

### 3. 稳定性衰减单调契约（M7 落点）

```gdscript
# 契约公式（替代 max(floor, cur - drop) 的抬升式写法）：
#   仅当 cur > floor 时才允许下跌，且下跌止于 floor；cur <= floor 时保持不变（绝不抬升）
#   单调性：new_stability <= cur_stability 恒成立（Inv-ON-3）
func _apply_stability_drop(cur: float, drop: float, floor: float) -> float:
    if cur <= floor:
        return cur                          # 已低于下限：不抬升、不再跌
    return maxf(floor, cur - drop)          # 从上方下跌，止于下限
```

语义定论（登记进 `sovereignty` 域注释）：`success_floor` / `failure_floor` 的含义为「该结果下**从上方下跌**的止点」；不代表「低于下限时可被垫高」。（若产品意图确为「失败政变保底稳定性 ≥ 下限」，则属需求变更，须另行立项——本卷按单调不升收敛。）

### 4. 并发水位计数释放契约（L9-a 落点）

| 契约项 | 设计 |
| :--- | :--- |
| 显式减路径 | `AudioBusPipeline.release_sound_instance(sound_id: String) -> void`：`active_sound_counts[sound_id] = maxi(0, active_sound_counts[sound_id] - 1)`，归零即删键（防 0 值堆积） |
| 减的触发源 | 播放宿主（表现层）在音频自然结束/被截停时经既有 EventBus 域事件回传（事件类别沿用 `event_driven_audio` 现有域事件，不新造传输通道） |
| 防负不变量 | `Inv-ON-4`：减操作一律 `maxi(0, …)` 下钳制；增/减并发交错不产生负计数 |
| 水位语义登记 | `max_concurrency_per_sound` 释义更新为「**同一时刻在播实例上限**」（以生命周期事件闭环计），不再是「历史累计发放上限」 |

### 5. 击败锁存契约（L9-b 落点）

| 契约项 | 设计 |
| :--- | :--- |
| 锁存字段 | `PhaseTransitionFSM` 增加 `is_defeated: bool`（或并入既有终态枚举，实现轮按状态机结构择一） |
| 受击入口守卫 | `apply_boss_damage` 在 `is_defeated` 为 true 时直接返回 `{"success": false, "error_code": "BOSS_ALREADY_DEFEATED"}`，不再结算 |
| 结算单次性 | 击败叙事广播与 `consume_event_channel` 渠道调整仅在 `is_defeated` false→true 临界区执行一次（Inv-ON-1） |
