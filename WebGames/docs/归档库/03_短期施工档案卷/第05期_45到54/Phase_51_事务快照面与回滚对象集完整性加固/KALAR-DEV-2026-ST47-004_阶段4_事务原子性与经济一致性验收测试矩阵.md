### 2. 核心注入用例设计（M1 代表例）

```gdscript
# M1：刷保底回归注入（满背包触发整批退款）
# 前置：banner.total_lifetime_pulls=89、current_pity_count=89、is_next_guaranteed_up=true
# 注入：inventory 容量置 0 → execute_multi_pull(10) 命中 grant_failed_count>0
# 断言：返回 REWARD_COMMIT_FAILED；banner 三字段 == 抽前（89/89/true）；
#       wallet 余额 == 抽前；inventory 快照等价（无部分发放残留）
```

### 3. 边界/容错用例设计（M5、M9 代表例）

- M5：穿戴武器（loadout 槽 weapon）销毁且产物回流失败 → 断言 `inventory.equipped_slots["weapon"]` 与 `loadout` 槽最终指向**同一 item_uid**，且 `container_state != "DESTROYED"`；
- M9：`deserialize({unassigned: 12, lifetime: 5})` → 断言 `unassigned==5`；`calculate_respec_cost` 对直接构造的越序 engine → 断言 `crystal_cost==0` 且 `wallet.mana_monocrystals` 扣减前后不减反增不可能发生（delta ≥ 0）。
