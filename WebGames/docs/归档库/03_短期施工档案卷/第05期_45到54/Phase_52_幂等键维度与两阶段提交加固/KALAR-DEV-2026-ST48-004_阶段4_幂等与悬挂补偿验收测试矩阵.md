### 2. 核心注入用例设计（M3/M4 代表例）

```gdscript
# M3 核心注入：跨账户同 mail_id 错配回归
# 前置：账户 A、B；两条 CDK 邮件 mail_id 均为 "CDK_SAME_SECOND"（构造同秒旧格式）
# 动作：A.claim_single_mail → B.claim_single_mail
# 断言（修复前红）：B 不再命中 A 的缓存结果；B 的附件/货币真实到账（success 且金额 == B 附件）

# M3 生成侧注入：同秒连发
# 动作：同账户循环 dispatch 100 条（不传 mail_id）
# 断言：100 条投递全部 success、mail_id 两两互异、无 get_mail_by_id 拒绝

# M4 核心注入：投递失败不烧码
# 前置：构造信箱拒绝（满箱/重复 id）
# 动作：redeem → 投递失败
# 断言：code 仍可重试（CLAIMM_PENDING）；current_global_redemptions 未 +1（修复前红：先烧后悬挂）

# M4 补偿注入：超时释放
# 前置：ttl_ms=0、max_retry=0（配置注入）
# 动作：触发补偿判定
# 断言：code=RELEASED、PENDING 清理、再次领取成功
```

### 3. 边界/容错用例

- 同账户重复领取（缓存命中）不重复入账（金额/物品只加一次）；
- 补偿通道总开关 `enabled=false` 时 PENDING 保留不释放（运维期语义）；
- 显式传入 mail_id 的既有调用路径回归（外部幂等键语义不变）。
