## 📋 二、 归档准入与质量门禁

1. **四阶段特化闭环**：归档前必须通过 `verify_stage_distinctness` 检查，确保阶段 1（数据契约）、阶段 2（业务实现）、阶段 3（配置驱动）、阶段 4（验收测试）完全特化，严禁样板化复制；
2. **全量测试通过**：关联的无头单元测试（`test-run.ps1`）与静态审查（`audit-all.ps1`）必须 100% PASS；
3. **自动化同步**：归档时自动编制标准档号，并同步更新 [卡拉尔全宗档案总目录与元数据库.md](../卡拉尔全宗档案总目录与元数据库.md)。
