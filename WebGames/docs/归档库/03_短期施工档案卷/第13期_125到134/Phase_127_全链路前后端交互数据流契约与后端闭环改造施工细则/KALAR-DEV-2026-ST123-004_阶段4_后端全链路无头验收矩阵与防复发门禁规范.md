| :--- | :--- | :--- | :--- |

| **TC-P127-03** | 序章交接 L3 属性与出生点防失真 | 经 `WorldGatewayFSM.handoff_prologue_to_world_exploration` 推入序章产出 | HUD 首帧快照准确携带 `attribute_values`、`attribute_levels` 与 `current_location_id` |
| **TC-P127-04** | 主页 HUD 常驻同步与脏标节流 | `WorldSessionRuntimeService` 连续 10 次微观突变 + 拉取/推送对比 | 节流窗口内合并广播不风暴；主动 Pull 与事件 Push 数值严格同源对齐，无硬编码假数据 |
| **TC-P127-05** | ESC 退回网关严禁 3 字段覆盖真档 | 先写入完整多域存档，再在未挂提供者态及已挂提供者态分别触发 `ESC_EXIT_TO_GATEWAY(auto_save=true)` | 未就绪态显式阻断返回 `ERR_INCOMPLETE_SAVE_BLOCKED` 且磁盘原存档字节完整保留；就绪态写回完整多域新档 |
| **TC-P127-06** | 活跃世界热切换网关阻断与退世界探针刷新 | 探索态发 `SWITCH_GATEWAY_MODE`；再发 `EXIT_WORLD_TO_GATEWAY` 后重新切换模式 | 探索态强拦截返回 `ERR_HOT_SWAP_BLOCKED_IN_ACTIVE_WORLD`；退世界后 `RuntimeModeGate` 清零且 `ModeReadinessProbe` 报告已刷新 |
| **TC-P127-07** | 协议令牌脱敏、权限校验与注销吊销 | 检查内存会话令牌经 `ClientSecretVault` 脱敏；执行 `LOGOUT_ACCOUNT` 后复用旧令牌发写指令 | 内存态无明文敏感 token；注销后复用旧令牌返回 `ERR_UNAUTHORIZED`；账号首页查询不泄密 |
| **TC-P127-08** | 生命周期诚实停机失败断言 | 在无完整提供者下请求 `REQUEST_GRACEFUL_SHUTDOWN(save_before_quit=true, force_quit=false)` 与 `force_quit=true` | 非强制停机下返回 `success=false, is_save_completed=false` 且状态机未误入 `STOPPED`；`force_quit=true` 明确记入 `degraded_resources` |
| **TC-P127-09** | 双轮启动-解体对称隔离校验 | 连续执行两轮完整 `GameBootstrap` 装配、会话运行与 `teardown()` | 第 2 轮启动前账号会话、世界档案锁定、租约表、协议池 dirty 标志均为纯净初值 |
