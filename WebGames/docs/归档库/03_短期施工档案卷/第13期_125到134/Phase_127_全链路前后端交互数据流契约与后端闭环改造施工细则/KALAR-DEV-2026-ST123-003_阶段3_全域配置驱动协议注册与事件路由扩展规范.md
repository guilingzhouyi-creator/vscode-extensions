## 一、 JSON 配置表与契约真源扩展明细

### 1.1 `config/infrastructure/contracts.json` 全链协议注册扩展

在完整保留现有 49 条 `entries` 仪表盘与域契约校验基线（`entry_count_expected = 49`）的前提下，于 `contracts.json` 新增 `protocol_flows` 全 11 环交互契约索引映射表，覆盖以下域与协议前缀：

| 契约 ID 前缀 | 归属领域 `domain_name` | 目标视图 `view_name` | 端点类型 `endpoint_kind` | 覆盖环节与关键契约方法/事件 |
| :--- | :--- | :--- | :--- | :--- |
| `CT-ACCT-FLOW-*` | `account` | `account_entry` | `CMD_MUTATION` / `QUERY_READONLY` | `REGISTER_ACCOUNT`、`LOGIN_LOCAL`、`LOGIN_COMPOSITE`、`LOGOUT_ACCOUNT`、`GET_ACCOUNT_HOME_VIEW_MODEL` |
| `CT-GATE-FLOW-*` | `world_gateway` | `account_entry` | `CMD_MUTATION` / `QUERY_READONLY` | `ENTER_GATEWAY`、`PROBE_MODES`、`SELECT_MODE`、`LIST_WORLDS`、`SELECT_OR_CREATE_WORLD`、`EXIT_WORLD_TO_GATEWAY`、`SWITCH_GATEWAY_MODE` |
| `CT-CHAR-FLOW-*` | `character_creation` | `account_entry` | `CMD_MUTATION` / `EVENT_PUSH` | `ROLL_CHARACTER_PREVIEW`、`CREATE_AUTHORITATIVE_CHARACTER`、`OPENING_EVENT_STREAM` |
| `CT-PRLG-FLOW-*` | `character_creation` | `cutscene_player` | `CMD_MUTATION` / `EVENT_PUSH` | `START_PROLOGUE`、`ADVANCE_PROLOGUE`、`COMPLETE_PROLOGUE`、`SKIP_PROLOGUE`、`PROLOGUE_COMPLETED` |
| `CT-HUD-SYNC-*` | `world_state` | `main_hud` | `QUERY_READONLY` / `EVENT_PUSH` | `PULL_HUD_SNAPSHOT`、`TICK_WORLD_CLOCK`、`HUD_STATUS_SNAPSHOT`、`HUD_STAT_MUTATED`、`HUD_WALLET_MUTATED`、`WORLD_CLOCK_ADVANCED` |
| `CT-ESC-FLOW-*` | `world_state` | `system_save` | `CMD_MUTATION` / `QUERY_READONLY` | `ESC_GET_MENU_STATE`、`ESC_SAVE_GAME`、`ESC_EXIT_TO_GATEWAY`、`ESC_QUIT_GAME`、`ESC_APPLY_SETTINGS` |
| `CT-LIFE-FLOW-*` | `persistence_protocol` / `lifecycle` | `system_save` | `CMD_MUTATION` / `EVENT_PUSH` | `REQUEST_GRACEFUL_SHUTDOWN`、`LIFECYCLE_SHUTDOWN_COMPLETED` |

### 1.3 `domains.json` 与文案表联动审计边界

1. 核对 `world_state`、`world_gateway`、`account`、`character_creation`、`persistence_protocol` 在 [`domains.json`](../../../../../config/infrastructure/domains.json) 中的 `depends_on`：若 `WorldSessionRuntimeService` 读取 `combat.participant_defaults` 等跨表配置，需确认使用已有 `shared_tables` 豁免表或补齐合法依赖声明，禁止跨 `domains.*` 隐式偷读。
2. 所有新错误码与提示 Key（如 `ERR_HOT_SWAP_BLOCKED_IN_ACTIVE_WORLD`、`ERR_INCOMPLETE_SAVE_BLOCKED`、`ERR_SAVE_FLUSH_FAILED`、`ERR_UNAUTHORIZED`）须遵循配置化错误文案映射契约，不得在业务逻辑中拼接面向用户的硬编码提示正文。
