## 一、 核心架构分层契约

1. **全领域 `ServiceLocator` 与真实服务注入闭环 ([service_locator.gd](../../../../../frontend/domain_boundary/service_locator.gd) · [real_service_container.gd](../../../../../frontend/domain_boundary/services/real_service_container.gd))**:
   - 为 `version`、`crafting`、`economy`、`gacha`、`grimoire`、`guild`、`mail`、`misc_edge`、`quest`、`save`、`combat`、`chat_command` 与 `snapshot_data` 提供面向真实后端求解器与 `GameConfig` / `WorldSessionRuntimeService` 的 `Real*Service` 实现并在 `RealServiceContainer` 全量注册，使 `"real"` 模式彻底脱离对 `MockServiceContainer._register_shared_mock_services()` 的运行时依赖。
   - [test_frontend_boundary_guard.gd](../../../../../tests/guards/test_frontend_boundary_guard.gd) 扩展审计 `frontend/views/` 与 `frontend/systems/` 严禁直调 `MockServiceContainer`，并断言 `config/frontend/ui.json` 的 `service_mode == "real"`。
2. **多命名空间物品标识与基座中性化 ([item_registry_solver.gd](../../../../../backend/domains/item_namespace_registry/item_registry_solver.gd) · [views.json](../../../../../config/frontend/views.json))**:
   - `ItemRegistrySolver` 采用泛化命名空间前缀规则（首位段匹配 `^[A-Z][A-Z0-9_]*$`，至少 4 段且每段非空、无空白或非法字符），[audit_item_keys.py](../../../../../scripts/py/audit_item_keys.py) 同步兼容多命名空间检查。
   - 清理 [views.json](../../../../../config/frontend/views.json)、[ui.json](../../../../../config/frontend/ui.json) 及基座配置中残留的卡拉尔剧情专有名词，迁入官方 MOD [official_kalar](../../../../../mods/official_kalar/pack.json) 并对齐 `views.json` 全端视图契约键。
3. **MOD SDK 强校验、模板完备与工具链去硬编码 ([check_mod.py](../../../../../mod_sdk/tools/check_mod.py) · [total_conversion_sample](../../../../../mod_sdk/templates/total_conversion_sample/pack.json))**:
   - `kalar_mod.py check` 接入 `mod_sdk/schemas/*.schema.json` 强结构校验；`preview_mod.py`、`play_mod*.py` 与 `scaffold_mod.py` 剥离对卡拉尔地名与默认出身的强绑定；补齐 `total_conversion_sample` `destinies.json` 与声明图标资产，确保 CLI 与引擎端 `ModPackageDiscoverySolver` 双侧一次通过。
4. **静态门禁精度、测试覆盖一致性与泄漏防线 ([audit_refactor_metrics.py](../../../../../scripts/py/audit_refactor_metrics.py) · [test_runner.gd](../../../../../tests/test_runner.gd))**:
   - `audit_refactor_metrics.py --strict` 阻断 `gateVerdict == "blocked"`；重构 [unified_protocol_dispatcher.gd](../../../../../backend/domains/world_state/services/unified_protocol_dispatcher.gd) `_enforce_auth_guard` 至圈复杂度 $\le 15$；消除 [asset_path_resolver.gd](../../../../../backend/infrastructure/resource_governance/asset_path_resolver.gd) 编译期 `char(0)` 导致的 NUL 解析告警与 [attribute_init_solver.gd](../../../../../backend/domains/character_creation/attribute_init_solver.gd) `%` 占位符格式报错；闭合 [code_governance_rules.json](../../../../../scripts/config/code_governance_rules.json) 与各审计器规则消费映射；[test-run.ps1](../../../../../scripts/ps1/test-run.ps1) / [test-run.sh](../../../../../scripts/sh/test-run.sh) 增加实例与 RID 泄漏检测，[test_fe_runner.gd](../../../../../tests/test_fe_runner.gd) 对齐全量前端套件。
