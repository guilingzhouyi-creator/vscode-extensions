### 1.2 核心不变量约束断言

- **全信道无遗漏监听不变量 (Inv-HUD-FULL-CHANNELS-1)**：`HudEventBridge` 必须完整订阅 `AuthoritativeHudSyncService.subscribe_hud_channels` 暴露的全部 6 个信道（全量快照、金币钱包、序章交接、进入世界、单项属性实值突变、世界时钟推进），严禁遗漏任何专用子信道导致 UI 状态停滞。
- **主动快照协议可控不变量 (Inv-HUD-PULL-FACADE-2)**：`HudEventBridge` 必须暴露 `pull_hud_snapshot_async()` 协议方法，允许在视图挂载或场景恢复时通过 `UnifiedProtocolDispatcher` 主动拉取当前常驻权威状态，严禁视图依赖任何本地硬编码 Mock 初值。
- **待命零接线架构安全不变量 (Inv-STANDBY-UNWIRED-3)**：`CutsceneEventBridge` 保持待命零接线模式，通过总线监听自动响应 `prologue.` 与 `cutscene.` 领域事件，并提供标准宿主挂载接口与跳过回调，严禁在业务视图中硬编码调用。
- **配置驱动单源不变量 (Inv-CONFIG-SSOT-4)**：所有新增领域服务的注册配置、超时时间、协议动作别名与事件信道名称必须全部在 `config/` 下的 JSON 配置表中登记，严禁在 GDScript 中出现裸字符串与魔法数字。

### 1.3 工程化重构最高指示

事件桥接器与服务容器必须遵循循环零堆分配原则（`ADV-PRF-002`），所有事件包解析必须兼容强类型 `payload_dto` 与字典 `payload_data` 双载荷；单例与服务容器必须具备对称的 `reset_for_tests()` 重置接口以保证测试隔离性。

## 一、 全信道事件桥接扩展与全域配置驱动路由设计

### 1.1 `HudEventBridge` 全 6 信道订阅扩展与主动拉取

对 [`HudEventBridge`](../../../../frontend/systems/hud_event_bridge.gd) 进行增量增强：
1. **补齐第 5、6 回调函数**：
   - `_on_stat_mutated(pkt: Variant) -> void`：解析 `HUD_STAT_MUTATED`（`0x0102`）单项属性实值突变事件包，构造增量快照并通过 `view.apply_snapshot` 刷新；
   - `_on_clock_advanced(pkt: Variant) -> void`：解析 `WORLD_CLOCK_ADVANCED`（`0x0201`）时钟推进事件包，提取年月日与纪元信息，构造时钟视图数据并单向刷新。
2. **主动拉取协议入口**：
   - 增加 `pull_hud_snapshot_async(callback: Callable = Callable()) -> void`：
     通过 `UnifiedProtocolFactory.create_human_request("world_state", "PULL_HUD_SNAPSHOT", {})` 发送请求；
     在回执到达时将权威快照转换后直接注入绑定的 `MainHUDView`（若当前视图已挂载），并回调通知上层。

### 1.2 `CutsceneEventBridge` 待命挂载与序章转场契约完善

1. 保持现有待命消费架构，增加与 `WorldSessionRuntimeService` 的序章上下文挂钩方法；
2. 暴露 `trigger_prologue_cutscene(prologue_session_id: String)`，自动拉取当前剧场 CG 描述并通过总线分发，驱动视口播放；
3. 当收到 `presentation_finished` 或 `presentation_skipped` 时，向 `UnifiedProtocolDispatcher` 发送 `COMPLETE_PROLOGUE` 或 `SKIP_PROLOGUE` 信封，推动状态机进入正式探索态。

### 1.3 `RealServiceContainer` 真实服务全量装配

重构 [`RealServiceContainer._init_default_services`](../../../../frontend/domain_boundary/services/real_service_container.gd)：
```gdscript
func _init_default_services() -> void:
    register_service("auth", RealAuthService.new())
    register_service("world", RealWorldService.new())
    register_service("character", RealCharacterService.new())
    register_service("esc_menu", RealEscMenuService.new())
    register_service("save", MockSaveService.new()) # 保持渐进式装配
    # ... 其余未实现域平滑回退至 Mock 服务
```
并在 `RealServiceContainer` 中增加强类型访问快捷门面：
- `func esc_menu() -> IEscMenuService`

### 1.4 `GameConfig` 契约注册表扩展

在 [`config/infrastructure/contracts.json`](../../../../config/infrastructure/contracts.json) 与 [`config/domains/world_state/core.json`](../../../../config/domains/world_state/core.json) 中追加：
- `world_state/hud_pull_throttle_ms`: 200
- `frontend/services/real_container_bindings`: 显式映射 `auth`, `world`, `character`, `esc_menu` 至对应的 Real 类路径。
