### 1.2 核心不变量约束断言

- **网关单源引用不变量 (Inv-GATEWAY-SSOT-1)**：`ServiceLocator` 中的 `get_active_gateway()`、`create_and_activate_gateway()` 与 `clear_active_gateway()` 必须全面收敛至 [`WorldSessionRuntimeService`](../../../../../backend/domains/world_state/services/world_session_runtime_service.gd)，严禁在前端持有脱节的第二网关实例。
- **真实创角必须落盘与水化不变量 (Inv-AUTHORITATIVE-CREATION-2)**：创建角色协议调用必须经由 [`UnifiedProtocolDispatcher`](../../../../../backend/domains/world_state/services/unified_protocol_dispatcher.gd) 触发 `WorldCharacterCreationOrchestrator`，完成真实物理存档落盘、初始装备槽位水化与序章上下文绑定，严禁使用前端轻量解算器伪造空壳槽位。
- **会话销毁双向对称不变量 (Inv-SESSION-TEARDOWN-3)**：执行退出账号（`revoke_token` / `logout_async`）必须向统一派发中枢发送 `LOGOUT_ACCOUNT` 请求，同步吊销 `AuthService` 内存掩码并清理 `WorldSessionRuntimeService` 活跃会话。
- **ESC 存盘退出诚实阻断不变量 (Inv-ESC-VERDICT-INTEGRITY-4)**：ESC 退出与存盘必须根据 `UnifiedResponseEnvelopeDTO.success` 作出确定性判定，在后端 `SaveReadinessGuard` 阻断或磁盘满载时明确返回失败原因，严禁无条件跳转。

### 1.3 业务实现最高指示

所有新增适配器必须继承对应的领域接口（如 `IAuthService`、`IWorldService`、`ICharacterService`、`ISaveService`），方法一律采用异步回调（`callback: Callable`）签名以解耦调用线程；所有请求数据必须封装为强类型 `ClientRequestEnvelopeDTO`，杜绝字典裸传与魔法字符串。

## 一、 领域边界适配器实现与双网关脱节治理核心设计

### 1.1 `ServiceLocator` 网关单源治理方案

将 `ServiceLocator` 中的独立静态变量 `_active_gateway` 废除，转为代理委托模式：
1. `create_and_activate_gateway(account_id)`：创建 `WorldGatewayFSM` 后立即调用 `WorldSessionRuntimeService.bind_gateway(gw)` 与 `WorldSessionRuntimeService.activate_authenticated_session(account_id, "", gw)`；
2. `get_active_gateway()`：直接返回 `WorldSessionRuntimeService.get_gateway()`；
3. `clear_active_gateway()`：调用 `WorldSessionRuntimeService.bind_gateway(null)` 与清理。

### 1.2 `RealAuthService` 完善与链路闭环

1. **补齐注销能力**：
   - 增加 `revoke_token(token: String, callback: Callable = Callable()) -> void`；
   - 增加 `logout_async(account_id: String, token: String, callback: Callable) -> void`；
   - 内部封装 `action_type = "LOGOUT_ACCOUNT"`，发送至 `UnifiedProtocolDispatcher.dispatch_request`，并在成功后执行 `WorldSessionRuntimeService.teardown_account_session()`。
2. **补齐首页视图模型拉取**：
   - 增加 `get_account_home_async(account_id: String, token: String, callback: Callable) -> void`；
   - 封装 `action_type = "GET_ACCOUNT_HOME_VIEW_MODEL"` 请求，返回包含历史账号、槽位列表与系统配置的聚合数据，替代旧有 Mock 快照。
3. **修复登录与注册会话激活**：
   - `login_async` 成功后，自动调用 `WorldSessionRuntimeService.activate_authenticated_session(resp.account_id, resp.session_token)`；
   - `register_async` 返回正规账号元数据，不签发未鉴权伪令牌。
4. **属性资质骰点收敛**：
   - `roll_attributes_async(callback: Callable) -> void`：封装 `character_creation` / `ROLL_CHARACTER_PREVIEW` 动作，统一后端确定性规则。

### 1.3 新增 `RealWorldService`（实现 `IWorldService`）

新建 `frontend/domain_boundary/services/real_world_service.gd`：
- `enter_gateway_async(account_id: String, token: String, callback: Callable) -> void`
- `probe_modes_async(account_id: String, token: String, callback: Callable) -> void`
- `list_worlds_async(account_id: String, token: String, callback: Callable) -> void`
- `select_mode_async(account_id: String, token: String, mode_id: int, account_slots: Array, callback: Callable) -> void`
- `switch_gateway_mode_async(account_id: String, token: String, target_mode: int, callback: Callable) -> void`
- `exit_world_to_gateway_async(account_id: String, token: String, callback: Callable) -> void`
全部通过 `UnifiedProtocolFactory.create_human_request` 构建信封并送入 `UnifiedProtocolDispatcher` 执行。

### 1.4 新增 `RealCharacterService` 与权威创角适配

新建 `frontend/domain_boundary/services/real_character_service.gd`：
- `create_character_async(account_id: String, token: String, req_data: Dictionary, callback: Callable) -> void`：
  封装 `action_type = "CREATE_AUTHORITATIVE_CHARACTER"`，向 `UnifiedProtocolDispatcher` 提交；
  后端触发 `WorldCharacterCreationOrchestrator` 生成完整多域存档文件，挂载初始物品，初始化 `PrologueContext` 并完成槽位绑定；
  返回权威生成的 `character_id`、`slot_id` 与水化后的 `CharacterProfile`。

### 1.5 新增 `RealEscMenuService`（实现 `IEscMenuService`）

新建 `frontend/domain_boundary/services/real_esc_menu_service.gd`：
- `get_menu_state_async(callback: Callable) -> void`：调用 `ESC_GET_MENU_STATE`，返回 `can_save`、`is_dirty` 与 `allowed_actions`；
- `request_save_async(target_slot: String, is_quicksave: bool, callback: Callable) -> void`：自动提取当前活跃会话令牌与账号 ID 发送 `ESC_SAVE_GAME`；
- `exit_to_gateway_async(callback: Callable) -> void`：发送 `ESC_EXIT_TO_GATEWAY`，校验 `_response.success`；
- `quit_game_async(callback: Callable) -> void`：发送 `ESC_QUIT_GAME`，校验存盘完成后触发停机。
