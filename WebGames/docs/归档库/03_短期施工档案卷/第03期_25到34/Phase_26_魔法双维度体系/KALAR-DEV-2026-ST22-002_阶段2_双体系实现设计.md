## 一、 实现设计（双体系 + 弱映射）

### 1.1 MagicRank 去嵌套化（阶位梯度维度）

```gdscript
# magic_tier_snapshot.gd —— 阶位梯度（纯连续 1~11，无能力分级前缀）
enum MagicRank {
	RANK_1 = 1, RANK_2, RANK_3, RANK_4, RANK_5,
	RANK_6, RANK_7, RANK_8, RANK_9, RANK_10, RANK_11,
}
## 阶位单调映射：MagicRank -> 1~11（唯一事实源，严格递增，禁跨级倒置）
static func rank_to_level(rank: MagicRank) -> int:
	return int(rank)   # 枚举值即阶位号（1~11 连续）
```

- 嵌套前缀（MORTAL_/HEROIC_/DIVINE_/GOD_）**彻底移除**——阶位名不再携带能力等级语义；
- `SUPERTIER` 从 MagicRank **移出**（归能力分级维度 1.2）；
- `magic_form` / `mana_aptitude` / 战斗实力等既有枚举不变（非本次纠正范围）。

### 1.2 AbilityTier 独立枚举（能力分级维度，新增）

```gdscript
# magic_tier_snapshot.gd —— 能力分级（施法主体/存在总体能力层次与身份范畴）
enum AbilityTier {
	ESP = 1,      # 异能
	HEROIC,       # 英雄
	DIVINE,       # 神圣
	GOD,          # 真神
	SUPERTIER,    # 超位（真神之上/超越位阶上限的特殊存在）
}
```

- 独立于阶位梯度；每等经配置段 `ability_tiers` 携带：`name_key`（`magic.ability_tier.*`）+ **参考区间**（weak interval，允许重叠）+ 权重 + 参考标签；
- 能力分级**不直接决定**施法者施展具体魔法的阶位（平行维度）。
