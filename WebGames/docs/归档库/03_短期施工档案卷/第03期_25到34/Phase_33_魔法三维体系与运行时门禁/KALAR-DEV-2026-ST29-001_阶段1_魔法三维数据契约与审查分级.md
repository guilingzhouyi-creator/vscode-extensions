## 一、审查问题分级

| 类型 | 已识别问题 | 处理原则 |
| :--- | :--- | :--- |
| 规范违规 | `MagicTierRegistry` 未由 `GameBootstrap.assemble()` 统一装配；注册表和解析器的所有权边界不完整 | 将魔法注册表纳入唯一启动入口，禁止消费方自行构造或绕过 |
| 规范违规 | `MagicTierRegistry` 未强制 `_tiers.size() == 5`、资质/形态数量及 key/value 一致性；`rank_bands` 重叠区间未拒绝 | 失败即不可用，配置键、枚举值、entry 字段逐项对齐 |
| 设计缺陷 | `MagicBaselineResolver` 返回的 `ability_tier` 是候选数组，而 `MagicTierSnapshot.ability_tier` 是单枚举 | 将主体能力分级标量与弱映射候选集合分成不同字段，禁止隐式类型转换 |
| 设计缺陷 | 静态 `MagicAbilityTierResolver`/`MagicRankBandResolver` 直接读 `GameConfig`，绕过已校验 registry | 解析器只消费注入的不可变快照或 registry 查询接口 |
| 潜在风险 | `MagicTierSnapshot.from_dto()` 对范围、形态配对、能损区间和档次一致性缺少拒绝路径 | 反序列化必须先校验再构造，错误可定位、不可静默归一化 |
| 潜在风险 | `rank_to_level()` 对非法值静默返回 1，可能把坏数据伪装为一阶 | 非法值返回显式错误/未登记值；仅展示层允许配置化安全兜底 |
| 可维护性问题 | `_register_one()` 访问 `LocalizationRegistryCatalog._locale_dictionaries` 私有字段；热重载后旧名称键可能残留 | 提供公开只读查询和按域替换/撤销 API，登记动作集中在 registry |
| 性能问题 | 每次基线解析都重复读取配置表并遍历字典 | 装配期构建索引，运行时只读快照；以基准确认收益 |
| 可选优化 | 为三维快照提供不可变视图、版本化缓存和调试导出 | 不改变 DTO 语义，不以抽象层数量替代实际护栏 |

## 二、三维度数据契约

| 维度 | 类型与字段 | 不变量 |
| :--- | :--- | :--- |
| 阶位梯度 | `MagicRank`、`rank_gradient`、level、strength_weight | 1~11 连续递增；键为 `magic.rank.rank_N`；不含能力或档次前缀 |
| 主体能力分级 | `AbilityTier`、`ability_tiers`、reference_interval、weight、reference_label | 恰 5 项；区间在 1~11 且 `lo <= hi`；允许重叠；候选集合可为空或多项 |
| 阶位档次 | `MagicRankBand`、`rank_bands`、interval | 恰 4 项；[1,3]/[4,6]/[7,9]/[10,11] 互斥、无缝全覆盖；每个 rank 唯一命中 |
| 资质 | `ManaAptitude`、`mana_aptitudes`、backfire_threshold、mana_gate | 恰 4 项；阈值严格递增；键与英文枚举语义一致 |
| 形态 | `MagicForm`、`magic_forms`、phase_loss_min/max | 恰 4 项；能损区间有限且 `min <= max`；真神位阶与 `SUPERTIER` 形态配对规则保持 |
| 实力称号 | `ProfessionRank`、`profession_ranks`、magic_domain | 恰 13 项连续；`magic_domain` 由配置决定且保持单调边界 |

## 三、注册表与快照边界

- `GameBootstrap.assemble()` 在 `GameConfig.ensure_loaded()` 成功后创建唯一 `MagicTierRegistry`，调用 `reload_configuration()` 并检查 `is_ready()`；失败阻断装配，不暴露半成品。
- registry 对外只提供类型化查询和版本化只读导出；解析器不得再次调用 `GameConfig.get_*`，也不得访问 registry 私有字典。
- `MagicTierSnapshot` 的 `ability_tier` 表示单一主体分级；弱映射结果使用 `ability_tier_candidates`，候选顺序稳定排序；`rank_band` 表示确定性档次。
- 快照 DTO 至少包含 `schema_version`、`config_version` 和六类维度字段；跨版本读取由迁移函数显式处理。
