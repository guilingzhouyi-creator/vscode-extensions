## 一、数据契约与边界

- `ConfigReloadResult` 提供新增、删除、变更表清单与版本号；任何消费者只接受完整快照。
- `WorldTimeDTO` 缺省字段按 schema 归一化，tick/day/month/year 不允许负值或倒退。
- `PhysiologySnapshot` 复制字段必须包含 `somatic_function`、`mental_stress_factor` 及既有全部生理维度。

## 二、业务实现与状态机

- 热重载采用 `SCAN -> VALIDATE -> BUILD -> NOTIFY -> SWAP`，构建失败保留旧快照。
- `WorldInstance.advance_world_time` 对缺失字段先补齐默认值，再执行单调推进并发事件。
- 生理复制使用字段清单或显式 DTO，新增字段未加入清单时测试失败。
- 设置应用器将真实渲染/音频适配器作为依赖，回滚只由确认超时状态触发。

## 三、配置驱动与工程化

- 必需表清单、schema 版本、迁移链和热重载消费者在 `infrastructure.domains` 声明。
- `audit_config.py` 增加未知字段、类型、上下界、迁移缺口和 provider/consumer 差集校验。
- 禁止通过公开 `GameConfig.get_value` 绕过类型化契约；保留兼容接口时必须增加审计告警。
