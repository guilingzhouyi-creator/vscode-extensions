## 一、 实现设计

### 1.1 AuditTask 扩展（group / exclusive）

```python
@dataclass
class AuditTask:
    task_id: str
    name: str
    script_name: str
    default_args: list
    scopes: set
    group: str = "audit"        # audit | bench | archive（Phase 29 新增）
    exclusive: bool = False     # True=独享串行（写操作任务，如归档）
```

### 1.2 三组任务表

| 组 | 任务 | 脚本 | 特性 |
| :--- | :--- | :--- | :--- |
| audit | 16 项（config/gd/hardcode/perf/coverage/config_unused/item_keys/secrets/bounds/name_keys/copywriting/magic_dimensions/event_probability/cdc/refactor_metrics/docs） | audit_*.py | 现状保持（默认组） |
| bench | `report_aggregate` / `report_sweep` | report_aggregate.py / report_sweep.py | 子进程透传各自 CLI（--gate/--out/--md 等） |
| archive | `archive_volume` | archive_volume.py | **exclusive=True**（git rm/移动文件写操作，独享串行） |

### 1.3 参数协议实现

| 参数 | 实现 |
| :--- | :--- |
| `--group audit\|bench\|archive` | 过滤任务表按组选择；可多次/逗号组合（`--group audit,bench`） |
| `--task a,b,c` | 逗号分隔 task_id 任意组合（跨组）；未知 id 报错退出码 2 |
| 无参 | audit 组全量（保持现状语义） |
| `-j/--serial/--json/--diff/--slice/--baseline` | 保持现状；-j 覆盖全组并行 |

### 1.4 并行调度（exclusive 串行队列）

```python
def schedule(tasks: list[AuditTask], workers: int) -> list[dict]:
    exclusive = [t for t in tasks if t.exclusive]        # 先串行（写操作防冲突）
    parallel = [t for t in tasks if not t.exclusive]     # 其余并行
    results = []
    for t in exclusive:                                   # exclusive 顺序执行
        results.append(run_one(t))
    with concurrent.futures.ThreadPoolExecutor(max_workers=workers) as ex:
        futures = {ex.submit(run_one, t): t for t in parallel}
        for fut in concurrent.futures.as_completed(futures):
            results.append(fut.result())
    return results
```

- 子进程隔离：每个任务 `subprocess.run([sys.executable, script, *default_args])`（现状复用）；
- `--serial` 时全部顺序执行（含 exclusive）；
- 状态聚合：`--json` 输出 tasks 数组（task_id/group/name/passed/returncode/elapsed_sec）+ 汇总（all_passed/耗时/并行加速比）——看板文本模式保持现状。

### 1.5 任务参数透传

- bench/archive 任务的定制参数（如 `--gate 10.0`、`--out path`）经**任务表 default_args 模板 + sh 链传参**（bench-sweep.sh/audit-perf.sh 现状不变）——统一入口聚焦**任务选择与并行编排**，不重写各脚本参数面（S1 边界不变量 2）。
