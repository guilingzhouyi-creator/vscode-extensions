## 一、 门禁链适配设计

### 1.1 既有调用面（零破坏保持）

| sh / 调用 | 现状 | Phase 29 处置 |
| :--- | :--- | :--- |
| `audit-all.sh` | 遍历 audit_runner（无参 → audit 全量） | **保持**（统一入口无参语义不变） |
| `bench-sweep.sh` | 直接调 report_sweep.py（定制参数组装：RUN_FILES/--out/--md） | **保持直接调用**（参数面复杂，不重写；S1 边界 2） |
| `audit-perf.sh` | 直接调 audit_perf_hotspots.py + report_aggregate.py（--gate） | **保持直接调用** |
| `archive` 流程 | archive_volume.py（--detect/--cycle/--all） | **保持直接调用**（exclusive 任务语义在统一入口内串行） |

**决策依据**：统一入口聚焦**任务选择与跨组异步并行编排**；各脚本的定制参数面（--gate 阈值/--out 路径/归档卷号等）仍由 sh 链承担参数组装——避免统一入口重写参数协议造成第二套维护面。

### 1.2 新增统一入口能力（并行启动演示）

```bash
# 全部 audit + bench 组并行启动（archive 组为 exclusive 需单独/串行）
python scripts/py/audit_runner.py --group audit,bench -j 4

# 跨组任意任务组合（异步并行，archive 自动串行先行）
python scripts/py/audit_runner.py --task config,name_keys,report_aggregate -j 2

# archive 组（exclusive 串行）
python scripts/py/audit_runner.py --group archive --serial
```

- `--group archive` 单组运行（exclusive 任务仅一个时顺序即串行）；
- `--task archive_volume,...` 跨组组合时 archive 自动先行串行（S2 调度器契约）。

### 1.3 兼容性与文档

- 参数协议为**纯新增**（--task/--group），既有参数（--diff/--slice/-j/--serial/--json/--baseline）语义不变；
- `audit_runner.py` 头部文档更新：声明「全脚本库统一调度入口（tool runner）——audit/bench/archive 三组 + 异步并行」；
- 任务表新增 bench/archive 任务条目（AuditTask group/exclusive 字段）。
