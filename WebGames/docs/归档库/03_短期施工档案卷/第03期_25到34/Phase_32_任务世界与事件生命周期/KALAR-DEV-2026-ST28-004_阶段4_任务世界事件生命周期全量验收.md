## 一、验收分级

| 级别 | 判定对象 | 通过条件 |
| :--- | :--- | :--- |
| P0 规范/数据一致性 | 命名、字段类型、配置版本、事件键 | 审计零新增；坏输入零静默回退 |
| P0 设计正确性 | 环路、负边、空队伍、负 delta、重复事务 | 全部拒绝或幂等，领域状态无部分提交 |
| P1 风险隔离 | 物化失败、热重载、异步消费者异常 | 可重试、可观测，失败不扩散到其它组 |
| P1 性能 | 大图寻路、批量提取、回放循环 | 达到配置阈值，结果与基准快照一致 |
| P2 可维护性/优化 | 多段事件路由、索引生命周期、优先队列候选 | 有文档和基准证据，未引入额外抽象负担 |
