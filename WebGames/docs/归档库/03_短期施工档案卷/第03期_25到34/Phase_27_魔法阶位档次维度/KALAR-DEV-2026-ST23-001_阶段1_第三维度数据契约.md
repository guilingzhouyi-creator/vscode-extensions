## 二、 第三维度数据契约（rank_band）

### 2.1 四档确定性区间（互斥全覆盖 1~11）

| 档次 | 英文键 | 区间 | 覆盖阶位 |
| :--- | :--- | :--- | :--- |
| 低阶魔法 | `magic.rank_band.low` | [1, 3] | 1、2、3 |
| 中阶魔法 | `magic.rank_band.mid` | [4, 6] | 4、5、6 |
| 高阶魔法 | `magic.rank_band.high` | [7, 9] | 7、8、9 |
| 超位魔法（统称） | `magic.rank_band.supertier` | [10, 11] | 10、11 |

- **互斥全覆盖**：四档区间无重叠、无缝覆盖 1~11（每阶恰属一档——与能力分级允许重叠的本质区别）；
- **禁嵌套**：档次名不嵌入阶位名（`低阶一阶` 禁止；`rank_1` 键保持纯梯度）；档次名也不嵌入能力分级名。

### 2.2 确定性判定

- `rank_to_band(rank) -> MagicRankBand`：按区间判定（[1,3]→LOW / [4,6]→MID / [7,9]→HIGH / [10,11]→SUPERTIER），越界返回 `UNREGISTERED_BAND` 拦截——**确定性映射（区间分段），非逐阶枚举表**；
- 档次不参与强度权重计算（强度由阶位梯度决定）——维度三仅分类展示/语境语义。

### 2.3 三维度平行不变量

- 阶位梯度（量化强度梯度）/ 能力分级（主体层次称谓）/ 阶位档次（魔法技术档次分类）**三者平行独立**；
- 任何新增等级/分类/规则不得破坏三维度独立性（沿 Phase 26 不变量延续）。
