## 一、 实现设计（第三维度 + 消费方接入）

### 1.1 MagicRankBand 枚举（magic_tier_snapshot.gd 新增）

```gdscript
# 3c. 阶位档次（Phase 27 第三平行维度：按阶位确定性区间分段——低阶 1~3 / 中阶 4~6 /
#     高阶 7~9 / 超位 10~11 统称；互斥全覆盖，禁嵌套命名）
enum MagicRankBand {
	LOW = 1,        # 低阶魔法（1~3 阶）
	MID,            # 中阶魔法（4~6 阶）
	HIGH,           # 高阶魔法（7~9 阶）
	SUPERTIER,      # 超位魔法（10~11 阶统称）
}
```

### 1.2 MagicRankBandResolver（新类，确定性判定）

```gdscript
# magic_rank_band_resolver.gd
class_name MagicRankBandResolver
extends RefCounted

const CONFIG_TABLE: String = "domains.magic_tiers"

## 确定性档次判定：rank -> band（区间分段，非逐阶枚举表）；越界返回 0（UNREGISTERED_BAND）
static func rank_to_band(rank: int) -> int:
	var bands: Dictionary = GameConfig.get_dict(CONFIG_TABLE, "rank_bands", {})
	for key in bands:
		var entry: Dictionary = bands[key]
		var interval: Array = entry.get("interval", [])
		if interval.size() >= 2 and rank >= int(interval[0]) and rank <= int(interval[1]):
			return int(entry.get("band", 0))
	return 0

## 档次名键查询（magic.rank_band.*；仅展示不作判定）
static func band_name_key(band: int) -> String:
	var bands: Dictionary = GameConfig.get_dict(CONFIG_TABLE, "rank_bands", {})
	for key in bands:
		var entry: Dictionary = bands[key]
		if int(entry.get("band", 0)) == band:
			return str(entry.get("name_key", ""))
	return ""
```

- **确定性**：每阶恰命中一档（互斥全覆盖由 audit 保证）；非 1:1 枚举表（区间分段判定）；
- **禁嵌套**：档次名不嵌入阶位名（键 `rank_1` 保持纯梯度，档次名仅经 `magic.rank_band.*` 表达）。
