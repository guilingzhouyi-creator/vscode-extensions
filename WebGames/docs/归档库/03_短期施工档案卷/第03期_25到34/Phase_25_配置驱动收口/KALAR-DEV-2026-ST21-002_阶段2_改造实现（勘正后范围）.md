### 1.3 AST kind 白名单单一真源（audit 从代码读取）

```python
# audit_event_probability.py —— 删除 Python KIND_WHITELIST 硬编码副本
# 改为从代码真源解析：扫描 narrative_causality_orchestrator.gd 的 match kind 分支
def load_kind_whitelist_from_code() -> set:
    src = (BACKEND / "domains/narrative_orchestration/narrative_causality_orchestrator.gd").read_text(encoding="utf-8")
    kinds = set(re.findall(r'match kind:\s*(.*?)\n\s*return false', src, re.S))
    return set(re.findall(r'"([A-Z_]+)":', src)) & KIND_LIKE  # 仅取 match 分支内的引号标识
```

- 真源 = 代码 `evaluate_ast_condition` 的 match kind 分支（新增 kind 只改代码一处，audit 自动跟随）；
- 保留 audit 的**复合节点 type 校验**（AND/OR/NOT 为代码语义常量，白名单从代码 OR 语句读取或保留内联——细则选代码为源统一）。
