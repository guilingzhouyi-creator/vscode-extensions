## 一、 三语言统一头注释契约 (Unified Header Contract)

### 1.1 bash（`scripts/sh/*.sh`）强制模板（与现有 README 模板对齐并补全字段）

```bash
#!/usr/bin/env bash
# =============================================================================
# <脚本名> — <一句话职责>
# -----------------------------------------------------------------------------
# 职能域：<bench|audit|check|report|archive|install|dev-util>
# 触发方：<本地 CLI / CI workflow / 定时任务>
# 文件路径: scripts/sh/<name>.sh
# 职责: <2~5 行>——核心职责、关键契约、配置/输入来源、边界约定（幂等/退出码语义）
# 用法：
#   bash scripts/sh/<name>.sh <args...>
# 依赖：<环境变量 / 外部命令（godot、python3）/ 前置脚本>
# 退出码：0=成功；1=业务失败/审查未通过；2=用法错误
# =============================================================================
set -uo pipefail
```

### 1.2 PowerShell（`scripts/ps1/*.ps1`）强制模板

```powershell
<#
.SYNOPSIS
  <脚本名>.ps1 — <一句话职责>（与 <同名>.sh 同构双实现）
.DESCRIPTION
  职责: <2~5 行>——核心职责、关键契约、配置/输入来源、边界约定。
  依赖: <环境变量 / 外部命令 / 前置脚本>
  退出码: 0=成功；1=业务失败/审查未通过；2=用法错误
.EXAMPLE
  .\scripts\ps1\<name>.ps1 <args...>
#>
[CmdletBinding()]
param(...)
```

### 1.3 Python（`scripts/py/*.py`）强制模板

```python
#!/usr/bin/env python3
# =============================================================================
# <name>.py — <一句话职责>
# -----------------------------------------------------------------------------
# 职能域：<audit|report|archive>
# 触发方：audit_runner（task_id="<kebab-id>"）/ 本地 CLI 直跑
# 文件路径: scripts/py/<name>.py
# 职责: <2~5 行>——核心职责、关键契约、配置/输入来源（config/ 表名）、边界约定。
# 依赖：<stdlib / 三方库 / 前置脚本>
# 退出码：0=通过；1=审查不通过/业务失败；2=用法错误
# =============================================================================
import ...
```

### 1.4 必填字段全集（三语言统一，审计引擎校验集）

| 字段 | sh 模板行 | ps1 模板行 | py 模板行 | 强制级别 |
| :--- | :--- | :--- | :--- | :---: |
| 文件路径 | `# 文件路径:` | `.DESCRIPTION` 内 | `# 文件路径:` | MUST |
| 职责 | `# 职责:` | `.DESCRIPTION` 内 | `# 职责:` | MUST |
| 职能域 | `# 职能域:` | `.SYNOPSIS` 标注 | `# 职能域:` | SHOULD |
| 触发方 | `# 触发方:` | `.SYNOPSIS` 标注 | `# 触发方:` | SHOULD |
| 用法 | `# 用法:` | `.EXAMPLE` | 头注释 `用法:` | SHOULD |
| 依赖 | `# 依赖：` | `.DESCRIPTION` 内 | `# 依赖：` | SHOULD |
| 退出码 | `# 退出码：` | `.DESCRIPTION` 内 | `# 退出码：` | SHOULD |

> MUST = `audit_gd.py` HEADER_MUST 同义（缺即阻断）；SHOULD = 门禁 warn 级（缺即告警，收敛期后升级 MUST）。

### 1.5 分隔线与未决标记禁令

- 头块上下分隔线等宽 **78 个 `=`**（与 `docs/后端代码注释规范.md` 二、区块集中分割同宽）；
- 生产注释**禁止显式未决标记**：TODO / FIXME / XXX / HACK 整词匹配即违规（对齐 `audit_gd.py` COMMENT-PENDING-MARKER，收敛为 Phase 编号追踪或移除）。
