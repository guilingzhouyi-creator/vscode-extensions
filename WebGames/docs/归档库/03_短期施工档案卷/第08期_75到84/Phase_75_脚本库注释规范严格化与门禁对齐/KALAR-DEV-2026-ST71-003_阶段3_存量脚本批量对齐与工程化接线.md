## 一、 存量批量对齐工程化 (Bulk Alignment & Engineering)

### 1.1 对齐执行顺序（三语言域分批，每批后跑引擎自检）

1. **sh 域**（14 个）：逐文件按阶段1 模板补全/修正头注释——必填 `文件路径:` 与 `职责:`、建议 `职能域/触发方/用法/依赖/退出码`、78 字符等宽分隔线；
2. **ps1 域**（14 个）：`.SYNOPSIS/.DESCRIPTION/.EXAMPLE` 补全职责与依赖/退出码说明，与对应 `.sh` 语义对齐；
3. **py 域**（26 个）：docstring 或头注释块补全 `文件路径/职责/职能域/触发方/依赖/退出码`；
4. **全量复检**：`python3 scripts/py/audit_script_comment.py` 违规清零。

### 1.2 audit-all 接入

- `audit-all.sh` / `audit-all.ps1` 的 audit 组追加 `script_comment`（通过 `audit_runner` AUDIT_TASKS 自动纳入，无需硬编码；若 runner 已按任务表驱动则仅登记即可）；
- 确认 `audit-all.sh` 汇总报告出现 `脚本库头注释规范审计 (audit_script_comment.py)` 一行。

### 1.3 文档同步
