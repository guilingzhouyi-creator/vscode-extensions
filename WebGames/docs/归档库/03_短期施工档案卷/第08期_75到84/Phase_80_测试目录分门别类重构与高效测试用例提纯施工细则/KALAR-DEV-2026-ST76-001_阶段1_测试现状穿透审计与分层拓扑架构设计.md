### 1.3 兼容适配桩工程实现设计（零死链保障机制）

为满足 `Inv-P80-1-2`，既有 `tests/unit/test_<name>.gd` 将统一转变为**超轻量继承代理桩（Compatibility Stubs）**：

```gdscript
# ==============================================================================
# 卡拉尔世界引擎 (Kalar World Engine) - 兼容适配代理桩
# 文件路径: res://tests/unit/test_inventory.gd
# 职责: 保持向后兼容性，桥接继承至 res://tests/unit/domains/inventory/test_inventory.gd
# ==============================================================================
class_name TestInventoryDomain
extends "res://tests/unit/domains/inventory/test_inventory.gd"

# 100% 透传所有静态测试方法，彻底杜绝 715 份历史归档文档与下游引用的死链与解析失败。
```
