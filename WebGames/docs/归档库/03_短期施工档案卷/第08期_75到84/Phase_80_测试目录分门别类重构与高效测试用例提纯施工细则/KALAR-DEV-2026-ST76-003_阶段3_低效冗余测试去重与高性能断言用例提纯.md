## 一、 测试用例样板消除与性能提纯工程 (Boilerplate Elimination & High-Performance)

### 1.1 现状重复样板 vs 提纯后对比

**重构前（散落于 105 个套件中的重复代码）**：
```gdscript
# 每个套件均重复手写此累加与打包逻辑（~25 行/套件，共计超 2500 行样板）
static func run_all_tests() -> Dictionary:
    var results: Array = []
    results.append(_test_item_a())
    results.append(_test_item_b())
    var passed := 0
    var all_ok := true
    for r in results:
        if r.get("passed", false):
            passed += 1
        else:
            all_ok = false
    return {
        "domain": "inventory",
        "total": results.size(),
        "passed": passed,
        "all_passed": all_ok,
        "results": results
    }
```

**提纯后（继承 `TestCase`，聚焦纯粹断言）**：
```gdscript
extends TestCase

static func run_all_tests() -> Dictionary:
    var results: Array[Dictionary] = [
        test_item_a(),
        test_item_b()
    ]
    return pack_results("inventory", results)

static func test_item_a() -> Dictionary:
    var ok := assert_eq(inventory.get_count("gold"), 100)
    return make_result("TC-INV-01: 基础金币断言", ok)
```

### 1.2 低效循环去重与高性能提纯策略

排查全域 28 个 Integration Pipeline 套件，识别并改造以下三类低效反模式：
1. **循环内重复加载配置**：提炼至类级别常量或 `setup()` 钩子，单次装配全套件共享只读数据；
2. **循环内瞬态实体分配**：消除用例内部的大量 `.new()` 实例创建，采用静态结构体或对象池模式；
3. **冗余的暴力遍历验证**：将无针对性的万次黑盒模糊遍历提纯为“边界极值 + 等价类覆盖”的高效靶向断言；
4. **随机种子锁死**：统一使用局部 `var rng := RandomNumberGenerator.new()`，显式执行 `rng.seed = 1337`；
5. **无头时间推进**：禁止使用 `OS.delay_msec()` 或依赖真实物理帧流逝，统一由逻辑时钟步进求解器推演状态。
