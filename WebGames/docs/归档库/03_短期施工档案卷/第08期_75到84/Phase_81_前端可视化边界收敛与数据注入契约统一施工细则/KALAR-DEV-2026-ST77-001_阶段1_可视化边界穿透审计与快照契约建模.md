### 1.2 统一快照 DTO 契约（强类型 + 序列化 + 展示派生字段标注）

```gdscript
# 契约落点（阶段1 仅定义，阶段2 接线）: res://frontend/domain_boundary/contracts/
class_name FrontendHudSnapshot extends RefCounted

var character_id: String = ""
var hp_current: float = 0.0
var hp_max: float = 1.0
var wallet_copper_total: int = 0
var monocrystals: int = 0

func to_dictionary() -> Dictionary:
	return {
		"character_id": character_id,
		"hp_current": hp_current,
		"hp_max": hp_max,
		"wallet_copper_total": wallet_copper_total,
		"monocrystals": monocrystals,
	}

static func from_dictionary(data: Dictionary) -> FrontendHudSnapshot:
	var dto := FrontendHudSnapshot.new()
	dto.character_id = str(data.get("character_id", ""))
	dto.hp_current = float(data.get("hp_current", 0.0))
	dto.hp_max = maxf(1.0, float(data.get("hp_max", 1.0)))
	dto.wallet_copper_total = int(data.get("wallet_copper_total", 0))
	dto.monocrystals = int(data.get("monocrystals", 0))
	return dto
```

按 18 视图逐项建立契约清单：角色/HUD/钱包/抽卡结果/商店价格/邮件/任务/公会/战斗/存档/地图/生态/通知/设置；每字段标注「权威来源（后端字段或 Phase 77/78 DTO）」与「展示派生字段（仅格式化，不可反推业务）」。

### 1.3 mock 真源与业务归属决议

* **真源收敛**：`skeleton_mock.json` 与 `MockDataCatalog` 二选一，输出迁移映射表；GameConfig 仅保留配置语义（布局、文案 key、阈值上限），业务数值与演示数据统一迁入快照服务。
* **业务归属**：gacha 概率与保底、economy 汇率与折扣与物价、crafting 成功率、character 加点与词缀聚合、account 骰点、guild 生成与 RBAC、quest 状态机、system_save 回放推进、world_map 领地升级等，统一迁往 `domain_boundary` 服务实现（同名接口可被真实后端替换），视图只消费已计算字段。
* **死视图裁定**：`main_dashboard` 登记为待处置项（移出导航注册或改写为纯快照消费），在阶段3 执行。
