### 1.2 视图边界静态审计立项（新增门禁）

* 建议规则：`frontend/views/**` 内禁止随机调用、禁止 `new()` 后端类、禁止 EventBus 订阅、禁止字符串路径取节点；规则落点优先复用既有架构护栏测试，其次新增独立审计脚本；
* 立项须在阶段1 契约审计中定案，并评估与 Phase 80 测试重构的落点冲突；若冲突则改挂 docs 治理规则 JSON，不得双份实现；
* 规则自证：反例夹具注入必须可检出，且不得对既有 18 视图产生批量误报（先清零后开闸）。

### 1.3 测试矩阵与计数同步

* 前端套件计数、断言计数与 `test_registry.gd` 注释、路线图声明三者一致；
* 新增边界套件必须注册且计数同步；阶段2/3 迁移的旧桩测试须替换为快照注入测试，禁止删除覆盖；
* Phase 80 若调整目录分类，本卷测试文件随其分类落位，不再自建平行目录。

### 1.4 文档同步与闭环

* `docs/路线图/路线图总索引.md`：Phase 81 看板状态推进（依两轮机制在 Round 2 验收全绿后置为已完成）；
