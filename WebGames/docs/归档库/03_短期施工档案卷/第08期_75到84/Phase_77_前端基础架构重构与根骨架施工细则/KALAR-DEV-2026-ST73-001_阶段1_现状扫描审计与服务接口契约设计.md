* **核心不变量约束断言**：`Inv-FE1-1 (零后端直接依赖)`：前端 `frontend/` 生产代码严禁直接 `new()` 或静态 `load()` 后端 `backend/` 业务实体与求解器，100% 经由 Service 契约交互；`Inv-FE1-2 (ViewModel 防御守卫)`：`HudViewModel` 的 `hp_max` 与 `ap_max` 求解必满足 `>= 1.0`，杜绝前端百分比渲染除零崩溃；`Inv-FE1-3 (钱包四级与单晶守卫)`：前端货币仅展示金/银/铜三元组与 `mana_monocrystals`（魔单晶），严禁捏造未登记资产。

## 一、 现状扫描与接口契约设计 (Status Audit & Interface Contracts)

### 1.1 存量资产与债务审计
1. **物理规模**：44 个文件（25 个 `.gd`、18 个 `.tscn`、1 个 `skeleton_mock.json`），共 21,301 行 GDScript；
2. **场景分布**：1 个主场景配置破损点（`res://frontend/views/main_dashboard.tscn` 实际不存在，真实路径为 `res://frontend/views/main_dashboard/main_dashboard.tscn`）；
3. **视图分布**：17 个业务功能视图（`account_entry`、`main_hud`、`character_progression`、`combat_view` 等）；
4. **核心痛点**：
   - **越界侵入后端聚合根 (P0)**：`main_dashboard.gd` 直接 `new()` 实例化了后端 `CharacterPhysiologySheet`、`CharacterWalletEntity`、`WorldClockMaster`；`MainHUDView` 直接实例化后端 `GmCommandIndexSolver`；
   - **缺乏多层级视口 (P0)**：`ViewRouter` 仅有一个扁平的 `_host_container`，导致 Screen、Modal、HUD、Loading 互相抢占；
   - **视图控制器巨型化 (P1)**：`AccountEntryView`（589 行）强行内嵌六大子面板与 40+ 个 `@onready` 节点；
   - **交互断裂与静默失败 (P2)**：存量代码包含 8 处 `pass # 骨架阶段` 桩，Tab 切换与局部按钮点击无任何反馈。

### 1.6 表现层响应式数据模型 (HudViewModel)
* 模块路径: `res://frontend/state/view_models/hud_view_model.gd`
* 约束: 严格遵循 P71 不变量（`hp_max >= 1.0` 零除防御，六维实值，钱包单晶），移除旧前端捏造的 `mana_crystals` 与 `stat_mp`。

```gdscript
# ==============================================================================
# 卡拉尔世界引擎 (Kalar World Engine) - 状态层: HUD 表现数据模型
# 文件路径: res://frontend/state/view_models/hud_view_model.gd
# 职责: 承载主页 HUD 渲染所需的全量响应式数据，对齐 P71 快照结构
# ==============================================================================
class_name HudViewModel
extends RefCounted

signal data_changed()

var character_id: String = ""
var character_name: String = ""
var race_name: String = ""
var location_name: String = ""

# 生命与行动力 (P71 零除安全守卫)
var hp_current: float = 100.0
var hp_max: float = 100.0
var ap_current: float = 10.0
var ap_max: float = 10.0

# 钱包三元组与魔单晶 (严格对齐 CharacterWalletEntity)
var gold: int = 0
var silver: int = 0
var copper: int = 0
var mana_monocrystals: int = 0

# 六维实值与等级
var attribute_values: Dictionary = {}
var attribute_levels: Dictionary = {}

## 从数据字典/快照更新并广播
func update_from_snapshot(snapshot: Dictionary) -> void:
	character_id = str(snapshot.get("character_id", character_id))
	character_name = str(snapshot.get("character_name", character_name))
	hp_current = float(snapshot.get("hp_current", hp_current))
	hp_max = max(1.0, float(snapshot.get("hp_max", hp_max)))
	ap_current = float(snapshot.get("ap_current", ap_current))
	ap_max = max(1.0, float(snapshot.get("ap_max", ap_max)))
	gold = int(snapshot.get("gold", gold))
	silver = int(snapshot.get("silver", silver))
	copper = int(snapshot.get("copper", copper))
	mana_monocrystals = int(snapshot.get("mana_monocrystals", mana_monocrystals))
	data_changed.emit()
```
