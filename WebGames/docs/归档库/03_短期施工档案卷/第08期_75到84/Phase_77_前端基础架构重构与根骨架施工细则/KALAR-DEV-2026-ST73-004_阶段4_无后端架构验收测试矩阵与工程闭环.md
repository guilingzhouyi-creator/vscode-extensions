## 一、 自动化验收测试套件构建 (Automated Test Suites)

### 1.1 架构与分层视口测试套件
* 文件路径: `res://tests/unit/test_frontend_architecture_and_bootstrap.gd`
* 覆盖点:
  1. `AppRoot` 初始化时 6 大 CanvasLayer 存在且层级单调递增；
  2. `NavManager` 驱动 Screen 压栈、出栈与替换，断言历史栈深度；
  3. `NavManager` 派发 Modal 弹窗与 Toast 队列；
  4. `ViewRouter` 兼容层穿透测试。

### 1.2 UI 状态与 Mock 服务测试套件
* 文件路径: `res://tests/unit/test_ui_state_and_mock_services.gd`
* 覆盖点:
  1. `UIStateContainer` 5 态流转与子节点显示互斥性；
  2. `UIStateContainer` 重试按钮点击与回调触发；
  3. `MockAuthService` 异步登录、错误凭据分支与注册；
  4. `MockWorldService` 快照获取与 `HudViewModel` 零除防御；
  5. `UIBindingRegistry` 弱引用生命周期与节点释放后自动移除。

### 1.3 弱引用内存泄漏防护与存量解耦
1. **`ui_binding_registry.gd` 弱引用改造验收**：
   - 验证节点使用 `weakref()` 包装存储；
   - 节点 `queue_free()` 后，调用 `refresh_all()` 不产生崩溃，且失效节点被自动清理；
2. **`ui_text_resolver.gd` 后端反射剥离验收**：
   - 验证移除对 `backend/domains/localization_i18n/` 的 `load()` 依赖，降级直接读取前端词库或配置表；
3. **`main_dashboard.gd` 历史控制器解耦**：
   - 剥离直接 `new()` 后端聚合根的逻辑，改由 `MockWorldService` 提供模拟快照。

### 1.4 未来后端接线契约清单 (Future Connection Blueprint)
本案卷严格建设了前端骨架，严禁提前接线后端。未来正式接线时，仅需按以下清单实施替换：

| 领域服务 | 当前 Mock 依赖 | 未来真实后端接线点 | 数据流协议 |
| :--- | :--- | :--- | :--- |
| **认证服务** | `MockAuthService` | `backend/domains/account/auth_service.gd` | `AccountRegistrationDTO` 请求/响应 |
| **世界状态** | `MockWorldService` | `backend/domains/world_state/` (Phase 71) | `HudStatusSnapshotDTO` 双轨事件/门面快照 |
| **战斗服务** | `MockCombatService`| `backend/domains/combat/combat_pipeline_fsm.gd` | 战斗动作包与战报事件 |
