## 一、 注入锚点脆弱耦合分析与结构化改造 (Anchor Robustness Engineering)

### 1.1 现存脆弱耦合点实测

| 脆弱点 | 位置 | 依赖的字面写法 | 失效场景 |
| :--- | :--- | :--- | :--- |
| ATT 指针注入 | `archive_short_term_cycle` 1024~1028 行 | `> **【施工目标】**：` 必须存在于正文 | 细则头块措辞演进（如改为【施工目标与范围】）后指针静默丢失 |
| navbar 插入定位 | `inject_volume_navbars` 709~727 行 | `> [!NOTE]` 或首个 `# ` 一级标题 | 细则改用其它引用块开头时导航浮标插错位置或整卷漏注 |
| 幂等判断 | 1024 / 706 行 | `案卷全局共享上下文` / `> 📍 **卷内快速直达**：` 字面包含 | 措辞微调即破坏幂等，重复注入 |

### 1.2 结构化锚点约定契约

```python
# constants.py — 锚点约定声明（唯一真源）
@dataclass(frozen=True)
class AnchorConventions:
    att_pointer_anchor: str        # ATT 指针插入锚：优先命中【施工目标】引用行，缺省回退首个 [!NOTE] 块尾
    navbar_note_anchor: str        # navbar 注入锚：[!NOTE] 块定位模式
    navbar_fallback_h1: str        # 一级标题回退定位模式
    att_pointer_marker: str        # 幂等标记串
    navbar_marker: str             # 幂等标记串

@dataclass(frozen=True)
class InjectOutcome:
    """注入结果结构化返回：降级分级 MUST 可观测"""
    file: str
    action: str            # injected | already_present | anchor_missed
    detail: str            # anchor_missed 时必填告警原因
```

### 1.3 降级分级策略

- **injected**：锚点命中，注入成功；
- **already_present**：幂等标记命中，跳过（非告警，属正常重入）；
- **anchor_missed**：锚点与回退位全部未命中——该文件跳过注入并输出告警行（`⚠️ 锚点未命中：<文件名>，ATT 指针/导航浮标未注入，请人工核对`），周期归档**不阻断**（头块与重命名等核心产物不受影响），但告警必须计入归档结束汇总，全卷 anchor_missed 达 2 处及以上时归档退出码升为 1（阻断留人工核验）。
