### 1.2 归档治理配置 Schema（constants.py 扩展契约）

```python
@dataclass(frozen=True)
class ArchiveHeaderTemplate:
    """14 项档案头块模板，年度由归档日期推导注入"""
    frontmatter_template: str      # 含 {annual_year} 槽位，严禁字面 2026
    navbar_anchor: str             # navbar 注入结构化锚点（阶段3 细化）
    att_pointer_anchor: str        # ATT 指针注入锚点（阶段3 细化）

@dataclass(frozen=True)
class ArchiveGovernanceConfig:
    header_template: ArchiveHeaderTemplate
    responsible_resolver: dict[str, str]   # {"前端": "卡拉尔世界引擎前端组", ...} 显式映射替代 "前端" in name 启发式
    keyword_stopwords_path: str | None     # 停用词外置路径；None 时用内嵌默认表
    cycle_size_default: int = 10
```
