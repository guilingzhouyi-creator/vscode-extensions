## 一、 核心实现 (Core Implementation)

### 1.1 `audit_script_comment.py` 新增 SHOULD 维度

```python
# 在 audit_file() 中追加（保持既有 MUST/SHOULD/分隔线/未决标记校验不变）

def _check_section_separator(lines: list, path: Path) -> list:
    """区块集中分割：脚本内逻辑分区应使用 78 字符等宽分割线（SHOULD 级）。"""
    issues = []
    for i, line in enumerate(lines[:120]):  # 仅头 120 行抽查，避免全文件 O(n)
        if re.match(r"^#\s*-{5,}", line) and not line.startswith(("# ===", "# ---")):
            # 短分割线（非 78 字符）用于分区提示 → warn
            issues.append({"file": str(path), "rule": "SECTION-SEPARATOR",
                           "detail": f"L{i+1} 区块分割线非 78 字符等宽（建议与后端规范一致）"})
            break  # 每文件最多提示一次，防噪音
    return issues

def _check_py_docstring(text: str, path: Path) -> list:
    """py 模块级 docstring 规范：存在且首行为一句话职责（SHOULD 级）。"""
    issues = []
    if path.suffix != ".py":
        return issues
    m = re.search(r'^\s*"""(.+?)"""', text, re.S | re.M)
    if not m or len(m.group(1).strip()) < 8:
        issues.append({"file": str(path), "rule": "PY-DOCSTRING",
                       "detail": "缺少模块级 docstring 或首行职责过短"})
    return issues
```

> 引擎 `main()` 汇总时把上述两类并入 `all_violations`，统计口径与 Phase 75 一致（违规计数按条输出，warn 不阻断 exit 语义——保持 `return 1 if any(error_level) else 0`，SHOULD 单独归 warn 桶）。
