## 四、GAP-04 修复实现设计

**文件**：`backend/domains/elite_mutation/generic_affix_solver.gd`

新增后端概率滚动入口（`apply_elite_affixes` 保留，不删除）：

```gdscript
## 后端概率滚动：按词缀池权重随机选取 count 个词缀（算法主权在后端）
## 词缀池由 config/domains/elite.json 的 affix_pool 段驱动
## rng 为空时回退共享实例（与 gacha/workshop 模式对齐）
static func roll_random_affixes(
    monster_tier: int,
    count: int,
    rng: DeterministicRNG = null
) -> Array[String]:
    var pool_key := "affix_pool/tier_%d" % monster_tier
    var pool: Array = GameConfig.get_array("domains.elite", pool_key, [])
    if pool.is_empty():
        # 回退全局词缀池（不分 tier 的统一池）
        pool = GameConfig.get_array("domains.elite", "affix_pool/global", [])
    if pool.is_empty():
        return []  # 无词缀池，安全返回空（不崩溃）

    var affix_rng := DeterministicRNG.resolve(rng)
    var selected: Array[String] = []
    var safe_count := mini(count, pool.size())
    for i in range(safe_count):
        var entry: Dictionary = affix_rng.pick_weighted(pool, "weight")
        if entry != null and entry.has("aff_id"):
            selected.append(str(entry["aff_id"]))
    return selected
```

**`DeterministicRNG.pick_weighted` 接口约定**（如不存在则同步补充）：

```gdscript
## 按 weight_key 字段加权随机选取（权重之和归一化，确定性）
func pick_weighted(pool: Array, weight_key: String = "weight") -> Variant:
    var total_weight := 0.0
    for entry in pool:
        total_weight += float(entry.get(weight_key, 1.0))
    if total_weight <= 0.0:
        return pick(pool)  # 退化为均匀随机
    var r := randf() * total_weight
    var acc := 0.0
    for entry in pool:
        acc += float(entry.get(weight_key, 1.0))
        if r <= acc:
            return entry
    return pool[-1] if not pool.is_empty() else null
```
