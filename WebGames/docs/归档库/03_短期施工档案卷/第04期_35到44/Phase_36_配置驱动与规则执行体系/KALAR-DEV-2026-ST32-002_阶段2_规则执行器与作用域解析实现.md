## 一、实现边界与错误隔离

| 领域 | 实现要求 | 禁止行为 |
| :--- | :--- | :--- |
| 作用域解析 | 兑换码级规则按 key 覆盖全局规则；运行时指标只注入本次判定 | 多层规则合并时产生隐式继承或相互覆盖语义 |
| 组合聚合 | AND/OR 短路求值；NOT 单规则取反；组合嵌套层级有配置上限 | 组合关系超出白名单或产生未定义语义 |
| 运行时数据 | 判定指标由调用方注入，引擎不持有玩家数据 | 引擎内嵌业务条件或缓存跨次判定结果 |
| 非法配置 | 未知 operator/缺字段/非法组合受控判定失败并输出原因 | 静默回退默认值掩盖配置错误 |

## 二、状态机与提交顺序

```text
作用域合并（兑换码级覆盖全局）-> 运行时数据注入 -> 逐条规则判定 -> 组合聚合 -> 判定结果
                                                      |非法配置
                                                      +-> 受控失败（结构化原因，不写状态）
```

- 作用域合并保持确定性：同 key 规则仅取兑换码级；无兑换码级时取全局；运行时指标永不写入配置。
- 判定结果含 `allowed`、`combinator`、`failed_rule_id`、`failed_metric`，供调用方决定后续流程（Phase 37 流程编排消费）。

## 三、算法与性能约束

- 单码规则数量有配置上限；AND/OR 短路求值避免无效判定。
- 作用域合并单次线性扫描，无嵌套重入；纯函数无副作用，可确定性重放（Phase 38 可重放审计机制兼容）。
