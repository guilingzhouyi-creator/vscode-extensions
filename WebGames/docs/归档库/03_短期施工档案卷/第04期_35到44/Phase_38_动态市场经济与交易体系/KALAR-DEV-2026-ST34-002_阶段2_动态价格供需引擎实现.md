## 一、实现边界与错误隔离

| 领域 | 实现要求 | 禁止行为 |
| :--- | :--- | :--- |
| 动态价格 | 价格 = f(基础价, 供需弹性, 时间因子, 成交量, 权重)——公式与参数配置化 | 直接返回配置固定价；把时间直接等同于价格 |
| 供需演化 | 供需随交易（买入/卖出）与时间推进更新；库存/成交量入状态 | 单向读取静态供需表 |
| 买卖价差 | 价差随市场状态（波动率/流动性）动态变化 | 固定价差常数 |
| 交易反馈 | 交易行为更新库存/供需/成交量并影响后续报价（闭环） | 交易不改状态（无反馈） |

## 二、状态机与提交顺序

```text
读取市场状态 -> 应用交易行为（更新供需/库存/成交量）-> 时间推进因子 -> 配置公式重算价格/价差
     -> 写回新市场状态 -> 状态快照入可重放日志（供审计/回滚）
```

- 交易结算先改状态后报价：买入增加成交量/需求、减少库存；卖出反向——顺序确定，避免竞态。
- 价格重算确定性：同输入（状态 + 时间 + 配置）必得同结果（纯函数核心 + 快照回放验证）。
- 时间推进不直接乘价格：时间因子作为公式输入之一（配合供需/成交量/权重），防止时间与价格线性等价。

## 三、算法与性能约束

- 公式核心为确定性纯函数（无随机/无系统时间依赖），随机性（若有）经确定性 RNG 与种子注入（复用 `deterministic_rng.gd`）。
- 单商品计算 O(1)；批量商品按配置批次调度；状态快照增量写入防无界增长。
