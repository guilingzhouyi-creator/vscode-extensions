## 一、配置映射契约

| 配置段 | 新增或收口字段 | 约束 |
| :--- | :--- | :--- |
| `domains.economy` → `formula` | `price_formula`（公式标识）、`elasticity`、`time_factor_weight`、`volume_weight` | 公式标识属于白名单；权重为非负有限数；最终结果不得写死 |
| → `bounds` | `price_min`、`price_max`、`change_rate_max`、`supply_min` | 上下限为正有限数；单轮价格变化率上限防极端波动 |
| → `protection` | `negative_price_policy`、`overflow_guard`、`mean_reversion_strength` | 负价/溢出受控处理；均值回归抑制长期漂移 |
| → `time_jump` | `max_tick_step`、`jump_policy`（STEP_CAPPED/REPLAY） | 时间跳变按步长封顶重算或按可重放批次处理 |
| → `init` | `initial_state`、`reset_on` | 初始状态与重置机制显式声明（世界重建/配置变更时） |

核心边界：

1. **上下限**：价格/供需恒在配置上下限内，超限钳制并记录。
2. **极端波动抑制**：单轮变化率上限 + 均值回归，防价格无限增长/下降。
3. **时间跳变处理**：大 tick 跳变按 `max_tick_step` 分步重算（不一次跨步），保持状态一致性。
4. **初始化与重置**：初始状态来自配置，重置机制（世界重建/配置变更）显式触发，不静默复用旧状态。
5. **不退化固定价格表**：配置只提供参数与初始值——运行时状态与时间共同计算最终结果（校验器拦截"直接读固定价"实现）。

## 二、热重载与快照流程

1. `GameConfig` 完成经济段解析与类型校验后发布带版本号快照（复用 Phase 31 ConfigReloadResult）。
2. 经济段任一字段非法时保留上一有效快照并输出结构化诊断；生产模式不得静默回退代码默认值。
3. 配置变更（版本变化）触发重置策略：按 `reset_on` 决定市场状态重置或渐进迁移。

## 三、异步、持久化和监控

- 市场状态快照增量写入可重放日志（同输入同结果审计）；快照保留窗口超限走压缩。
- 监控指标至少包括 `economy_price_clamp_count`、`economy_wave_suppress_count`、`economy_time_jump_count`、`economy_reset_count`（指标名 `snake_case`）。
- `audit_config.py` 增加经济段结构校验：字段类型、公式白名单、上下界合法性、保护策略枚举。
