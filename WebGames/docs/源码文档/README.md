> 本文档库面向 **WebGames（卡拉尔世界引擎，Kalar World Engine）** 当前运行中的全部源码、配置、模组工具链、测试套件与自动化门禁脚本，按实际工程拓扑建立 1:1 技术白皮书。

## 三、命名与编写规范

1. **目录与文件命名真源**：统一登记于 [docs_governance_rules.json](../../scripts/config/docs_governance_rules.json) 的 `naming_rules`，受 [audit_docs.py](../../scripts/py/audit_docs.py) 强制校验。
2. **文件族划分规则**：
   - 分卷总览与专题文档采用 `NN_主题.md` 两位阿拉伯数字前缀（如 `01_分层拓扑与依赖规则.md`）。
   - 后端基础设施、跨域底座及 47 个业务领域文档严格采用源码目录同构的 `snake_case` 命名（如 `world_state.md` 对应 `backend/domains/world_state/`）。
   - 每个目录提供唯一入口 `README.md`。
3. **事实一致性原则**：文中引用的类名、函数签名、配置表名、事件信道与测试文件路径均以当前代码及 [domains.json](../../config/infrastructure/domains.json) 为唯一事实来源。
