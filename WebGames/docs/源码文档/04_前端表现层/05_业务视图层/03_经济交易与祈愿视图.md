## 二、`economy_trade`（商铺、拍卖与货币金融）

- **公共组件装配**：使用 `KPageHeader`、`KCurrencyBar`、`KSplitPanel`、`KSearchBar` 组装主结构。
- **核心功能板块 (`EconomyTradeTabs`)**：
  1. **钱包与地缘商铺 (`ShopMode`)**：`set_wallet_snapshot()` 渲染四级货币（金/银/铜/魔晶），`set_shop_shelves_snapshot()` 渲染商铺货架与折扣。
  2. **集市拍卖行与商队物流**：竞拍出价列表与跨地缘运费预估展示。
  3. **物价走势曲线**：`set_price_trend_snapshot()` 渲染时间序列商品价格波动。
  4. **货币兑换所与资源水池**：汇率换算与总铜币价值预览（`calculate_total_copper_value()`），计算规则统一委托 `IEconomyService`；默认商店标题读取配置 `frontend.views:fe05_economy_trade/default_shop_title`。

## 三、`gacha_wish`（祈愿卡池与保底历史）

- **三段式视觉布局 (`GachaWishTabs`)**：
  - **主卡池区 (`WISH_MAIN`)**：多卡池切换按钮（`switch_banner`）、UP 概率展示网格、单抽/十连入口与大小保底进度条。
  - **结果弹窗 (`WISH_RESULT`)**：覆盖网格展示十连产出、稀有度边框、`NEW` 标记以及「跳过 / 详情 / 再抽一次」交互闭环。
  - **保底历史抽屉 (`PITY_HISTORY`)**：默认隐藏的侧边抽屉，呈现累计抽数统计与历史抽取记录。
- **演出状态机 (`WishAnimationState`)**：管控空闲 -> 动画播放 -> 结果展示 -> `reset_animation_state()` 的平滑复位；概率、保底计次与扣费校验经 `IGachaService` 获取。
