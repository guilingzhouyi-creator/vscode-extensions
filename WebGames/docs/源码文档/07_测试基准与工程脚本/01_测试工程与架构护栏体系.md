# 01 测试工程与架构护栏体系 (`tests/`)

> 本册覆盖 [WebGames/tests/](../../../tests/) 全部 **152 个** `.gd` 脚本，阐明无头测试驱动入口、注册中心契约、四大防退化架构护栏以及单元/集成/前端分层结构。

---

## 一、运行入口与基类支持 (`tests/*.gd` & `support/` & `fixtures/`)

| 模块 / 文件 | 类型 / 职责 | 源码路径 |
| :--- | :--- | :--- |
| 全量测试运行器 | `SceneTree` 入口，汇总执行 `TestRegistry.get_all_engine_test_classes()`（**140 套件**）并输出套件与断言通过率（DoD 100% 通过即 `quit(0)`） | [test_runner.gd](../../../tests/test_runner.gd) |
| 前端专项运行器 | 独立执行 `TestRegistry.get_frontend_test_classes()` 的 23 套前端测试，加速 UI 迭代反馈 | [test_fe_runner.gd](../../../tests/test_fe_runner.gd) |
| 架构护栏独立运行器 | 桥接 `audit-arch`，在无头 Godot 中快速运行 `TestArchitectureGuardDomain` | [arch_runner.gd](../../../tests/arch_runner.gd) |
| 批量语法预检器 | 单进程快速预加载扫描全仓 `.gd` 文件，阻断脚本解析与类型错误 | [batch_syntax_checker.gd](../../../tests/batch_syntax_checker.gd) |
| 全域测试注册表 (`TestRegistry`) | 单一注册中心（117 后端与横切套件 + 23 前端套件 = 140 套件），内置 `validate_registry_integrity()` 校验无空/重复引用 | [test_registry.gd](../../../tests/test_registry.gd) |
| 测试基类与扫描器 (`support/`) | `TestCase` 基础断言框架与 `structured_log_print_scanner.gd` 日志印记审计工具 | [test_case.gd](../../../tests/support/test_case.gd) |
| 契约测试工厂 (`fixtures/`) | `contract_registry_factory.gd` 提供可复用契约登记测试夹具 | [contract_registry_factory.gd](../../../tests/fixtures/factories/contract_registry_factory.gd) |

## 二、四大长效守护护栏 (`tests/guards/`，4 个套件)

| 护栏类 | 核心校验对象与不可违背不变量 | 源码路径 |
| :--- | :--- | :--- |
| `TestArchitectureGuardDomain` | 以 `config/infrastructure/domains.json` 为单一真源，自动校验「领域目录 / `config` 与 `sub_tables` 配置表 / `TestRegistry` 注册 / 确定性公约 / 文档领域总数 / 静态配置键存在性」六方双向零差集 | [test_architecture_guard.gd](../../../tests/guards/test_architecture_guard.gd) |
| `TestConfigurationGuard` | 校验除数/模数/分桶基数正值约束、概率边界、`_required_tables` 启动零缺失（`TC-CFG-04`）、`reload_config()` 版本单调递增与 `FifoBudget` 最旧逐出 | [test_configuration_guard.gd](../../../tests/guards/test_configuration_guard.gd) |
| `TestFrontendBoundaryGuard` | 静态扫描 `frontend/`：验证基类继承、禁止直连 `res://backend`（白名单界外）、禁止裸随机、配置语义 8 项白名单外零直读、`DesignTokens` 颜色单一真源、对象池契约与音效占位 | [test_frontend_boundary_guard.gd](../../../tests/guards/test_frontend_boundary_guard.gd) |
| `TestBackendRobustnessGuard` | 校验脏数据清洗、整数溢出与极值截断、错误分级分类、数组/字典深拷贝隔离，防止下游输入污染内核状态 | [test_backend_robustness_guard.gd](../../../tests/guards/test_backend_robustness_guard.gd) |
