## 二、`sweep -> promote -> gate` 性能防线工作流

1. **基准采集 (`bench-run` / `bench-sweep`)**：执行单次基准或多次运行（`bench-sweep.sh` / `bench-sweep.ps1`）取中位数以消除抖动，产出 `bench_latest.json` 与时间戳快照。
2. **基线晋升 (`report_aggregate.py --promote`)**：将稳定中位数确立为可追踪 golden 基线（`benchmarks/reports/baseline.json` 与 `baseline.md`）。
3. **回归门禁 (`audit-perf` / `--gate`)**：结合静态热点扫描（`audit_perf_hotspots.py`）与阈值比较（默认 10% 回退告警阻断），发现关键通路吞吐退化即返回 `exit 1`。
4. **演进趋势对比 (`report_sweep.py --md`)**：横向并排历史 sweep 中位数序列，量化优化收益或内存分配回潮。
