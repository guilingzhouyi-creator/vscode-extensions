# 进阶玩法需求设计稿：深度业务机制与全域交互拓扑

## 一、 玩法愿景与核心架构定位
本设计稿规范卡拉尔世界引擎（WebGames）的高阶业务机制，包括深层动态战斗时序、高维物品聚合统计、任务因果链式推演以及区域据点争夺等进阶玩法。
所有业务计算遵从无头解耦、配置驱动与高承压对象池化原则。

## 二、 核心进阶系统设计

### 1. 动态战斗时序与连击增益矩阵
- **时序切片驱动**：战斗计算按固定时间步推进，通过 `BattleTimelineSolver` 拆解动作前摇、瞬态判定与后摇结算；
- **连击与元素共鸣**：基于事件总线接收技能释放信号，动态计算多元素相互作用增益。

### 2. 任务因果链式推演引擎
- **图状态转移**：任务节点构成有向无环图（DAG），前置条件由 `QuestCausalityService` 统一校验；
- **奖励强类型上下文**：任务完成结算统一通过 `QuestRewardContextDto` 进行跨域分发，杜绝散装参数传递。

### 3. 全域物品统计与经济流转
- **聚合统计 DTO**：物品产出、消耗与稀有度分布通过 `ItemStatAggregationDto` 汇总；
- **缓存与增量更新**：高频流转数据采用 LRU 缓存与对象池复用，避免循环瞬态分配。

### 4. 世界状态与前端 HUD 视图解耦
- **单向数据流**：世界状态突变通过 `HudMutationContextDto` 发射至前端桥接层；
- **视图零计算**：前端仅通过 `apply_snapshot()` 消费数据，严禁在渲染循环中进行业务逻辑演算。
