# 模板库索引与 Agent 定向区间切片阅读指引 (Template Index & Slice-Reading Guide)

> [!IMPORTANT]
> **【Agent 极效 Token 阅读与防生搬硬套铁律】**：
> 1. **严禁无差别通读全量模板库**：模板库涵盖全生命周期规范，全量通读会产生大量无效 Token 消耗并稀释上下文注意力；
> 2. **强制定向区间切片阅读（Slice Reading）**：编写特定任务时，**仅允许使用 `view_file` 定向阅读指定模板文件的具体行号区间**；
> 3. **单任务 Token 控制**：通过区间阅读将每次模板查阅的 Token 消耗从 5,000+ Tokens 压缩至 **150 ~ 350 Tokens**（提纯度达 90% 以上）；
> 4. **严禁生搬硬套模板代码与占位符**：模板中的示例类名、字段、伪代码仅为结构示范。编写路线图细则时必须 **100% 替换为具体业务领域真实数据模型、具体配置表与真实逻辑**，严禁在交付物中残留 `<...>` 模板占位符或 `TODO/TBD/待填写/MyDataDTO` 未决标记；
> 5. **题头与自动化归档系统边界约定**：在活跃施工阶段（路线图），**正文直接从 `# 施工细则：...` 开始编写（题头可省略）**。若开发期附带了草稿题头，**自动化归档系统 (`archive_volume.py`) 在满 10 卷归档时会自动识别、安全剥离草稿题头，并统一签发权威国家标准 14 项档案头块（含真实档号、归档日期与 100% PASS 状态）**，彻底杜绝双重题头堆叠或草稿占位符泄漏；
> 6. **生命周期日期客观溯源铁律（施工开始日期落戳约定）**：Agent **创建施工细则文件时必须走一步获取系统时间**，在正文题头落「施工开始日期: YYYY-MM-DD（时段）」时间戳（**真实读取系统时间，严禁编造/硬编码**）。便捷获取脚本：**`bash scripts/sh/timestamp.sh`**（输出 `2026-09-08 半夜`；`--full` 输出含具体时刻 `2026-09-08 22:21 半夜`）——施工时段六刻度（半开区间 [start, end)）：**凌晨（02~05 时）/ 早上（06~09 时）/ 中午（10~13 时）/ 下午（14~17 时）/ 晚上（18~21 时）/ 半夜（22~01 时，跨日）**；历史三区间「上午」戳存量文档仅解析不回写，新落戳一律六刻度；**归档日期严禁 Agent 自编**，由自动化归档系统 (`archive_volume.py`) 周期封存时权威签发。归档时系统按 文件内「施工开始日期」时间戳 → Git 首次提交链 → 底层文件创建时间 三级溯源求解客观「形成日期」，并以「形成日期 ≠ 归档日期」识别真实施工周期与施工完成度（形成 == 归档 即告警存疑，供人工核对）；
> 7. **长远大局观架构铁律（严禁局部最小 MVP 敷衍）**：模板与标准化文件中的代码片段与逻辑仅为格式示范。实际设计与编写业务代码时，**严禁以仅跑通简单测试断言的局部最小 MVP 形式应付**，必须具备全生命周期状态闭环、双向边界隔离、配置绑定与长远扩展性的全局大局观；
> 8. **不明确需求真源基准与测试延后容许**：若遇不明确或未定义需求，**统一以「短期施工区（01_短期施工区/）」与「全宗归档库（docs/归档库/）」既有案卷标准为基准真源**并在此基础上演进完善；对于依赖下游或跨域长链条业务，**允许将部分非阻塞的高阶集成断言与表现层联调测试延后**至后续阶段或后续案卷闭环。
