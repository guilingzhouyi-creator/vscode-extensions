# 工作区规则家族分类与统一命名分类学 (Rule Family Taxonomy)

全工作区 385 条规则遵循严格的语义前缀编码规范，规则 ID 命名通式为：`[FAMILY]-[TOPIC]-[NNN]` 或分层格式 `L[0-5]-[TOPIC]`。

---

## 二、 规则命名与元数据规范

1. **唯一性**：规则 ID 在全工作区命名空间中全局唯一，严禁重复定义；
2. **祈使句摘要**：规则 `title` 必须使用客观祈使句清晰说明校验行为；
3. **严重等级划分**：
   - `error`：违规时触发门禁非零退出码一票否决阻断；
   - `warn`：违规时在审查报告中发出警告与重构建议。
4. **度量求真公理**：规则扣分必须分配至明确的质量维度（`dimension`），单规则跨维度扣分遵循 `MAX_AXES_PER_FINDING <= 4`，严禁虚假注水。
