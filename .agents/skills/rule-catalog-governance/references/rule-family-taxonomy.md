# 工作区规则家族分类与统一命名分类学 (Rule Taxonomy)

全工作区 380+ 条规则遵循严格的语义前缀编码规范：

| 家族前缀 (Family) | 领域职责 | 典型规则示例 |
| :--- | :--- | :--- |
| **`ARCH-`** | 架构拓扑、门面设计、空包跳板拦截 | `ARCH-FAC-001` (实质承载), `ARCH-ABS-001` (单行跳板消融) |
| **`GATE-`** | 本地提交与远端 CI 质量门禁守卫 | `GATE-AST-001` (AST 切片), `GATE-ISO-001` (双层同构防线) |
| **`CMG-`** | Git 提交说明格式、项目归属与文本风格 | `CMG-PRJ-001` (项目归属), `CMG-STY-001~006` (风格求实) |
| **`ADV-`** | 高性能计算、循环内存与对象池 | `ADV-PRF-002` (循环内零瞬态堆分配) |
| **`HYG-`** | 物理文件卫生、空文件与换行契约 | `HYG-RAW-001` (零空文件), `HYG-EOL-001` (EOL 契约) |
| **`VSC-`** | VS Code 扩展 UI 规范、双语与崩溃安全 | `VSC-UI-001` (UI 有界折叠), `VSC-UI-002` (暗色变量) |
| **`NAM-`** | 文件命名与跨生态标识符风格 | `NAM-FILE-001` (kebab-case 规范) |
| **`RCFG-`** | 规则一致性与元数据防漂移 | `RCFG-RULE-DRIFT` (规则反虚构) |
| **`L0~L5`** | workspace-timing 内部六层权重体系 | `L0-COMPILE`, `L1-STORAGE-CRASH`, `L3-I18N-COVERAGE` |
