# 文档超链接存活性与相对路径避坑指南 (`LINK-DEAD`)

## 一、 为什么绝对路径与 URI 会被阻断？

在自动化门禁（`audit_docs.py` / `validate-docs.js`）中：
- `LINK-ABS-FILE-URI`：包含 `file:///` 或 Windows 盘符（如 `C:\...`）将直接触发退出码 1 阻断。因为本地绝对路径在远端 CI、其他协同开发者或不同机器上必然解析失败；
- 必须统一采用**项目内的相对路径**。
