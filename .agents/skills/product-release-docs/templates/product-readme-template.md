# Product Name — Elegant & Reliable Tool for Developers

A lightweight, distraction-free extension designed to provide developers with clear, objective insights into their daily engineering workflow.

---

## Features

- **Automated Activity Tracking**: Accurately records active coding time without manual clock-in/out.
- **Visual Analytics Dashboard**: Interactive heatmaps, daily breakdowns, and weekly trends rendered directly within your editor.
- **Privacy First & Local Storage**: 100% offline data persistence. Your workflow metrics never leave your machine.
- **Bilingual Internationalization**: Seamless out-of-the-box support for both English and Simplified Chinese (简体中文).
- **Crash-Resilient Persistence**: Double-write journal mechanics ensure data integrity even across sudden reboots.

---

## Quick Start

1. Install the extension from the VS Code Marketplace or via `.vsix` package.
2. Open any workspace or project folder.
3. The timer begins automatically in your status bar as you edit files.
4. Click the status bar item or run command `Workspace Timing: Open Dashboard` to inspect your visual statistics.

---

## Extension Settings

This extension contributes the following settings:

| Setting Key | Default | Description |
| :--- | :--- | :--- |
| `workspaceTiming.autoStart` | `true` | Automatically track coding sessions upon workspace launch. |
| `workspaceTiming.heartbeatInterval` | `30` | Interval in seconds for flushing memory buffers to local journal. |
| `workspaceTiming.language` | `auto` | UI language (`auto`, `zh-CN`, `en`). |
