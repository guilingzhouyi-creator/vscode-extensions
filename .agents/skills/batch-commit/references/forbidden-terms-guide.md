# 提交说明六大禁词与正向技术事实转换词典

依据 `scripts/common/commit-msg-forbidden-terms.json` 与 `validate-commit-msg-style.js`，以下六类表达在提交说明中被严格拦截：

| 规则 ID | 违规类别 | 常见拦截词示例 | 正向技术事实重构建议 |
| :--- | :--- | :--- | :--- |
| **`CMG-STY-001`** | 临时与敷衍用语 | `临时`, `暂存`, `凑合`, `随便`, `先这样`, `wip`, `temp`, `hack`, `quickfix` | 陈述具体改动边界，如：“实现基础分支调度，暂未支持异步流” |
| **`CMG-STY-002`** | 过度肯定与夸大 | `绝对`, `彻底`, `完美`, `极致`, `终极`, `100%`, `工业级`, `顶尖`, `规则金字塔` | 陈述具体实现事实，如：“补齐类型断言与异常捕获分支” |
| **`CMG-STY-003`** | 过度否定与贬损 | `垃圾`, `稀烂`, `恶心`, `蠢`, `笨拙`, `毫无价值`, `糟透` | 客观描述技术缺陷，如：“原实现存在 O(n^2) 嵌套循环，耗时较高” |
| **`CMG-STY-004`** | 风格元叙事口号 | `调整语调为低调中肯`, `移除宣扬性词汇`, `优化文档表述` | 陈述具体修改的文字与章节，如：“更新 README 第四节关于对象池的说明” |
| **`CMG-STY-005`** | 程序化流水账 | `退出码0`, `返回0`, `XX项检查通过`, `双端返回0` | 陈述功能断言事实，如：“断言暂存区无物理空文件且行号平移对齐” |
| **`CMG-STY-006`** | 执行数字与量词 | `通过146套测试`, `耗时50.8s`, `覆盖419个文件`, `达标98%` | 提炼为质性技术事实，如：“断言全量单元自测套件合规通过” |
