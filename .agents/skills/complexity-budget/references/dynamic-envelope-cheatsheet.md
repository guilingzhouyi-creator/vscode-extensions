## 四、 循环内存纪律与虚假重构熔断速查

- **循环内存零瞬态堆分配（`CPX-SPACE-001`）**：
  - 严禁循环内创建闭包函数、临时对象 `{}`、临时数组 `[]`；
  - 严禁循环内字符串 `+=`，使用单例行缓冲数组 `push` + 循环外 `join`；
  - 严禁高频 `map.entries()` 数组展开，使用 `for (const [k, v] of map)` 原生解构；
- **虚假重构熔断（`BLOCK_GAMING_DETECTED`）**：
  - 语义变化量 $\text{ELOC}_{semantic} \le 15\%$ 且无真实技术债净消除，直接触发熔断；
  - 严禁纯重排代码、改空行、重排 import 伪装重构产出。
