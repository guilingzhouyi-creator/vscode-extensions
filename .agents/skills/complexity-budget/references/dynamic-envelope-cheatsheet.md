# 双轨代码体积与 1:3 动态包络速查表

依据 `scripts/common/evaluate-eloc-budget.js` 单源实现：

## 一、 核心阈值矩阵

| 概念 | 变量名 | 默认值 | 作用与判定逻辑 |
| :--- | :--- | :---: | :--- |
| **有效代码行硬顶** | `DEFAULT_MAX_ELOC` | `900` | 排除空行、注释后的纯净语义行，超标一票否决 |
| **物理总行数硬顶** | `DEFAULT_MAX_LOC` | `1400` | 编辑器排版兜底防膨胀线，超标一票否决 |
| **有效代码行预警** | `DEFAULT_WARN_ELOC` | `750` | 超过该值发出重构拆分建议告警 |
| **物理总行数预警** | `DEFAULT_WARN_LOC` | `1100` | 超过该值发出体积收敛建议告警 |
| **黄金密度比** | `DEFAULT_TARGET_DENSITY_RATIO` | `3.0` | 衡量排版注水与稀释程度的基准比值 |
| **高负荷契约注释率** | `MIN_CONTRACT_COMMENT_RATIO` | `8%` | 当 ELOC >= 600 时，注释行占总行数比例必须 >= 8% |
| **反向密度起征点** | `MIN_REPRESENTATIVE_LOC` | `250` | 当总行数 >= 250 时，纯代码行必须 >= LOC / 3.0 |
