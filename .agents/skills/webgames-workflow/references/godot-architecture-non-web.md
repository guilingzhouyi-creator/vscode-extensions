# Godot 4.7 卡拉尔世界引擎纯逻辑解耦架构与非 Web 游戏技术栈规范指南

> 本指南为 `WebGames/` 项目架构定位、领域求解器解耦与技术栈刚性边界的权威参考手册。

---

## 一、 项目本质定位与非 Web 游戏刚性红线

### 1. 历史命名与真实技术栈澄清
- **历史遗留命名**：本项目物理目录名为 `WebGames/`，但**绝对不是基于浏览器的 Web 游戏、网页游戏或 HTML5 游戏**；
- **真实物理本质**：基于 **Godot 4.7 游戏引擎**打造的**卡拉尔世界纯逻辑解耦与配置驱动独立系统**，核心编程语言为 **GDScript**，运行于桌面与无头（Headless）服务环境；
- **刚性禁止行为**：
  - 严禁在本项目中引入任何 DOM、HTML、CSS、Web API、浏览器运行环境或 JavaScript/TypeScript Web 前端技术栈；
  - 严禁假定游戏在浏览器渲染上下文中运行；
  - 严禁将 Godot 视图控制器与 Web 前端组件概念混淆。

---

## 二、 三层解耦架构拓扑

卡拉尔世界引擎采用严格的三层解耦架构：

```text
┌────────────────────────────────────────────────────────┐
│   前端表现层 (frontend/views/** · Godot Control 节点树) │
│   - 视图零业务计算 (零随机数、零数值公式、零持久状态)      │
│   - 强类型 Tabs 视图控制器 (显式强类型引用，零弱类型穿透)  │
│   - 唯一数据入口: apply_snapshot(snapshot: Dictionary) │
└───────────────────────────▲────────────────────────────┘
                            │ (单向快照注入)
┌───────────────────────────┴────────────────────────────┐
│   后端纯逻辑领域系统 (domains/** · 纯逻辑求解器与状态机) │
│   - 无头独立 (零 UI 依赖、零渲染管线依赖、可无头纯测)     │
│   - 确定性求解器与状态转移 (隔离时钟与确定性伪随机)       │
│   - 高承压对象池循环零堆分配 (ADV-PRF-002, reset_state) │
└───────────────────────────▲────────────────────────────┘
                            │ (统一读取配置)
┌───────────────────────────┴────────────────────────────┐
│   全域配置驱动中心 (config/domains/** · 领域配置表)      │
│   - 统一由 GameConfig.get_* / get_value 读取            │
│   - 严禁根目录平铺配置，按领域分级归并                  │
└────────────────────────────────────────────────────────┘
```

## 三、 前端可视化表现层核心设计原则

1. **视图零业务计算**：
   - 视图层仅负责根据快照渲染 UI、接收用户输入并向上分发意图事件；
   - 严禁在视图内调用 `randf()`/`randi()` 产生伪随机；
   - 严禁在视图内嵌入战斗数值公式、汇率结算、爆率判定等领域求解逻辑。
2. **强类型 Tabs 控制器治理**：
   - 消除 `var v = _view` 等弱类型缩写；
   - 必须通过 `@onready var _sub_view: ExplicitSubViewType` 显式声明强类型引用；
   - 杜绝动态弱类型穿透（如 `v.call("do_something")`）。
3. **单向快照注入 (`apply_snapshot`)**：
   - 业务数据一律通过 `apply_snapshot(snapshot: Dictionary) -> void` 注入；
   - 快照为纯数据字典（DTO），视图层不可持有领域实体内部引用。

## 四、 后端纯逻辑与无头执行机制

1. **无头可测试性**：
   - 后端领域系统（43 卷架构需求）必须能够完全脱离 Godot 窗口与渲染管线独立运行；
   - 单元测试通过 `TestCase` 统一调度，可在 CI 无头环境中极速跑完。
2. **极速原生 Python 静态提取门禁 (`audit_arch_static.py`)**：
   - 剥离 Headless 引擎冷启动依赖，直接通过 Python AST 语法分析器检查领域一致性、零堆分配与配置路由；
   - 提供毫秒级本地快速反馈，相比冷启动提速 87.5%。
3. **高承压对象池与循环零堆分配 (`ADV-PRF-002`)**：
   - 高频每帧更新（`_process` / `_physics_process`）与事件流中绝对禁止裸调 `.new()`；
   - 池化对象必须实现 `reset_state()` 接口，出池与入池对称维护。
