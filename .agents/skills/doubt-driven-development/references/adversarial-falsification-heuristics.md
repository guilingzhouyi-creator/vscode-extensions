# 对抗性证伪启发式清单 (Adversarial Falsification Heuristics)

> 本指南提供在怀疑驱动开发（Doubt Cycle）第 3 步“证伪（DOUBT）”阶段使用的五类高频证伪切入点。

---

## 一、 五类核心证伪切入点

| 证伪维度 | 典型自满假设 | 对抗性证伪探针 |
| :--- | :--- | :--- |
| **1. 边界与退化输入** | “输入集合非空且规模适中” | 当输入为空集、单元素、跨午夜边界或规模超阈值（$>1500$ 行）时，是否触发除零、归零或 $O(N^2)$ 卡死？ |
| **2. 循环内隐式堆分配** | “只是调了一个小辅助方法” | 循环体内的 `.replace()`、`.slice()`、正则匹配或闭包捕获是否在百万次迭代下引发 GC 抖动（`CPX-SPACE-001` / `ADV-PRF-002`）？ |
| **3. 状态与生命周期泄漏** | “任务结束后自然释放” | 异步异常或提前 `return` 分支下，Worker 监听器、定时器或对象池实例是否严格执行了解绑与 `reset_state()`？ |
| **4. 跨层契约与快照篡改** | “返回内部引用更省事” | 调用方修改返回对象是否会污染底层缓存或状态机？门面导出是否执行了不可变冻结（`ARCH-FAC-001`）？ |
| **5. 物理落盘与并发半写** | “直接覆写目标文件即可” | 进程在写入中途崩溃是否会损坏既有快照？是否严格走暂存路径（`stagingPath` / `stagingUri`）再原子重命名？ |
