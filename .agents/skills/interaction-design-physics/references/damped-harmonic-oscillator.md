# 二阶阻尼谐振子微分方程与动效动力学 (Damped Harmonic Oscillator)

## 一、 物理学数学模型

所有高质感、自然的界面动效均基于二阶阻尼谐振子（Damped Harmonic Oscillator）物理方程：

$$m \frac{d^2 x}{dt^2} + c \frac{dx}{dt} + k (x - x_{\text{target}}) = 0$$

其中参数定义如下：
* $m$：物体质量（Mass，单位 $\text{kg}$，通常归一化为 1.0）；
* $k$：弹性刚度（Stiffness，单位 $\text{N/m}$，决定弹簧拉力强弱）；
* $c$：阻尼系数（Damping，单位 $\text{N}\cdot\text{s/m}$，消耗动能的阻力）；
* $\omega_0 = \sqrt{\frac{k}{m}}$：未阻尼固有角频率；
* $\zeta = \frac{c}{2\sqrt{mk}}$：**无量纲阻尼比（Damping Ratio）**，是决定运动质感的核心物理量。

---

## 二、 阻尼比的三大运动模态

根据阻尼比 $\zeta$ 的取值区间，系统呈现三种截然不同的运动特征：

```
           ζ < 1                  ζ = 1                  ζ > 1
      [欠阻尼 Underdamped]   [临界阻尼 Critical]    [过阻尼 Overdamped]
  
       /\                         _---""""---_
      /  \    /\                 /            \
     /    \  /  \               /              \
    /      \/    \---------    /                \-----------
   存在振荡超调，利落回弹        最快速度收敛，绝对无振荡   缓慢平稳吸附，强力磁咬合
```

### 1. 欠阻尼态 ($\zeta < 1$)
* **解析解**：
  $$x(t) = 1 - e^{-\zeta \omega_0 t} \left(\cos(\omega_d t) + \frac{\zeta}{\sqrt{1 - \zeta^2}} \sin(\omega_d t)\right)$$
  其中 $\omega_d = \omega_0 \sqrt{1 - \zeta^2}$ 为阻尼固有角频率。
* **物理特征**：物体冲过平衡位置并在目标点两侧振荡衰减。
* **超调量 (Overshoot)**：$\text{Overshoot} = \exp\left(-\frac{\pi \zeta}{\sqrt{1 - \zeta^2}}\right)$。
* **典型应用**：按钮点击回弹（$\zeta \approx 0.612$）、成功打勾动画（$\zeta \approx 0.462$）。

### 2. 临界阻尼态 ($\zeta = 1$)
* **解析解**：
  $$x(t) = 1 - e^{-\omega_0 t} (1 + \omega_0 t)$$
* **物理特征**：系统以最短时间收敛到目标位置，且完全不发生任何冲过目标的振荡。
* **典型应用**：菜单弹出、浮层展开（$\zeta \approx 0.8 \sim 1.0$）。

### 3. 过阻尼态 ($\zeta > 1$)
* **解析解**：
  $$x(t) = 1 - \frac{s_2 e^{s_1 t} - s_1 e^{s_2 t}}{s_2 - s_1}$$
  其中 $s_{1,2} = -\omega_0 (\zeta \mp \sqrt{\zeta^2 - 1})$。
* **物理特征**：阻力过大，系统缓慢单调滑向目标点，完全无超调。
* **典型应用**：手势分栏拖拽释放吸附（$\zeta = 3.65$），松手瞬间如强磁铁咬合。
