# VS Code 插件设计质询问题库

## 维度 1：用户交互与侵入性 (UX & Ergonomics)
- **命令呈现**：该功能是仅放入 Command Palette，还是需要在状态栏常驻图标，亦或在上下文右键菜单展示？
- **通知打扰度**：运行结果是采用轻量状态栏跳动，还是弹出右下角 Notification？是否提供 "不再提醒" 开关？

## 维度 2：存储与工作区范围 (Storage & Scope)
- **生效范围**：配置项是全局生效（Global User Settings），还是单工作区独立隔离（Workspace Settings）？
- **数据保留**：历史记录是否需要跨窗口聚合显示？当工作区文件夹重命名时如何保持关联？

## 维度 3：性能与系统承载 (Performance & Budget)
- **扫描规模**：在大单体工程（文件数 > 50,000）下，是否需要设置白名单或跳过 .gitignore 目录？
- **心跳开销**：后台巡检与刷新间隔的下限预算是多少毫秒？
