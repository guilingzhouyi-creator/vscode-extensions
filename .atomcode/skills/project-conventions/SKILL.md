## 规范来源
所有约定以 `.cnb/` 目录下的文档为准，涉及具体主题时先阅读对应文档：
- NPC-约定-命名项目规范.md — 命名规范（文件、目录、标识符）
- NPC-约定-角色领域.md — 角色与领域边界
- NPC-约定-规划调度.md — 任务规划与调度约定
- NPC-约定-并行拓扑.md — 并行协作拓扑
- NPC-约定-容错兜底.md — 容错与兜底策略
- NPC-约定-门禁治理.md — PR 门禁与发布治理
- NPC-约定-协作流程.md — 协作流程
- NPC-约定索引.md — 约定文档索引

## 应用方式
1. 编写或修改代码前，先阅读相关约定文档
2. 严格遵守其中的命名、结构、流程与门禁规则
3. 涉及发布、PR、合并时，遵守门禁治理与 release 流程（scripts/ 下的 pr-gate.sh、release.sh）
4. 若约定文档与通用最佳实践冲突，以 .cnb/ 约定为准
