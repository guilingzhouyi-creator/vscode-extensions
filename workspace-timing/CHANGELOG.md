The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.5.2] — 2026-10-09

### Added（新功能）
- **开发者与外部智能体双轨工时智能感知**：新增 `ActivityWatcher` 宿主交互与文件变更监听器，实时感知键盘/编辑器输入（手动编码）与外部 AI Agent 文件写入事件，在运行期动态切换 `manual`（手动工时）与 `ai`（AI 协作工时）工作模式。
- **自适应空闲超时暂停与追溯截断**：新增空闲检测能力（配置项 `workspaceTiming.idleTimeoutMinutes`），在开发者离开键盘且无文件变更超出阈值时，自动将计时状态切入空闲暂停态并追溯截断离开前的时间段，空闲工时独立沉淀至 `idleSessions`，确保在工时守恒律 $T_{total} = T_{manual} + T_{ai}$ 下精准剔除无效等待时长。
- **状态栏实时协作模式指示与双语适配**：状态栏新增协作模式图标与运行态标识（手动模式、AI 模式、空闲暂停态），支持双语字典热切换与动态提示。

### Changed（功能与体验优化）
- **数据结构 v3 平滑迁移与双轨统计持久化**：升级 `DataValidator`，自动为存量历史记录补齐多维工时（`manualMs`、`aiMs`、`manualTotalMs`、`aiTotalMs`）与空闲历史数组，保证向后兼容性与数据无损迁移。
- **配置边界单一真源约束扩展**：在 `ConfigBounds` 中纳入空闲超时（0~120 分钟）、AI 检测开关及观察冷却窗口（10~600 秒）合法值域边界校验，杜绝非法畸形参数。

### Refactoring & Architecture（架构重构与规范化契约）
- **全仓六字段 JSDoc 模块头部契约落地**：全量 50 个 TypeScript 源码文件统一落实六字段 JSDoc 标准模块头部（`Module`, `File Path`, `Architecture Role`, `Dependencies & Triggers`, `Responsibilities`, `Exit Semantics & Design Rationale`），消除未结构化注释，代码自解释性与有效注释率大幅提升。
- **核心算法边界与数学不变量显式声明**：在 `RingBuffer`（无锁循环队列指针与崩溃一致性）、`TimeAggregator`（本地时区跨午夜切分与时长守恒）、`StorageCoordinator`（三级存储降频与紧急兜底备份）等核心算法中显式声明退化保护阈值与前置不变式约束。
- **TimerEngine 圈复杂度平铺重构**：重构 `recomputeTodayEnded` 函数，抽离日桶提取与模式分摊纯函数辅助方法，控制流平铺并消除三元嵌套，使单函数圈复杂度严格控制在合法包络内。

## [0.5.1] — 2026-10-05

### Added（新功能）
- **今日会话列表有界折叠与日报导出置顶**：当今日会话数超出 5 条时自动启用有界折叠模式，并在列表底部提供交互式折叠切换器（`展开更多会话（共 N 条）` / `收起会话`），运行期维护展开状态锁；将“导出日报”按钮提至今日明细标题栏右侧，优化操作可达性并精简卡片底部冗余空间。
- **跨工作区列表折叠与总时长红区迁移**：跨工作区对比列表超出 5 个工作区时支持有界折叠收缩；将“总时长与工作区计数”信息从卡片底部迁移至标题栏右侧焦点区域，以高对比度高亮呈现。

### Changed（功能与体验优化）
- **跨自然日休眠与息屏切分防御**：重构跨午夜会话结算与休眠恢复时间切分算法，精准规避操作系统息屏与休眠唤醒时的异常时长注水。
- **曲线平滑与图表排版美化**：优化周报单调三次样条平滑插值与高对比度暗色主题样式适配，消除微小噪点抖动，提升数据可视化表现力。

### Refactoring & Stability（架构重构与稳定性加固）
- **存储层多级崩溃安全与解耦演化**：完善双写存储机制，基于 RingBuffer 内存环形缓冲与 Journal 追加日志，杜绝异常断电导致的数据损坏；落实日汇总 `dailyTotals` 有界折叠与内存保护。

## [0.5.0] — 2026-10-04

### Added（新功能）
- **会话智能生命周期自动回收**：新增双端会话回收机制，支持跨周会话归零沉淀与单日会话超出 20 条时的 FIFO 滚动淘汰；淘汰与归零的历史工时严格沉淀至日聚合桶（`dailyTotals`），在保障总工时精确守恒的前提下控制运行期内存开销。
- **24 周全宽活动热力图**：活动热力图展示视窗由 12 周扩展至 24 周（168 格，覆盖约半年历史全景），并采用自适应弹性排版充满卡片，消除右侧留白。
- **周报 Markdown 导出入口置顶**：在周报看板顶部提供独立导出按钮，支持将周度工时明细与核心统计快速导出为 Markdown 报表。

### Changed（功能与体验优化）
- **周报活跃曲线常驻与 5 档精细刻度划分**：下线周柱状图模式，常驻鲜亮高对比度活跃曲线；Y 轴水平标尺细化为 5 档等分参考刻度（0%、25%、50%、75%、最大值），动态计算工时数值与标尺线。
- **周报核心指标深度集成与布局精简**：移除图三独立冗余栏，将周报关键指标（日均工时、活跃天数、最活跃日）集成至周报曲线看板顶部状态条，呈现更紧凑清晰的数据视图。
- **默认历史会话容量基准调整**：将 `workspaceTiming.storage.maxSessions` 默认保留上限调整为 140 条（对应单周高频编码周期），优化历史图表初始化性能与低配设备内存开销。

### Refactoring（架构重构与模块解耦）
- **时间聚合计算领域模块化解耦**：将原超长单文件 `TimeAggregator` 重构为日期处理、时长排版、日报明细、周报趋势与热力图 5 个高内聚子领域纯函数模块，并通过冻结门面对象保持向后兼容 API 契约。
- **报表构建与格式化导出解耦**：将 CSV 与 Markdown 格式导出流程从计时总控器中抽离为独立服务（`OrchestratorReportHandler`），实现表现层与应用编排层的清晰隔离。
- **超大模板模块化拆解**：将原 2100+ LOC 的面板模板拆解为基础样式、图表样式、交互脚本与骨架组合器 4 个独立模块，消除循环依赖并受行数红线预算看守。

### Fixed（缺陷修复与稳定性加固）
- **日志输出规范化与生产环境净化**：统一日志通道级别守卫，消除控制台未受控的直接打印。
- **配置与数据校验边界强化**：细化顶级字段、单会话及日汇总的纯函数校验，提升崩溃恢复与数据还原时的异常容错能力。

### Fixed（缺陷修复）
- **数据重置命令异常修复**：修复重置命令在部分工作区环境下无法正确识别存储路径的问题。
- **全链路时区归桶统一**：彻底统一为本地时区时间戳计算，杜绝早晨时段工时被误分至前一天的问题。

- **小时分布时长精准分摊**：小时分布按真实跨越时长精准分摊至对应小时，不再将整段会话粗暴归入开始时间。
