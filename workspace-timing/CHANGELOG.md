# Changelog

All notable changes to the "workspace-timing" extension will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.4.12] — 2026-09-28

### Changed（功能与体验优化）
- **展示文案去技术化与交互体验提升**：全面重构命令面板、设置选项、仪表板与通知文案，消除底层存储与内部术语暴露，提供清晰友好的中英双语交互说明。
- **24 小时活跃分布标尺精准对齐**：重构今日 24 小时分布槽位与微光分界，采用 7 锚点物理标尺刻度系统，实现刻度与时间柱垂直精准对齐，消除半小时偏差与边缘截断。
- **周报活跃曲线全宽自适应与暗色高对比度**：采用单调三次样条平滑算法，彻底消除零值下凹与平原噪点；完善玻璃态高亮色彩变量，锁定鲜亮纯白字体渲染；支持图表画布随窗口大小实时全宽自适应重绘。

### Performance & Optimization（性能与稳定性优化）
- **构建与扩展发布流水线加速**：优化编译生命周期守卫，消除重复编译开销；完善跨 IDE 热同步与扩展自愈校验流水线，提升发布包的一致性与分发效率。
- **数据结构与常量单一真源收敛**：统一收拢全库配置边界与格式常量，完善 Webview 样式变量完备性与双语词条覆盖，保障长期运行稳定性。

## [0.4.10] — 2026-09-27

### Performance & Optimization（性能与稳定性优化）
- **配置边界与双向持久化加固**：全面规范各配置项的合法值域与安全净化规则，保证设置面板与 VS Code 配置项的双向热更新与异常值自动纠错。
- **扩展发布包体积轻量化**：优化发布打包过滤清单，排除多余的本地缓存与临时文件，大幅削减 `.vsix` 安装包体积。
- **仪表板异步刷新调度重构**：抽离图表渲染与统计计算常量，优化后台静默调度器，降低面板开启时的宿主负载。

### Refactoring（架构与解耦）
- **崩溃恢复流程解耦与鲁棒性提升**：统一重构崩溃恢复与历史数据补偿模块，增强异常断电与突发崩溃场景下的数据完整性保障。

## [0.4.9] — 2026-09-05

### Added（新功能）
- **状态栏显示模式运行期即时生效**：支持在设置中选择状态栏默认显示模式（今日/累计、累计/今日、仅今日），点击状态栏快捷切换后自动持久化保存。
- **敏感信息安全防护与无用资源检测**：引入静态安全检测能力，自动拦截可能存在的敏感信息泄露与冗余无用资源。

### Performance & Optimization（性能与稳定性优化）
- **扩展激活事件现代化改造**：将激活事件升级为延迟后台激活（`onStartupFinished`），彻底消除扩展对 VS Code 首屏启动耗时的拖累。
- **历史数据聚合算法提速**：优化多维度统计的缓存与时间窗聚合算法，缩短图表数据计算耗时，降低高频使用时的内存占用与 GC 压力。

### Fixed（缺陷修复）
- **双语本地化覆盖率补齐**：全面梳理并补齐手动存盘提示、数据还原失败对话框、文件导出过滤器及 Webview 面板的双语词条。
- **只读数据视图防突变保护**：固化历史会话只读契约与排序不变量，杜绝外部突变导致的数据统计错位。

## [0.4.7] — 2026-08-29

### Performance & Optimization（性能与稳定性优化）
- **多周趋势窗口化轻量聚合**：重构多周趋势聚合计算为有界窗口算法，剔除对全生命周期历史数据的冗余排序计算，面板刷新计算耗时降至亚毫秒级（<0.02ms）。
- **历史归档零拷贝快路径**：为历史会话折叠归档增加零分配快速通道，在无超限会话的日常周期内实现零内存分配开销。
- **高频统计热点路径提前过滤**：在今日统计、7 日趋势、按小时分布与热力图等高频查询中引入时间区间快速过滤，大幅降低垃圾回收负担。

### Fixed（缺陷修复）
- **设置项双向持久化同步修复**：修复在面板中修改配置未能持久化写入 VS Code 全局设置的问题，确保 IDE 重启后配置 100% 保持。
- **周上限分割线视觉比例优化**：重构多周趋势轨道刻度算法，设定基准达标点处于 75% 黄金分割区域，超限时进度条等比延伸并高亮发光，视觉展现更加自然协调。

## [0.4.6] — 2026-08-28

### Fixed（缺陷修复）
- **跨午夜与休眠后崩溃恢复防重计修复**：修复跨午夜轮转或系统休眠后发生异常退出时，已封存历史时长被二次累加的问题；引入日志回放水位线机制，确保恢复时仅重放新增增量。
- **增量日志追加时序安全保障**：修复日志追加异常时的回退缓冲顺序，保持时间切片严格正序，杜绝恢复时切片顺序颠倒。
- **核心数据链路质量保障增强**：将崩溃恢复、会话调度与存储协调等关键业务链路全量纳入自动化回归验证。

## [0.4.5] — 2026-08-28

### Added（新功能）
- **周工作上限目标管理**：支持自定义每周工作工时目标（1~168 小时，默认 40h），可在设置或仪表板中便捷开启与调整。
- **动态渐变进度条与发光分割线**：多周趋势栏中直观呈现目标分割线，进度条采用安全青蓝、临界琥珀向超限深红动态过渡的多阶渐变色彩。
- **超限健康休息提醒**：当本周编码时长首次达到或超过预设目标时，弹出贴心通知提醒劳逸结合，每周仅提醒一次避免打扰。
- **多周趋势完整周期区间标注**：趋势栏日期标注升级为完整周时间区间（如 `08-24 ~ 08-30`），周期边界一目了然。
- **双阈值无损数据自动归档**：支持保留天数与条数上限双重容量约束，溢出会话自动按自然日汇总沉淀入日历史，工时与会话总数严格守恒。

### Fixed（缺陷修复）
- **全历史会话统计口径统一**：面板顶部“会话数”统一聚合历史日汇总、活跃会话与当前进行中会话，解决长期使用后总会话数统计虚低问题。
- **跨午夜时段自然日自动轮转**：长时间运行跨越午夜（00:00:00）时，自动将昨日会话封存并将今日起点重置为零点，严格对齐系统本地时间。
- **系统休眠与挂起时钟跳变过滤**：智能检测系统休眠导致的时钟突变，休眠与待机时长自动排除在编码工时之外。
- **跨周自然日精确切分与隔离**：重构跨周时段计算逻辑，周日夜间跨周一凌晨的会话按自然日精准拆分，历史周工时绝不误计入新一周。

- **24 小时明细分布图**：今日明细区新增 24 小时柱状分布图，跨小时会话按真实经过时间精准分摊，峰值小时高亮展示。
- **实时平滑活跃曲线**：周报区支持在「7 日柱状图」与「实时活跃曲线」间一键切换，直观呈现近 5 分钟编码节奏。

### Fixed（缺陷修复）
- **设置数值边界安全钳制**：为缓存容量、日志自动保存间隔与全量存盘间隔增加合法下限钳制，杜绝极端配置引发异常。
- **面板后台挂起与空转抑制**：面板处于不可见或最小化状态时自动暂停高频图表聚合计算，降低资源占用。
- **双语帮助提示内容补全**：全面补齐设置项问号图标的中英双语悬停帮助说明（Tooltip）。

### Performance & Optimization（性能与稳定性优化）
- **热力图渲染窗口化聚合**：热力图仅定向聚合窗口内 84 天数据，大幅提升历史久远项目下的加载速度。

## [0.4.1] — 2026-08-24

### Fixed（缺陷修复）
- **统计面板会话总数口径统一**：顶部统计卡统一计入已结束会话与当前进行中会话，消除不同统计区域数值不一致问题。
- **跨工作区失联数据自动回收**：全局同步时自动清理超过 30 天未更新的陈旧项目历史数据，防止跨项目统计虚高。
- **新增「清除跨工作区累计」命令**：支持独立清空全局聚合统计，不影响当前各工作区的本地计时数据。
- **重置数据后即时恢复计时**：修复重置操作后计时器未能自动重新启动的问题，重置后即时建立新会话并刷新界面。
- **时钟回拨防御机制**：加入时钟回退校验，杜绝系统时间意外被调早时产生负计时或负时长会话。
- **夏令时周窗口对齐安全化**：周报时间窗口改用本地日期安全归一化，规避夏令时切换导致的时长偏差。

## [0.4.0] — 2026-08-24

### ⚠️ Breaking（重要架构精简）
本版本是一次大规模**精简与可靠性重构**，移除闲置检测、打卡等次要噪音功能，全面回归「轻量、精准、零打扰」的核心计时体验。

- **移除冗余模块**：移除闲置检测、连续打卡等边缘功能及对应配置项，极大降低后台资源占用。
- **轻量 Markdown 报表导出**：统一收敛导出器为简洁实用的 Markdown 日报与周报，保留 CSV 明细导出。
- **存储目录结构优化**：数据存储路径从 `.workspace-timing-data/` 迁入 `.vscode/` 统一管理。

### Fixed（缺陷修复）
- **数据重置命令异常修复**：修复重置命令在部分工作区环境下无法正确识别存储路径的问题。
- **全链路时区归桶统一**：彻底统一为本地时区时间戳计算，杜绝早晨时段工时被误分至前一天的问题。
- **跨午夜会话自动分割**：跨越午夜的编码会话自动拆分为对应自然日的独立片段，日报与周报统计完全精准。
- **跨工作区自动同步周期化**：将全局时长同步挂载至定期存盘任务，解决跨项目统计更新不及时的问题。
- **小时分布时长精准分摊**：小时分布按真实跨越时长精准分摊至对应小时，不再将整段会话粗暴归入开始时间。

### Changed（功能与体验优化）
- **配置项即时热更新**：日志保存间隔与会话历史上限支持运行期实时生效，无需重新加载窗口。
- **Webview 安全基线加固**：遵循 VS Code Webview 安全规范，全面启用 CSP 策略与随机 Nonce 白名单。
